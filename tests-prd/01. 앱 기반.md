# 01. 앱 기반

> E2E: `tests/01. 앱 기반/`

## 01. 구성

1.  Next.js App Router와 React 기반의 브라우저 노트 앱이다.

2.  노트 상태는 Zustand로 관리하며 `web-notepad-storage` 키를 사용해 브라우저 로컬 저장소에 저장한다.

3.  저장 상태를 복원한 뒤 편집 화면을 표시하며, 복원 전에는 로딩 화면을 표시한다.

4. 개발 서버의 첫 접속은 `localhost`와 `127.0.0.1` 모두에서 저장 데이터 없이 기본 작업공간을 열 수 있다.

## 02. 브라우저 이력

1.  왼쪽 패널의 활성 탭 선택을 URL 이력으로 기록하며, 브라우저 뒤로가기·앞으로가기로 이전·이후의 탭을 복원한다.

2.  그룹 전환은 현재 활성 탭과 패널 상태를 포함해 이력에 기록하고, 뒤로가기·앞으로가기로 전환 전후의 그룹 UI를 복원한다.

3.  분할 화면에서 활성 pane 전환을 이력에 기록하고, 뒤로가기·앞으로가기로 활성 pane과 포커스를 복원한다.

4.  우측 패널을 연 상태를 URL 이력에 기록하고, 새로고침과 뒤로가기·앞으로가기로 복원한다.

5.  활성 탭을 닫아 같은 pane의 다른 탭이 활성화되면 URL의 탭 ID를 새 활성 탭으로 교체한다.

6.  우측 패널을 닫은 상태를 URL 이력에 기록하고, 뒤로가기·앞으로가기로 열림과 닫힘 상태를 복원한다.

7.  활성 탭을 닫은 후 새로고침해도 새 활성 탭과 pane을 유지한다.

8.  오른쪽 패널의 활성 탭 선택을 URL 이력으로 기록하며, 브라우저 뒤로가기·앞으로가기로 오른쪽 탭과 pane 포커스를 복원한다.

## 03. 저장소 예외 처리

1.  `web-notepad-storage`의 JSON이 손상되어도 기본 작업공간으로 복구해 앱을 열고, 이후 편집한 정상 상태를 다시 저장한다.

2.  브라우저가 `web-notepad-storage` 읽기·쓰기·삭제를 차단해도 기본 작업공간을 열고 현재 세션의 노트를 계속 편집할 수 있다.

## 04. 모바일 입력과 표시

1. 모바일 하단 패널 명령 아이콘은 28.8px, 현재 그룹 이름은 17px로 표시한다.

2. 모바일 하단 버튼 영역의 기본 높이는 76.8px로 표시한다.

3. 모바일 편집기는 19px 글자와 39px 줄 높이, 라인 번호는 12px 글자를 유지한다.

4. PC와 모바일의 에디터·검색창·그룹 이름 입력란은 그레이(`#b8b8b0`) 텍스트 커서를 표시한다.

5. 탭 색상을 변경하거나 다른 탭으로 전환해도 에디터의 텍스트 커서 색상은 유지한다.

6. 터치 기기의 에디터·검색창·그룹 이름 생성·수정 입력란은 전체 폰트 설정과 관계없이 글자 크기를 최소 16px로 유지한다.

7. 마우스 입력 기기에서는 전체 폰트 설정에 따른 입력란 글자 크기를 그대로 적용한다.
