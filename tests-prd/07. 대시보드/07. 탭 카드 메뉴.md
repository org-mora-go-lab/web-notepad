# 07. 탭 카드 메뉴

> E2E: `tests/07. 대시보드/07. 탭 카드 메뉴/`

1. 탭 카드의 우클릭 메뉴에는 그룹 이동·북마크를 표시하고 북마크를 전환할 수 있다. To Do는 Note 이동, Doing은 Done 이동 바로가기를 추가하고 그 외 상태에는 상태 이동을 표시하지 않는다. 삭제는 표시하지 않는다.
2. 그룹 이동은 현재 그룹과 Ungrouped를 제외한 대상 그룹으로 카드를 이동한다.
3. 우클릭은 에디터를 열지 않고 해당 카드만 강조하며 메뉴를 닫으면 강조를 해제한다.

4. To Do 카드 우클릭 메뉴의 Note 이동으로 본문을 보존하며 Note로 이동하고 새로고침해도 유지한다.
5. Doing 카드 우클릭 메뉴의 Done 이동으로 본문을 보존하며 Done으로 이동하고 새로고침해도 유지한다.
