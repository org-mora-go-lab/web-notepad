# 07. 탭 카드 메뉴

> E2E: `tests/07. 대시보드/07. 탭 카드 메뉴/`

1.  PC에서 To Do 카드의 우클릭 메뉴 맨 아래에 Note를 표시하고, 선택하면 해당 카드를 Note 상태로 이동하고 메뉴를 닫는다.

2.  PC에서 열린 탭 카드의 우클릭 메뉴로 북마크 상태를 전환할 수 있다.

3.  PC에서 열린 탭 카드의 우클릭 메뉴로 현재 그룹과 `Ungrouped`를 제외한 다른 그룹으로 이동할 수 있다.

4.  PC에서 Done 카드의 우클릭 메뉴 맨 아래에 Closed를 표시하고, 선택하면 해당 카드를 Closed 상태로 이동하고 메뉴를 닫는다. To Do·Doing 카드에는 Closed 기능을 표시하지 않는다.

5.  PC에서 탭 카드를 우클릭하면 에디터에서 열지 않고 우클릭 메뉴가 열린 동안 해당 카드의 테두리만 클릭한 카드와 같은 방식으로 강조한다.
