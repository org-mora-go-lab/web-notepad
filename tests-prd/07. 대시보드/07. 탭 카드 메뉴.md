# 07. 탭 카드 메뉴

> E2E: `tests/07. 대시보드/07. 탭 카드 메뉴/`

1. PC에서 To Do 카드의 우클릭 메뉴에 현재 상태를 제외한 Note·Doing·Done·Closed를 표시하고, 각각 선택하면 해당 상태로 이동하고 메뉴를 닫는다.

2.  PC에서 열린 탭 카드의 우클릭 메뉴로 북마크 상태를 전환할 수 있다.

3.  PC에서 열린 탭 카드의 우클릭 메뉴로 현재 그룹과 `Ungrouped`를 제외한 다른 그룹으로 이동할 수 있다.

4. PC에서 Done 카드의 우클릭 메뉴에 현재 상태를 제외한 Note·To Do·Doing·Closed를 표시하고, 각각 선택하면 해당 상태로 이동하고 메뉴를 닫는다.

5.  PC에서 탭 카드를 우클릭하면 에디터에서 열지 않고 우클릭 메뉴가 열린 동안 해당 카드의 테두리만 클릭한 카드와 같은 방식으로 강조한다.

6. Note 카드의 우클릭 메뉴는 To Do·Doing·Done·Closed로 이동할 수 있다. 이동 항목에는 그룹별 사용자 지정 상태 이름을 적용한다.

7. Doing 카드의 우클릭 메뉴는 Note·To Do·Done·Closed로 이동할 수 있다.

8. Closed 카드의 우클릭 메뉴는 삭제 명령과 함께 Note·To Do·Doing·Done으로 이동할 수 있다.

> 상태 이동 항목은 일반 동작 아래에 구분선으로 나누고 Note·To Do·Doing·Done·Closed 순서에서 현재 상태를 제외한다. 숨겨진 Note·Closed 상태도 이동 대상으로 표시한다.
