# 07. 탭 카드 메뉴

> E2E: `tests/07. 대시보드/07. 탭 카드 메뉴/`

1. 개인 그룹 탭 카드의 우클릭 메뉴에는 `Bookmark → Move Group` 순서로 항목을 표시하고 북마크를 전환할 수 있다. 삭제는 표시하지 않는다.
2. 그룹 이동은 현재 그룹과 Ungrouped를 제외한 대상 그룹으로 카드를 이동한다.
3. 우클릭은 에디터를 열지 않고 해당 카드만 강조하며 메뉴를 닫으면 강조를 해제한다.

4. To Do 카드 우클릭 메뉴에는 Note 또는 사용자 지정 New 상태로 이동하는 바로가기를 표시하지 않는다.
5. Doing 카드 우클릭 메뉴에는 Done 상태로 이동하는 바로가기를 표시하지 않는다.
6. 공유 그룹의 탭 카드 우클릭 메뉴에는 `Link → Bookmark → Move Group` 순서로 항목을 표시하고, Link를 선택하면 해당 공유 그룹과 탭 주소를 클립보드에 복사하며 결과를 알린다.
