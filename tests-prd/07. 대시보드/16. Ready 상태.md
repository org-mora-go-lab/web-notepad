# 16. Ready 상태

> E2E: `tests/07. 대시보드/16. Ready 상태/`

1. 기존 Note·To Do·Doing·Done 색상 분류를 유지하면서 Note·To Do·Ready·Doing·Done 순서로 표시한다. Ready의 기본색은 Orange이고 To Do·Ready·Doing은 설정에서 선택한 색상을 사용한다.
2. Ready로 이동한 노트는 Orange·내용·명시적인 Ready 상태를 새로고침 뒤에도 보존한다.

3. 이전 To Do·Doing·Done 색상 주기를 To Do·Ready·Doing 주기로 옮길 때 기존 카드의 상태와 본문을 보존하고 재접속 시 재변환하지 않는다.
