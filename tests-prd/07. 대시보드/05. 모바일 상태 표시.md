# 05. 모바일 상태 표시

> E2E: `tests/07. 대시보드/05. 모바일 상태 표시/`

> 모바일 카드에는 To Do·Doing·Done 상태 변경 버튼을 표시하지 않는다.

1.  모바일에서 탭 카드를 드래그하면 드래그 직후 발생한 클릭으로 카드를 열거나 편집기에 포커스를 옮기지 않아 가상 키보드가 열리지 않는다.

2.  모바일의 각 상태 제목은 위·아래 9px padding을 적용하고 제목 글자는 17.8px, 카운트 글자는 15.4px로 표시한다. 카운트는 우측 padding 13px로 기존보다 왼쪽으로 3px 이동한다. Note·To Do·Doing·Done·Closed 모두 같은 글자색을 사용한다. 카드가 있는 상태 영역 왼쪽에는 제목부터 카드 목록 끝까지 이어진 3px 세로선을 표시하고, 상태 색상을 70% 불투명도로 적용한다. 모든 빈 상태에서는 제목 왼쪽에만 상태색 선을 표시하고 본문은 옅은 테두리로 감싼다. 스크롤하면 각 상태 표시줄 위·아래 20px 범위에 2px 배경 블러를 표시한다. 블러의 불투명도는 상태 표시와 맞닿은 지점의 100%에서 바깥쪽의 0%까지 연속적으로 낮아지며, 스크롤 고정을 따라가고 클릭을 가로막거나 간격을 바꾸지 않는다.

3.  모바일에서 Note와 Closed를 단독 또는 동시에 표시하고 반복 전환해도 모든 상태 영역은 30px 간격의 한 열 세로 배치를 유지한다.
