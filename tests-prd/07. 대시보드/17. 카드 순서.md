# 17. 카드 순서

> E2E: `tests/07. 대시보드/17. 카드 순서/`

1. PC에서 같은 상태의 카드 앞·뒤로 드래그하여 순서를 지정하고 삽입선을 표시한다. 새로고침 후에도 유지하며 에디터 탭 순서와 본문은 변경하지 않는다.
2. 모바일에서도 길게 누른 카드를 같은 상태 안에서 정렬하며 드래그로 편집기를 포커스하지 않는다.
3. 다른 상태의 카드 위에 드롭하면 해당 카드 앞·뒤 위치로 이동하면서 상태와 순서를 함께 저장한다.
4. All Group에서 서로 다른 원본 그룹의 카드를 정렬하고 원본 그룹 소속과 에디터 탭 순서를 보존한다.
5. 공유 그룹 카드의 순서는 다른 협업자와 동기화하고 새로고침 후 유지한다.
