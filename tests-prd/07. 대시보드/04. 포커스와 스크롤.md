# 04. 포커스와 스크롤

> E2E: `tests/07. 대시보드/04. 포커스와 스크롤/`

1.  현재 탭 카드는 상태 색상의 12% 배경과 50% 불투명도 1px 테두리로 강조하고 추가 외곽선 없이 접근성 현재 표시를 제공한다. Note·Closed 상태의 현재 탭 카드는 탭 자체 색상 대신 해당 상단 상태 색상으로 배경과 테두리를 강조한다.

2.  고정 대시보드에서 다른 카드를 선택하면 편집기 활성 탭과 카드 강조를 함께 옮긴다.

3.  PC 대시보드 헤더는 카드 목록을 스크롤해도 상단에 고정한다. 스크롤 중 상태 표시 아래에는 24px 범위의 2px 배경 블러를 표시하고, 블러 불투명도는 상태 표시와 맞닿은 지점의 100%에서 아래쪽의 0%까지 연속적으로 낮아진다.

4.  모바일 대시보드의 첫 상태 제목과 헤더 사이는 20px 간격으로 표시한다. 스크롤하면 상태 제목을 Dashboard 헤더 바로 아래에 맞닿게 고정하고, Doing과 Done 영역에 차례로 진입할 때 해당 상태 제목으로 교체해 고정한다.

5.  모바일 대시보드를 위로 스크롤하면 Doing 카드 영역에 진입할 때 Doing을, To Do 영역에 진입할 때 To Do를 다시 상단에 고정한다.

6.  모바일에서 고정된 상태 제목은 자신의 왼쪽 세로선 끝까지 이동하고, 영역 끝에서 제목 아래쪽과 세로선 끝이 일치한 뒤 다음 상태 제목으로 고정을 넘긴다.
