# 14. 상태 변경과 데이터 보존

> E2E: `tests/07. 대시보드/14. 상태 변경과 데이터 보존/`

1. 상태 변경 뒤에도 노트 내용과 줄 선택 및 저장 기준을 보존한다.
2. 보조 상태에서 일반 상태로 이동해도 고정된 노트는 고정을 유지한다.
3. 편집기에서 숨긴 Closed 카드를 다른 상태로 옮겨도 자동으로 열지 않는다.
4. 북마크된 카드의 상태 색상은 원본 북마크에도 반영한다.
5. 하나의 카드 상태를 옮겨도 같은 그룹의 다른 북마크는 변경하지 않는다.
6. 전체 그룹에서 카드 상태를 바꿔도 원본 그룹과 다른 그룹의 소유권을 유지한다.
7. 카드 상태 메뉴를 Escape로 취소하면 데이터와 상태를 변경하지 않는다.
8. 상태를 Closed로 옮기는 동작은 편집 탭 닫기나 보관 기록 생성을 수행하지 않는다.
