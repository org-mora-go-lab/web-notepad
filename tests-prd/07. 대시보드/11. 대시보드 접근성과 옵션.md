# 11. 대시보드 접근성과 옵션

> E2E: `tests/07. 대시보드/11. 대시보드 접근성과 옵션/`

1. DASHBOARD 명령은 패널 제어 대상과 펼침 상태를 제공한다.
2. 대시보드 옵션 명령은 메뉴 제어 대상과 펼침 상태를 제공한다.
3. 열린 대시보드 옵션은 Dashboard options 이름의 dialog다.
4. 새 작업공간에서 Note는 기본으로 숨기며, Note 표시 명령은 aria-pressed로 꺼진 상태를 제공한다. 기존에 저장된 표시 선택은 유지한다.
5. Done 표시 명령은 aria-pressed로 표시 상태를 제공한다.
6. Note 표시를 켜고 다시 끄면 Note 컬럼과 눌림 상태를 함께 전환한다.
