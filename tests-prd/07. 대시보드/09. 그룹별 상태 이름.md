# 09. 그룹별 상태 이름

> E2E: `tests/07. 대시보드/09. 그룹별 상태 이름/`

1.  PC와 모바일에서 Edit Status를 선택하면 적용 대상 그룹명과 다섯 상태의 입력란을 표시한다. 저장한 이름은 현재 그룹의 상태 제목과 메뉴에만 적용하고 새로고침과 그룹 전환 후에도 유지하며 다른 그룹과 탭 색상은 변경하지 않는다. 기본 이름은 언어에 따르고 빈 입력은 기본 이름으로 복원하며 최대 30자까지 입력한다. 이전 전역 설정의 상태 이름은 적용하지 않는다.

2.  이름 편집을 Cancel·Escape·팝업 바깥 클릭으로 취소하면 저장하지 않고 대시보드를 유지하며 세로 점 버튼으로 포커스를 돌려준다.

3.  모든 그룹에서는 Edit Status를 비활성화하고 개별 그룹을 선택하라는 안내를 표시하며 그룹별 이름을 변경하지 않는다.
