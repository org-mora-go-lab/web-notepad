# 02. 전체 그룹과 카드 표시

> E2E: `tests/07. 대시보드/02. 전체 그룹과 카드 표시/`

> 대시보드는 현재 그룹의 탭만 표시하고 패널 상단에 그룹 이름 필드를 두지 않는다.

1.  All Group 대시보드는 에디터에서 숨긴 탭을 포함해 모든 그룹의 탭을 모으고 카드에 소속 그룹 이름을 표시한다.

2.  All Group에서 카드를 옮기면 해당 탭이 속한 그룹의 상태를 변경한다.

3.  내용이 비어 있거나 공백·탭·개행만 있는 탭은 카드와 컬럼 개수에서 제외한다.

4.  각 상태 컬럼의 카드는 과거 탭 고정 정보와 관계없이 북마크, 일반 순서로 표시하며 핀 아이콘을 노출하지 않고 같은 우선순위에서는 기존 순서를 유지한다.
5.  카드 제목은 본문과 같은 가용 너비를 사용하며 들어갈 수 있는 제목을 불필요하게 줄바꿈하지 않는다. 북마크된 카드만 표시 아이콘을 위한 공간을 확보하여 제목과 아이콘이 겹치지 않게 한다.
