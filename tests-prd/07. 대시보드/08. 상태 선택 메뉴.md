# 08. 상태 선택 메뉴

> E2E: `tests/07. 대시보드/08. 상태 선택 메뉴/`

1.  PC와 모바일의 대시보드 제목 글자 오른쪽 10px 위치에 공통 패널 아이콘보다 1.2배 큰 세로 점 세 개 버튼 아이콘을 표시하고, 선택하면 기존 MENU와 같은 형태의 Note·Done 선택 항목과 Edit Status 명령을 표시한다. Note는 접힌 모서리가 있는 메모지 아이콘으로 표시하고, 닫은 탭 항목의 기본 영어 명칭은 `Done`로 표시한다. 기존 푸터 진입점은 제거하고, 각 항목을 선택해 상태 표시를 전환해도 선택 영역을 유지하며 선택 여부를 표시한다.

2.  그룹 선택 영역처럼 메뉴 버튼을 다시 누르거나 선택 영역 바깥을 누르면 상태 선택 영역을 닫는다.

3.  상태 선택 영역에서 Escape를 누르면 대시보드는 유지한 채 선택 영역만 닫고 세로 점 버튼으로 포커스를 돌려준다.

4.  Note·Done 표시 여부는 그룹별로 독립 저장한다. 그룹을 전환하거나 대시보드를 닫았다 다시 열어도 각 그룹의 선택 상태를 유지하며, 새로고침 후에도 복원한다. 상태 선택 영역 자체는 대시보드를 다시 열거나 새로고침하면 닫힌 상태로 시작한다.
