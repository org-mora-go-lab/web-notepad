# 18. 개인 보기와 선택 복원

> E2E: `tests/07. 대시보드/18. 개인 보기와 선택 복원/`

1. 공유 그룹의 Note·Done 표시 여부를 공동 그룹 데이터에서 제외하고 로그인 사용자의 개인 작업공간에 저장한다. 다른 사용자 표시와 공유 저장 요청에 영향을 주지 않으며 다른 협업자의 편집이나 재접속 후에도 유지한다.
2. 같은 계정의 다른 기기에는 개인 이력을 통해 해당 공유 그룹의 표시 설정을 복원한다.
3. PC·모바일에서 대시보드를 열면 현재 선택한 카드가 목록 안에 보이도록 스크롤한다. 카드 선택 시 선택 상태를 유지하고 다음 열기에서도 그 위치를 복원한다.
4. 동기화 기준 이력이 없더라도 로컬에 저장한 공유 그룹 개인 표시 설정과 All Group 상태 이름을 초기 서버 조회가 덮어쓰지 않고 개인 이력에 병합해 보존한다.
