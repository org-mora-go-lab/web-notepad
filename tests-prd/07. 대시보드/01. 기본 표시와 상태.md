# 01. 기본 표시와 상태

> E2E: `tests/07. 대시보드/01. 기본 표시와 상태/`

1. 하단 그룹 버튼과 계정 영역 사이에 DASHBOARD 명령을 두고 PC는 아이콘 오른쪽, 모바일은 아이콘 아래에 라벨을 표시하며 선택하면 Dashboard 패널을 연다.

2. 현재 그룹의 탭을 저장된 상태에 따라 To Do·Ready·Doing·Done 컬럼에 분류하고 상태별 개수를 표시한다.

3. 모바일에서 카드가 없는 상태에는 `None`을 표시하고 카드가 생기면 해당 상태의 빈 안내를 제거한다. PC에서는 카드가 없는 상태에 빈 안내를 표시하지 않는다.

4. 에디터에서 숨긴 탭의 카드를 누르면 해당 탭을 다시 열어 활성화하고 PC 고정 패널을 유지한다. 모바일에서는 패널을 닫는다.

5. 탭에서 색상을 변경하면 해당 카드를 새 색상에 대응하는 컬럼으로 즉시 옮긴다.

6. PC 대시보드 헤더는 우측 닫기 버튼 왼쪽에 확장 버튼을 표시하고, 브라우저 전체 화면 API를 사용하지 않은 채 페이지 viewport 전체로 확장하거나 기존 패널 크기로 축소한다. 전체화면 대시보드는 열린 왼쪽 메뉴보다 위에 표시한다.
