# 포커스와 모바일 표시

> E2E: `tests/07. 대시보드/04. 포커스와 모바일 표시/`

1.  현재 탭 카드는 상태 색상의 12% 배경과 50% 불투명도 1px 테두리로 강조하고 추가 외곽선 없이 접근성 현재 표시를 제공한다. Note·Closed 상태의 현재 탭 카드는 탭 자체 색상 대신 해당 상단 상태 색상으로 배경과 테두리를 강조한다.

2.  고정 대시보드에서 다른 카드를 선택하면 편집기 활성 탭과 카드 강조를 함께 옮긴다.

3.  PC 대시보드 헤더는 카드 목록을 스크롤해도 상단에 고정한다. 스크롤 중 상태 표시 아래에는 24px 범위의 2px 배경 블러를 표시하고, 블러 불투명도는 상태 표시와 맞닿은 지점의 100%에서 아래쪽의 0%까지 연속적으로 낮아진다.

4.  모바일 대시보드의 첫 상태 제목과 헤더 사이는 20px 간격으로 표시한다. 스크롤하면 상태 제목을 Dashboard 헤더 바로 아래에 맞닿게 고정하고, Doing과 Done 영역에 차례로 진입할 때 해당 상태 제목으로 교체해 고정한다.

5.  모바일 대시보드를 위로 스크롤하면 Doing 카드 영역에 진입할 때 Doing을, To Do 영역에 진입할 때 To Do를 다시 상단에 고정한다.

6.  모바일에서 고정된 상태 제목은 자신의 왼쪽 세로선 끝까지 이동하고, 영역 끝에서 제목 아래쪽과 세로선 끝이 일치한 뒤 다음 상태 제목으로 고정을 넘긴다.

> 모바일 카드에는 To Do·Doing·Done 상태 변경 버튼을 표시하지 않는다.

7.  모바일에서 탭 카드를 길게 눌러 화면 밖의 상태 영역 쪽으로 터치 드래그하면 목록이 가장자리에서 자동 스크롤되고, 해당 영역에 놓으면 상태가 바뀐다. 드래그 직후 발생한 클릭으로 카드를 열거나 편집기에 포커스를 옮기지 않아 가상 키보드가 열리지 않는다.

8.  모바일의 각 상태 제목은 위·아래 9px padding을 적용하고 제목 글자는 17.8px, 카운트 글자는 15.4px로 표시한다. 카운트는 우측 padding 13px로 기존보다 왼쪽으로 3px 이동한다. Note·To Do·Doing·Done·Closed 모두 같은 글자색을 사용한다. 카드가 있는 상태 영역 왼쪽에는 제목부터 카드 목록 끝까지 이어진 3px 세로선을 표시하고, 상태 색상을 70% 불투명도로 적용한다. 모든 빈 상태에서는 제목 왼쪽에만 상태색 선을 표시하고 본문은 옅은 테두리로 감싼다. 스크롤하면 각 상태 표시줄 위·아래 20px 범위에 2px 배경 블러를 표시한다. 블러의 불투명도는 상태 표시와 맞닿은 지점의 100%에서 바깥쪽의 0%까지 연속적으로 낮아지며, 스크롤 고정을 따라가고 클릭을 가로막거나 간격을 바꾸지 않는다.

9.  모바일에서 Note와 Closed를 단독 또는 동시에 표시하고 반복 전환해도 모든 상태 영역은 30px 간격의 한 열 세로 배치를 유지한다.
