# 03. 그룹과 기록

> E2E: `tests/03. 그룹과 기록/`

## 01. 그룹 - 생성과 편집

1. 하단 그룹 선택 버튼을 누르면 버튼 위에 그룹 드롭다운이 열린다.

2. PC에서 그룹을 선택하면 드롭다운을 열린 채 유지한다.

3. 모바일에서 그룹을 선택하면 드롭다운을 바로 닫는다.

4. 모바일에서는 그룹 전용 우측 패널과 그룹 검색을 표시하지 않는다.

5. 기본 `Ungrouped` 그룹은 삭제할 수 없다.

6. 그룹 추가 버튼과 `…`·고정·수정·삭제·저장·취소 버튼은 정사각형이다. 추가 버튼은 PC 34px·모바일 40.8px, 나머지는 PC 28px·모바일 33.6px로 표시한다.

## 02. 그룹 - 삭제

1. 그룹 삭제 시 브라우저 확인창 대신 앱 팝업에 `Do you want to delete {group}?`와 실제 그룹 이름을 표시한다.

2. 삭제 팝업의 취소 버튼으로 삭제를 취소하면 그룹과 노트·북마크를 유지한다.

3. 삭제 팝업의 닫기 버튼으로 삭제를 취소하면 그룹과 노트·북마크를 유지한다.

4. 삭제 팝업에서 Escape로 삭제를 취소하면 그룹과 노트·북마크를 유지한다.

5. 삭제 팝업의 바깥 영역을 클릭해 삭제를 취소하면 그룹과 노트·북마크를 유지한다.

6. 삭제 팝업은 취소 버튼에 기본 포커스를 두고 팝업 안에서 키보드 포커스를 유지한다.

7. 삭제를 확인한 경우에만 그룹을 삭제하고 해당 그룹의 노트와 북마크를 `Ungrouped`로 옮긴다.

## 03. 그룹 - 정렬과 표시

1. 그룹 목록 첫 줄에 `All Group`과 `Ungrouped`를 나란히 두고 이름 있는 그룹은 그 아래에 배치한다.

2. 이름 있는 그룹은 한글로 시작하는 이름을 먼저 배치하고 같은 분류 안에서 한국어 기준 문자순으로 정렬한다.

3. 현재 그룹 이름은 PC와 모바일 모두 그룹 선택 버튼에 아이콘과 함께 표시한다. PC는 최대 너비 351px의 한 줄 말줄임으로 표시한다.

4. 모바일 그룹 이름은 그룹 선택 버튼의 아이콘 오른쪽에 한 줄 말줄임으로 표시한다.

5. 긴 그룹 이름은 전체 이름을 툴팁과 접근성 라벨로 제공한다.

6. 긴 그룹 이름은 다른 하단 라벨과 겹치지 않는다.

7. 그룹 이름은 PC 15px·모바일 18px로 표시한다. 생성 입력은 PC 14px·34px, 모바일 16.8px·40.8px이고 수정 입력은 PC 15px·30px, 모바일 18px·36px다.

8. 첫 줄의 `All Group`과 `Ungrouped`는 같은 너비로 4px 간격을 둔다. 그 아래에 나머지 그룹을 배치하고 행 높이는 PC 39px·모바일 46.8px로 표시한다.

9. `Ungrouped`와 `All Group` 이름은 다른 그룹 이름보다 옅은 같은 회색으로 표시한다.

## 04. 그룹 - 고정과 메뉴

1. `Pin`을 누르면 그룹을 이름 있는 그룹 목록의 맨 위로 옮기고 핀 아이콘을 표시한다.

2. 탭 메뉴의 그룹 이동 목록도 고정한 그룹을 맨 위에 배치한다.

3. 그룹 고정 상태는 브라우저에 저장하고 새로고침 후 복원한다.

4. 고정한 그룹에는 `Unpin`(`고정 해제`)을 표시한다. 고정을 해제하면 핀 아이콘을 제거하고 일반 정렬 위치로 되돌린다.

5. 드롭다운의 바깥 영역을 클릭하면 드롭다운을 닫는다.

6. Escape로 드롭다운을 닫으면 그룹 선택 버튼에 포커스를 복원한다.

7. 열린 드롭다운의 그룹 선택 버튼을 다시 누르면 드롭다운을 닫는다.

8. 기본 `Ungrouped`와 가상 `All Group`에는 `…` 버튼을 표시하지 않는다.

9. 그룹 행의 hover 배경은 선택된 행보다 옅게 표시하고, 선택된 행은 hover해도 더 짙은 배경을 유지한다.

## 05. 북마크

1. 북마크를 패널에서 제거할 수 있다.

2. 원본 탭이 남아 있는 북마크를 열면 해당 탭을 활성화한다.

3. 원본 탭이 없는 북마크를 열면 내용을 복원한다.

4. 원본 탭이 없는 북마크를 열면 탭 색상을 복원한다.

5. 원본 탭이 없는 북마크를 열면 선택한 줄 번호를 복원한다.

6. PC에서 패널 제목 22px, 북마크 제목 15px, 내용·빈 문구 16px, 검색 14px·높이 42px, 시각 12px, 동작 버튼 13px, 검색 결과 없음 15px로 표시한다.

7. 모바일은 북마크 패널 글자를 PC의 1.2배로 표시하고 검색 입력 높이 42px는 유지한다.

8. 생성 시각은 제목 길이와 관계없이 우측의 폭 12ch·높이 PC 32px·모바일 38px 영역에 표시한다. 긴 제목은 말줄임해 시각과 겹치지 않는다.

9. 생성 시각은 첫 줄 `YY. MM. DD.`, 둘째 줄 초 없는 `hh:mm AM/PM` 현지 시각으로 표시하며 각 줄은 줄바꿈하지 않는다.

## 06. 닫은 탭 - 보관과 복원

1. PC와 모바일 MENU에 아이콘과 `CLOSED` 라벨을 표시하고, 0보다 큰 CLOSED 개수를 괄호 없이 표시한다.

2. PC와 모바일에서 CLOSED 개수가 0이면 개수를 숨긴다.

3. CLOSED를 선택하면 드롭다운을 닫고 Closed 패널을 연다.

4. 상태 표시줄에는 CLOSED를 표시하지 않는다.

5. 닫을 당시의 그룹이 삭제되었으면 목록에 `Ungrouped`로 표시하고 `Ungrouped`로 복원한다.

6. CLOSED 개수와 패널 목록은 현재 그룹과 관계없이 모든 그룹의 닫은 탭을 수집하고 그룹 전환 후에도 유지한다.

7. 빈 탭과 내용이 10자 이하인 탭은 닫은 탭에 보관하지 않고 영구 삭제한다.

## 07. 닫은 탭 - 패널과 검색

1. CLOSED 명령은 모든 그룹의 닫은 탭을 모은 패널을 연다. 각 항목에 그룹 이름, 탭 내용과 닫은 시각을 표시한다.

2. 닫은 탭 내용은 접지 않은 전체 내용으로 표시하며 접기 버튼을 두지 않는다.

3. 항목의 삭제 버튼은 확인 팝업이나 브라우저 확인창 없이 즉시 영구 삭제한다.

4. 남은 항목이 없으면 `Empty Closed`를 표시한다.

5. 검색창에 `Search closed` placeholder를 표시한다.

6. 그룹 이름, 탭 제목과 내용을 대소문자 구분 없이 부분 검색한다.

7. 항목을 삭제해도 패널은 열린 상태를 유지하고 다른 항목을 그대로 둔다.

8. 검색 결과가 없으면 `No search results`를 표시한다.

## 08. 닫은 탭 - 시각과 재보관

1. 닫은 시각은 우측의 폭 12ch·높이 PC 32px·모바일 38px 영역에 표시한다. 긴 그룹명은 말줄임해 시각과 겹치지 않는다.

2. 닫은 시각은 첫 줄 `YY. MM. DD.`, 둘째 줄 초 없는 `hh:mm AM/PM` 현지 시각으로 표시하며 각 줄은 줄바꿈하지 않는다.

3. 북마크된 일반 탭은 확인 팝업 없이 닫고 닫은 탭 목록에 보관하지 않는다.

4. Closed에서 복원한 뒤 수정하지 않은 탭은 확인 없이 다시 닫은 탭에 보관한다.

5. 복원 후 수정하지 않은 짧은 탭도 확인 없이 닫고 Closed에 다시 보관한다.

6. 복원 후 내용을 수정한 탭을 닫으면 탭 닫기 확인 팝업을 표시한다.

7. 복원 후 수정하지 않은 북마크 탭도 확인 없이 닫고 Closed에 다시 보관한다.

## 09. All Group

1. `All Group`을 선택하면 하단 그룹 이름에 `All Group`을 표시한다.

2. `All Group`은 모든 그룹의 탭을 하나의 편집기에 모아 표시한다.

3. `All Group` 선택을 저장하고 새로고침 후 복원한다.

4. `All Group`의 분할 배치는 개별 그룹의 분할 배치와 별도로 관리한다.

5. `All Group`에서 기존 탭의 내용을 편집하면 그 탭이 속한 그룹에 반영한다.

6. `All Group`에서 기존 탭의 색상을 바꾸면 그 탭이 속한 그룹에 반영한다.

7. `All Group`에서 기존 탭을 닫으면 그 탭이 속한 그룹에 반영한다.

8. `All Group`에서 만든 새 탭은 `Ungrouped`에 추가한다.

## 10. 그룹 - 상태 격리

1. 각 그룹은 서로 다른 탭과 노트 내용을 유지한다.

2. 북마크는 생성한 그룹에만 저장한다.

3. 각 그룹은 마지막으로 활성화한 분할 편집기를 독립적으로 복원한다.

4. 각 그룹은 분할 비율을 독립적으로 저장하고 다시 전환할 때 복원한다.

## 11. 그룹 - 이름 편집

1. 이름 수정 입력에서 Enter를 누르면 앞뒤 공백을 제거해 저장한다.

2. 모바일에서도 이름 수정 저장 버튼을 화면 안에 표시하고 변경을 저장한다.

3. 취소 버튼은 입력한 이름을 버리고 기존 이름을 유지한다.

4. 이름 수정 입력에서 Escape를 누르면 편집을 취소한다.

5. 그룹 이름을 바꿔도 그룹 ID를 유지하고 새로고침 후 복원한다.

6. 그룹 이름을 바꿔도 그룹의 노트를 유지하고 새로고침 후 복원한다.

7. 그룹 이름을 바꿔도 그룹의 북마크를 유지하고 새로고침 후 복원한다.

8. 바꾼 그룹 이름은 새로고침 후에도 복원한다.

## 12. 그룹 - 생성 입력과 검증

1. 새 그룹 이름 입력란의 placeholder는 `Group name`이다.

2. 새 그룹 이름의 앞뒤 공백을 제거해 저장한다.

3. 새 그룹 이름은 최대 60자로 입력하고 저장한다.

4. `All Group`·`Ungrouped` 아래에 이름 입력란과 + 버튼을 한 줄로 표시한다.

5. 새 그룹 이름 입력란에서 Enter를 누르면 그룹을 만든다.

6. + 버튼을 누르면 그룹을 만든다.

7. 생성 입력란은 기존 Groups 톤을 유지하고 추가 버튼의 아이콘과 테두리만 밝게 표시한다.

## 13. 그룹 - 동작 메뉴와 이름 검증

1. 이름 있는 그룹의 `…` 버튼에서 고정·수정·삭제 명령을 연다.

2. 수정한 그룹 이름의 앞뒤 공백을 제거해 저장한다.

3. 수정할 그룹 이름은 최대 60자로 입력하고 저장한다.

4. 수정할 그룹 이름이 비어 있으면 저장하지 않는다.

## 14. 그룹 - 정렬 갱신

1. 새 그룹을 생성한 직후 이름 있는 그룹에 같은 정렬을 적용한다.

2. 그룹 이름을 수정한 직후 이름 있는 그룹에 같은 정렬을 적용한다.

3. 새로고침 후에도 이름 있는 그룹에 같은 정렬을 적용한다.

4. 새 그룹을 생성해도 드롭다운을 열린 상태로 유지한다.

5. 새 그룹을 생성하면 해당 그룹을 활성 그룹으로 전환한다.

## 15. 북마크 - 생성과 동기화

1. 탭 메뉴에서 북마크를 추가하면 제목과 내용을 보관한다.

2. 탭 메뉴에서 북마크를 추가하면 생성 시각을 보관한다.

3. 탭 메뉴에서 기존 북마크를 해제한다.

4. 북마크를 추가하면 탭 색상을 보관한다.

5. 북마크를 추가하면 선택한 줄 번호를 보관한다.

6. 원본 탭의 내용이 바뀌면 연결된 북마크의 제목과 내용을 갱신한다.

7. 원본 탭의 색상이 바뀌면 연결된 북마크의 탭 색상을 갱신한다.

8. 원본 탭의 줄 선택이 바뀌면 연결된 북마크의 선택한 줄 번호를 갱신한다.

## 16. 북마크 - 내용 표시

1. 북마크 내용에서 제목과 중복되는 첫 줄을 제외한다.

2. 북마크의 나머지 내용은 접지 않은 전체 내용으로 표시한다.

3. 북마크 항목에는 더보기나 접기 버튼을 표시하지 않는다.

4. 제목을 제외한 내용이 없으면 높이 30px의 빈 내용 영역을 표시한다.

## 17. 닫은 탭 - 보관 규칙

1. 내용이 11자 이상인 탭을 닫은 탭 목록에 보관한다.

2. 닫은 탭에는 닫을 당시의 그룹을 함께 기록한다.

3. 닫은 탭은 목록의 맨 위부터 최신순으로 보관한다.

4. 닫은 탭 목록은 새로고침 후에도 유지한다.

## 18. 닫은 탭 - 복원 데이터

1. 닫은 탭을 복원하면 닫을 당시의 그룹으로 전환한다.

2. 복원한 탭을 활성 탭으로 표시한다.

3. 복원한 탭은 닫은 탭 목록에서 제거한다.

4. 닫은 탭을 복원하면 내용을 유지한다.

5. 닫은 탭을 복원하면 탭 색상을 유지한다.

6. 닫은 탭을 복원하면 선택한 줄 번호를 유지한다.

## 19. 닫은 탭 - ID 충돌

1. 닫은 탭 ID가 열린 탭과 충돌하면 새 ID로 복원해 두 탭을 유지한다.

2. ID 충돌을 해소해 복원한 탭은 닫은 탭 기록에서 제거한다.

3. ID 충돌을 해소한 두 탭은 새로고침 후에도 서로 다른 ID로 유지한다.
