# 03. 그룹과 기록

> E2E: `tests/03. 그룹과 기록/`


<br>

## 01. 그룹 - 생성과 편집

1.  하단 그룹 선택 버튼을 누르면 버튼 위에 그룹 드롭다운이 열린다.

2.  PC에서 그룹을 선택하면 드롭다운을 열린 채 유지한다.

3.  모바일에서 그룹을 선택하면 드롭다운을 바로 닫는다.

4.  기본 `Ungrouped` 그룹은 삭제할 수 없다.

5.  그룹 드롭다운 너비는 PC에서 322px, 모바일에서 386.4px이며 화면이 더 좁으면 좌우 8px 여백 안으로 제한한다.

<br>

## 02. 그룹 - 삭제

1.  그룹 삭제 시 브라우저 확인창 대신 앱 팝업에 `Do you want to delete {group}?`와 실제 그룹 이름을 표시한다.

2.  삭제 팝업의 취소 버튼으로 삭제를 취소하면 그룹과 노트·북마크를 유지한다.

3.  삭제 팝업은 취소 버튼에 기본 포커스를 두고 팝업 안에서 키보드 포커스를 유지한다.

4.  삭제를 확인한 경우에만 그룹을 삭제하고 해당 그룹의 노트와 북마크를 `Ungrouped`로 옮긴다.

<br>

## 03. 그룹 - 정렬과 표시

1.  그룹 목록 첫 줄에 `All`과 `Ungrouped`를 나란히 두고 이름 있는 그룹은 그 아래에 배치한다.

2.  이름 있는 그룹은 한글로 시작하는 이름을 먼저 배치하고 같은 분류 안에서 한국어 기준 문자순으로 정렬한다.

3.  현재 그룹 이름은 PC와 모바일 모두 그룹 선택 버튼에 아이콘과 함께 표시한다. PC는 최대 너비 351px의 한 줄 말줄임으로 표시한다.

4.  긴 그룹 이름은 전체 이름을 툴팁과 접근성 라벨로 제공한다.

<br>

## 04. 그룹 - 고정과 메뉴

1.  `Pin`을 누르면 그룹을 이름 있는 그룹 목록의 맨 위로 옮기고 핀 아이콘을 표시한다.

2.  그룹 고정 상태는 브라우저에 저장하고 새로고침 후 복원한다.

3.  고정한 그룹에는 `Unpin`(`고정 해제`)을 표시한다. 고정을 해제하면 핀 아이콘을 제거하고 일반 정렬 위치로 되돌린다.

4.  Escape로 드롭다운을 닫으면 그룹 선택 버튼에 포커스를 복원한다.

5.  기본 `Ungrouped`와 가상 `All`에는 `…` 버튼을 표시하지 않는다.

<br>

## 05. 북마크

1.  북마크를 패널에서 제거할 수 있다.

2.  원본 탭이 남아 있는 북마크를 열면 해당 탭을 활성화한다.

3.  원본 탭이 없는 북마크를 열면 내용을 복원한다.

4.  원본 탭이 없는 북마크를 열면 탭 색상을 복원한다.

5.  원본 탭이 없는 북마크를 열면 선택한 줄 번호를 복원한다.

<br>

## 09. All

1.  `All`은 모든 그룹의 탭을 하나의 편집기에 모아 표시한다.

2.  `All` 선택을 저장하고 새로고침 후 복원한다.

3.  `All`의 분할 배치는 개별 그룹의 분할 배치와 별도로 관리한다.

4.  `All`에서 기존 탭의 내용을 편집하면 그 탭이 속한 그룹에 반영한다.

5.  `All`에서 기존 탭을 닫으면 그 탭이 속한 그룹에 반영한다.

6.  `All`에서 만든 새 탭은 `Ungrouped`에 추가한다.

<br>

## 10. 그룹 - 상태 격리

1.  각 그룹은 서로 다른 탭과 노트 내용을 유지한다.

2.  북마크는 생성한 그룹에만 저장한다.

3.  각 그룹은 마지막으로 활성화한 분할 편집기를 독립적으로 복원한다.

4.  각 그룹은 분할 비율을 독립적으로 저장하고 다시 전환할 때 복원한다.

<br>

## 11. 그룹 - 이름 편집

1.  이름 수정 입력에서 Enter를 누르면 앞뒤 공백을 제거해 저장한다.

2.  취소 버튼은 입력한 이름을 버리고 기존 이름을 유지한다.

3.  그룹 이름을 바꿔도 그룹 ID를 유지하고 새로고침 후 복원한다.

4.  그룹 이름을 바꿔도 그룹의 북마크를 유지하고 새로고침 후 복원한다.

<br>

## 12. 그룹 - 생성 입력과 검증

1.  새 그룹 이름의 앞뒤 공백을 제거해 저장한다.

2.  새 그룹 이름은 최대 60자로 입력하고 저장한다.

3.  새 그룹 이름 입력란에서 Enter를 누르면 그룹을 만든다.

4.  + 버튼을 누르면 그룹을 만든다.

<br>

## 13. 그룹 - 동작 메뉴와 이름 검증

1.  이름 있는 그룹의 `…` 버튼에서 고정·수정·삭제 명령을 연다.

2.  수정한 그룹 이름의 앞뒤 공백을 제거해 저장한다.

3.  수정할 그룹 이름은 최대 60자로 입력하고 저장한다.

<br>

## 14. 그룹 - 정렬 갱신

1.  새 그룹을 생성한 직후 이름 있는 그룹에 같은 정렬을 적용한다.

2.  그룹 이름을 수정한 직후 이름 있는 그룹에 같은 정렬을 적용한다.

3.  새로고침 후에도 이름 있는 그룹에 같은 정렬을 적용한다.

<br>

## 15. 북마크 - 생성과 동기화

1.  탭 메뉴에서 북마크를 추가하면 제목과 내용을 보관한다.

2.  탭 메뉴에서 기존 북마크를 해제한다.

3.  북마크를 추가하면 탭 색상을 보관한다.

4.  원본 탭의 내용이 바뀌면 연결된 북마크의 제목과 내용을 갱신한다.

5.  원본 탭의 색상이 바뀌면 연결된 북마크의 탭 색상을 갱신한다.

6.  원본 탭의 줄 선택이 바뀌면 연결된 북마크의 선택한 줄 번호를 갱신한다.

<br>

## 16. 북마크 - 내용 표시

1.  북마크 내용에서 제목과 중복되는 첫 줄을 제외한다.

2.  북마크의 나머지 내용은 접지 않은 전체 내용으로 표시한다.

3.  제목을 제외한 내용이 없으면 높이 30px의 빈 내용 영역을 표시한다.
