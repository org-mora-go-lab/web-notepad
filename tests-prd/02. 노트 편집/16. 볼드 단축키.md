# 16. 볼드 단축키

> E2E: `tests/02. 노트 편집/16. 볼드 단축키/`

1. macOS Cmd+B는 편집기에서 선택한 텍스트를 `**`로 감싸고, 같은 선택에서 다시 누르면 `**`를 제거한다.
2. 선택 영역이 없을 때 Cmd+B를 누르면 `****`를 삽입하고 두 표식 사이에 커서를 둔다. 그 상태에서 다시 누르면 빈 표식을 제거한다.
3. `**`로 감싼 텍스트 내부에 커서가 있을 때 Cmd+B를 누르면 굵게 표식을 제거하고 커서 위치를 유지한다.
4. Cmd+B는 편집기에 포커스가 있을 때만 굵게 표시를 토글하며 그룹 패널은 열지 않는다. 그룹 패널은 Option+F11로 연다.

> 이미 처리된 이벤트와 IME 조합 중인 이벤트는 가로채지 않으며, 반복 keydown은 한 번만 처리한다. 굵게 표시는 Markdown `**` 문법으로 저장하고 실행 취소 기록에 포함한다.
