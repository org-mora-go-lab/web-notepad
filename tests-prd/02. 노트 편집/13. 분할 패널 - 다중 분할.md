# 13. 분할 패널 - 다중 분할

> E2E: `tests/02. 노트 편집/13. 분할 패널 - 다중 분할/`

1.  좌우 각 열은 `Split down`으로 상하 분할하며 좌상·좌하·우상·우하 최대 4개 패널까지 확장한다.

2.  상하 구분선으로 각 패널의 높이 비율을 조정하며 20%~80% 범위로 제한한다.

3.  왼쪽과 오른쪽 열의 상하 분할 비율은 서로 독립적으로 관리한다.

4.  하단 패널의 마지막 탭을 닫으면 해당 열의 상하 분할을 해제한다.

5.  상단 패널이 비면 같은 열의 하단 패널을 상단으로 올린다.
