# 33. 들여쓰기와 텍스트 보존

> E2E: `tests/02. 노트 편집/33. 들여쓰기와 텍스트 보존/`

1. Shift Tab은 여러 겹의 앞쪽 탭에서 한 단계만 제거한다.
2. 여러 줄 내어쓰기는 공백 들여쓰기를 탭으로 오인해 제거하지 않는다.
3. 선택 끝이 다음 줄 시작이면 내어쓰기에서 다음 줄을 제외한다.
4. 줄 중간 커서 앞의 탭을 내어써도 뒤쪽 텍스트를 보존한다.
5. 내어쓰기 후 실행 취소로 원래 탭 들여쓰기를 복구한다.
6. 줄을 줄인 노트를 재방문하면 범위 밖 줄 선택만 제거한다.
7. HTML 형태로 작성한 노트는 재방문해도 실행 없이 원문을 유지한다.
8. 이모지와 결합 문자를 포함한 노트는 편집 실행 취소와 재방문에도 손실되지 않는다.
