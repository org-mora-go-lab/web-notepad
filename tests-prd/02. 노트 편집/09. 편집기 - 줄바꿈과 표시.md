# 09. 편집기 - 줄바꿈과 표시

> E2E: `tests/02. 노트 편집/09. 편집기 - 줄바꿈과 표시/`

1.  자동 줄바꿈으로 표시 줄이 늘어나면 LINE 번호도 같은 개수로 연속해서 표시한다.

2.  편집 내용을 바꾸면 새 자동 줄바꿈 결과에 맞춰 LINE 번호를 갱신한다.

3.  분할 패널의 너비를 조정하면 해당 편집기의 표시 줄과 LINE 번호를 다시 계산한다.

4.  자동 줄바꿈된 번호를 선택하면 같은 원본 줄의 모든 표시 줄을 강조한다.

5.  화면 너비가 바뀌어 자동 줄바꿈 수가 달라져도 개행 기준 줄 선택 데이터를 유지하고 같은 원본 줄의 표시 줄을 다시 강조한다.

6.  모바일 WebView에서 글자 자동 확대를 제한하고 편집기와 줄 번호가 동일한 정수 줄 높이를 사용한다. 긴 문서의 중간과 끝을 연속해서 스크롤해도 위치가 어긋나지 않고 화면 크기와 글자 비율 변경 후 재정렬한다.
