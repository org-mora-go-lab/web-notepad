# 분할 패널 - 드롭과 정리

> E2E: `tests/02. 노트 편집/21. 분할 패널 - 드롭과 정리/`

1.  우측 편집기가 비어 있으면 `Split right`를 대상 패널의 오른쪽 절반에 표시한다.

2.  `Split right`와 `Split down`을 함께 표시하면 각각 우상단과 하단 영역을 사용한다.

3.  마지막 탭을 다른 기존 패널로 옮길 때 대상에는 `Move here`만 표시한다.

4.  탭 제목을 편집기 하단으로 직접 드래그해 상하 분할한다.

5.  일반 그룹의 하단 탭은 기존 우상단 탭을 유지하고 비어 있는 우하단으로 이동한다.

6.  일반 그룹에 오른쪽 열이 없으면 하단 탭을 새 오른쪽 열의 상단으로 이동한다.

7.  일반 그룹에서 하단 탭을 기존 우상단 아래로 옮긴 복합 분할 배치는 새로고침 후 복원한다.

8.  우측의 마지막 탭은 좌하단에 `Move here`로 합치고 비어진 우측 패널을 정리한다.

9.  오른쪽 패널의 마지막 탭을 닫으면 분할 화면을 해제한다.

10.  하단 패널의 마지막 탭을 다른 패널로 옮기면 해당 열의 상하 분할을 해제한다.
