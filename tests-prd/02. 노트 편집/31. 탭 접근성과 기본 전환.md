# 31. 탭 접근성과 기본 전환

> E2E: `tests/02. 노트 편집/31. 탭 접근성과 기본 전환/`

1. 탭 모음은 Note tabs 이름의 tablist로 제공한다.
2. 기본 탭은 선택된 tab으로 표시한다.
3. 새 탭 버튼은 접근 가능한 이름과 툴팁을 제공한다.
4. 탭 색상 버튼은 대상 탭 제목을 포함한 이름을 제공한다.
5. 탭 닫기 버튼은 대상 탭 제목을 포함한 이름을 제공한다.
6. 새 탭을 만들면 `-` 제목의 새 탭이 선택 상태가 된다.
7. 탭을 전환하면 aria-selected 상태도 함께 이동한다.
8. 활성 탭을 닫으면 남은 탭 하나만 선택 상태를 가진다.
9. 탭 제목이 바뀌면 탭과 편집기의 접근성 이름을 함께 갱신한다.
10. 탭 선택 버튼은 키보드 포커스를 받을 수 있다.
