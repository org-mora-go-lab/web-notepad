# 02. 탭 - 닫기

> E2E: `tests/02. 노트 편집/02. 탭 - 닫기/`

1.  닫기 버튼으로 일반 탭을 에디터에서 숨길 수 있다.

2.  이전에 고정한 탭도 핀 표시와 고정 전용 스타일 없이 일반 닫기 버튼으로 닫을 수 있다.

3.  내용이 있는 탭을 닫기 버튼으로 닫으면 확인 없이 에디터에서만 숨기고 To Do·Doing·Done 상태를 유지하며 Closed로 이동하지 않는다.

4.  북마크된 탭을 가운데 클릭하면 확인 없이 에디터에서만 숨기고 북마크를 유지하며 Closed로 이동하지 않는다.
5.  All Group에서도 일반 그룹처럼 오른쪽 끝의 선택 탭을 닫으면 같은 패널의 바로 왼쪽 탭으로 이동한다. 패널의 마지막 탭을 닫으면 남아 있는 패널의 탭을 선택하고 원본 내용과 새로고침 후 선택 상태를 보존한다.
