# 32. 편집기 접근성과 입력 경계

> E2E: `tests/02. 노트 편집/32. 편집기 접근성과 입력 경계/`

1. 편집기는 현재 탭 제목을 포함한 접근성 이름을 제공한다.
2. 빈 편집기는 Take a note.. 안내 문구를 표시한다.
3. 편집기는 브라우저 맞춤법 검사를 비활성화한다.
4. 줄 번호 영역은 Line numbers 접근성 이름을 제공한다.
5. 각 줄 번호는 키보드 포커스를 받을 수 있는 버튼 역할로 제공한다.
6. 줄 번호에서 Enter를 누르면 해당 줄을 선택한다.
7. 선택된 줄 번호는 aria-pressed 상태를 true로 표시한다.
8. Tab 키는 편집기에 탭 문자를 삽입한다.
9. 첫 줄이 비어 있어도 다음 유효한 줄을 탭 제목으로 사용한다.
