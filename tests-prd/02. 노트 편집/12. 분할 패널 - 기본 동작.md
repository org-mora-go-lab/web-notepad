# 12. 분할 패널 - 기본 동작

> E2E: `tests/02. 노트 편집/12. 분할 패널 - 기본 동작/`

1.  탭 제목을 다른 패널의 편집기 영역에 직접 드롭해 해당 패널로 이동할 수 있다.

2.  왼쪽 패널의 탭을 `Split right` 영역에 드롭해 좌우 분할 화면을 만든다.

3.  각 패널은 자체 탭 목록과 활성 탭을 가진다.

4.  구분선을 드래그해 너비 비율을 조정하며 각 패널은 20%~80% 범위로 제한한다.

5.  오른쪽 패널의 마지막 탭을 왼쪽으로 옮기면 분할 화면을 해제한다.

6.  분할 비율은 앱 재접속 시 중앙으로 초기화한다.
