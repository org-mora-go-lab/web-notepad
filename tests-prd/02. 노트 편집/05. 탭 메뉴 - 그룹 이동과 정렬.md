# 탭 메뉴 - 그룹 이동과 정렬

> E2E: `tests/02. 노트 편집/05. 탭 메뉴 - 그룹 이동과 정렬/`

1.  PC 탭 우클릭 메뉴와 모바일 탭 더블탭 메뉴에 `Move Group`을 표시한다. 선택하면 탭의 현재 소속 그룹과 `Ungrouped`를 제외한 대상 그룹 목록을 표시한다. `All Group`에서도 `Ungrouped`는 이동 대상으로 표시하지 않는다.

2.  다른 그룹이 없으면 `Move Group`을 비활성화한다.

3.  상단 뒤로가기 버튼으로 이동 없이 기존 탭 메뉴로 돌아간다.

4.  Escape로 이동 없이 그룹 목록과 탭 메뉴를 닫는다.

5.  기본 탭 메뉴와 그룹 목록은 PC와 모바일 화면의 여백 안에 배치한다.

6.  그룹 목록은 한글로 시작하는 이름을 먼저 배치하고 한국어 기준 문자순으로 정렬한다.
