# 14. 분할 패널 - All Group

> E2E: `tests/02. 노트 편집/14. 분할 패널 - All Group/`

1.  All Group에서도 탭 제목을 드래그해 좌우 분할한다.

2.  All Group의 좌우 분할 배치는 별도로 저장해 새로고침 후 복원한다.

3.  All Group 분할은 탭 소속과 각 소속 그룹의 분할 배치를 변경하지 않는다.

4.  All Group에서도 `Split down`과 `Split right`로 최대 4분할한다.

5.  All Group의 분할 편집기 사이로 탭을 옮기고 활성 상태를 저장한다.

6.  All Group 분할 편집기의 새 탭은 현재 패널에 표시하고 `Ungrouped` 소속으로 저장한다.
