# 편집기 - 입력과 터치 동작

> E2E: `tests/02. 노트 편집/08. 편집기 - 입력과 터치 동작/`

1.  여러 줄 일반 텍스트를 편집하며 줄 번호를 표시한다.

2.  Enter는 커서 위치에 줄바꿈을 삽입한다.

3.  편집기 높이를 넘어가는 위치로 커서가 이동하면 커서가 보이도록 편집기와 줄 번호 영역을 함께 스크롤한다.

4.  한글 IME 조합 중에도 입력을 처리한다.

5.  편집기에서 Shift+Tab은 커서가 있는 줄이나 선택한 여러 줄의 앞쪽 탭 들여쓰기를 한 단계 제거하고 편집기 포커스와 선택 범위를 유지한다. 커서 바로 앞에 Tab으로 삽입한 탭 문자도 제거한다. 제거할 탭이 없으면 브라우저의 기본 역방향 포커스 이동을 유지한다.

6.  편집기를 한 번 터치하면 브라우저가 정한 접힌 커서 위치를 유지하고 문서 끝으로 재설정하지 않는다.
