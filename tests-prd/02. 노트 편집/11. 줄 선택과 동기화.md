# 줄 선택과 동기화

> E2E: `tests/02. 노트 편집/11. 줄 선택과 동기화/`

1.  Shift+클릭으로 기준 줄부터 클릭한 줄까지 범위를 선택하고, 선택한 범위를 다시 Shift+클릭하면 해제한다.

2.  Shift+클릭한 줄이 이미 선택된 연속 블록에 속하면 해당 블록 전체를 해제하고 나머지 선택 블록은 유지한다.

3.  줄 번호를 클릭하거나 키보드로 선택하면 줄 번호의 배경색과 글자색을 활성 탭 색상으로 강조한다. 선택하지 않은 줄 번호는 투명 배경으로 YouTube 테마의 중립 작업 영역(#0f0f0f)을 유지한다.

4.  선택한 줄은 노트별로 저장하고 탭을 전환해도 각 노트의 선택을 복원한다.

5.  줄 선택과 선택 해제 결과는 새로고침 후 복원한다.

6.  줄을 삽입하면 기존 선택 위치를 새 줄 번호에 맞춰 이동한다.

7.  선택한 줄을 삭제하면 해당 선택을 제거하고 남은 선택 위치를 맞춘다.

8.  그룹을 전환했다 돌아와도 노트별 줄 선택을 유지한다.

9.  탭을 분할 패널 사이로 이동해도 해당 노트의 줄 선택을 유지한다.
