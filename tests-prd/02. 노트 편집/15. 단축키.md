# 단축키

> E2E: `tests/02. 노트 편집/15. 단축키/`

1.  Alt+Tab은 활성 패널에 새 탭을 추가한다.

2.  Alt+위/아래 화살표는 같은 패널의 탭 사이를 이동한다.

3.  분할 상태의 Alt+위/아래 화살표는 패널 경계를 넘어 이동한다.

4.  Alt/Option+Backspace는 빈 활성 탭을 바로 닫는다.

5.  macOS에서 Option+F12는 활성 탭을 오른쪽 열의 상단 패널로 이동한다.

6.  macOS에서 Option+F11은 활성 탭을 왼쪽 열의 상단 패널로 이동한다.

7.  왼쪽 패널에 탭이 하나만 남으면 Option+F12 이동을 수행하지 않는다.
