# 16. 그룹 패널 단축키

> E2E: `tests/02. 노트 편집/16. 그룹 패널 단축키/`

1. macOS Cmd+B는 편집기와 그룹 생성 입력란에서 그룹 패널을 열고 닫으며 현재 노트 내용과 활성 탭을 유지한다. 브라우저 기본 동작은 차단하고 물리 키 KeyB도 인식한다.
2. Cmd+B를 길게 눌러 발생하는 반복 keydown은 추가로 패널을 전환하지 않으며 키를 놓고 다시 누르면 전환한다.
3. 일반 B, Ctrl+B와 Shift·Alt·Ctrl이 추가된 Cmd+B는 그룹 패널 단축키로 처리하지 않는다.
4. 모달 사용 가이드가 열려 있으면 Cmd+B로 뒤쪽 그룹 패널을 열지 않는다.

> 이미 처리된 이벤트와 IME 조합 중인 이벤트는 가로채지 않는다. 그룹 버튼과 동일한 토글 함수를 사용해 기존 상태 저장과 모바일 이력 동작을 유지한다.
