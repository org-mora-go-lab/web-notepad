# 28. 기기 간 동기화

> E2E: `tests/05. 화면과 설정/28. 기기 간 동기화/`

같은 카카오 사용자 ID의 개인 작업공간은 로그인 후 서버 최신 이력으로 복원하고, 초기 진입과 창 포커스·연결 복구 시 변경을 확인한다. 대기 중 주기적인 자동 조회는 수행하지 않는다. 변경 후 0.5초 저장 지연과 실패 대기열을 유지한다. 공유 그룹은 기존 멤버십과 버전 프로토콜로 동기화하며 개인 이력 복원으로 덮어쓰지 않는다.

1. PC에서 만든 그룹과 새 탭의 글을 같은 계정 모바일에서 새로고침해 복원한다.
2. 다른 기기의 화면을 다시 활성화하면 저장된 글을 가져온다.
3. 새 기기의 빈 초기 상태가 서버의 기존 글을 덮어쓰지 않는다.
4. 저장 실패 후 새로고침하면 로컬 그룹과 다른 기기의 변경을 함께 보존한다.
5. 같은 글의 동시 수정이 충돌하면 복구 탭으로 양쪽 본문을 남긴다.
6. 같은 브라우저에서 다른 계정으로 바꾸면 이전 계정의 글을 전송하지 않는다.
7. 서버 조회 실패 시 빈 상태를 업로드하지 않고 연결 복구 후 다시 읽는다.
8. 이전 버전을 기준으로 저장하면 409와 최신 이력을 반환하고 기존 글을 지킨다.
9. 서로 다른 기기에서 생성한 그룹의 탭 ID가 겹쳐도 두 글을 별도로 보존한다.

10. 로그인 후 편집 없이 대기하는 동안 개인 이력·공유 그룹·그룹알림을 주기적으로 조회하지 않는다.
