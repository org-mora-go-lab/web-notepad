# 03. 상태 표시줄 - 패널과 모바일

> E2E: `tests/05. 화면과 설정/03. 상태 표시줄 - 패널과 모바일/`

1.  PC와 모바일 하단 메뉴는 화면 하단에서 가로 스크롤 없이 모든 항목을 표시하며 각 버튼 높이는 PC에서 35px, 모바일에서 61.2px(1.2배)다. 모바일의 그룹·북마크·대시보드 아이콘은 동일한 너비의 세 영역 중앙에서 위로 3px 옮겨 푸터 상단에 가깝게 표시하며, 라벨과 버튼 위치는 유지한다.

2.  하단 메뉴의 각 항목은 연결된 메뉴·패널을 열고 활성 아이콘을 강조한다.

3.  모바일에서 그룹을 전환하면 하단 메뉴 위의 현재 그룹 이름을 즉시 동기화하고, 사이드바 버튼은 열기·닫기 용도를 접근성 이름으로 제공한다.

4.  PC 패널은 X, 모바일 패널은 Escape로 닫으며, 닫은 뒤 하단 메뉴의 활성 표시를 해제한다.

5.  모바일 UI는 화면 너비가 512px 이하일 때만 적용한다. PC에서 고정 패널 확대로 작업 영역이 512px 이하가 되면 기존 그룹 선택 UI는 유지하고 BOOKMARK·DASHBOARD 라벨만 숨겨 아이콘으로 표시하며, 작업 영역이 다시 넓어지면 두 라벨을 복원한다.
