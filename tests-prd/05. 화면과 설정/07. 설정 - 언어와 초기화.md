# 07. 설정 - 언어와 초기화

> E2E: `tests/05. 화면과 설정/07. 설정 - 언어와 초기화/`

> 설정 초기화의 기본값 복원과 저장은 13. 설정 - 초기화 상호작용의 3번에서 통합 검증한다.

1.  설정 패널의 `Tab Colors` 아래 `Language`에서 `English`·`한국어` 중 언어를 선택할 수 있으며 기본값은 English다. 각 언어 이름은 해당 언어로 표시한다.

2.  선택한 언어는 브라우저에 저장해 새로고침 후에도 유지하고 문서의 `lang` 속성에 반영한다.

3.  `Tab Colors` 제목 오른쪽에 탭 색상 초기화 버튼을 표시한다. 누르면 확인 팝업 없이 탭 색상 순서를 기본값(Gray → Indigo → Teal)으로 되돌리고 저장한다.

4.  선택한 언어는 MENU·하단 메뉴·탭 메뉴·우측 패널·팝업·검색창 안내 문구 등 화면에 표시되는 문구에 즉시 적용한다. 한국어의 기본 그룹 이름은 `모든 그룹`·`미지정 그룹`으로 표시하고 영어로 전환하면 `All Group`·`Ungrouped`로 되돌린다. 번역은 기본 그룹 ID에만 적용하며 저장된 그룹 이름과 사용자가 만든 그룹 이름은 변경하지 않는다.
