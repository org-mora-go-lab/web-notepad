# 30. My Page

> E2E: `tests/05. 화면과 설정/30. My Page/`

1. 로그인 계정 메뉴에서 별도 My Page로 이동한다. PC 본문은 로그인 이미지와 오른쪽 콘텐츠를 약 50:50으로 나누고 이미지 아래 30px 여백을 유지한다. 오른쪽 상단에는 사용자 이름과 간결한 `Kakao` 연결 표시를 두고 그 아래에 내 그룹·공유·참여·노트·북마크 5개 통계를 모두 표시한다. Workspace Sync는 두 영역 아래의 전체 너비를 채우며 캐시 프로필을 사용해도 hydration 오류 없이 표시한다.
2. 비로그인 직접 접근은 로그인 안내를 표시하고 개인 통계를 숨긴다.
3. 저장 대기 중 My Page로 이동해도 편집 내용을 서버에 저장한다.
4. 계정 로딩 실패 뒤 다시 시도하면 프로필과 통계를 복구한다.
5. 좁은 모바일에서는 로그인 이미지 영역을 콘텐츠 위에 배치하고 이미지를 영역에 맞게 채운다. 긴 이름과 통계가 가로로 넘치지 않고 페이지 내부를 스크롤한다.
6. 하단의 설정·보드·로그아웃 영역을 제거하고 상단 메모로 돌아가기만 유지한다. 작업공간 API를 사용할 수 없는 환경에서는 프로필과 5개 mock 통계를 표시한다.
7. 계정·작업공간·공유 그룹처럼 서버 데이터가 필요한 영역은 각각 응답이 준비될 때까지 기존 레이아웃 크기의 스켈레톤을 표시한다. 왼쪽 이미지 Skeleton은 이미지 영역의 위아래를 빈틈없이 채운다. 계정이 먼저 준비되면 오른쪽 프로필은 즉시 표시하고 아직 수신 중인 통계와 Workspace Sync만 스켈레톤으로 유지한다.
