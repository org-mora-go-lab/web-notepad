# 27. 로그인 전후 반응형 헤더

> E2E: `tests/05. 화면과 설정/27. 로그인 전후 반응형 헤더/`

1. 계정 영역은 헤더에서 제거하고 하단 우측 Dashboard·Login 순서에 배치한다. PC에서 로그인 전후 하단 계정 영역의 오른쪽 끝과 탭 추가 버튼의 위치가 유지된다.
2. 모바일에서 긴 카카오 이름은 말줄임되고 프로필 이미지는 28.8px 고정 크기로 표시되며 가로 넘침이 없다.
3. 모바일에서 로그아웃한 뒤 로그인 영역이 원래 위치와 크기로 돌아온다.

4. 초기 로그인 상태를 확인하는 동안 계정 영역에 스켈레톤과 로딩 상태를 표시하고 확인 후에도 영역의 크기를 유지한다.
