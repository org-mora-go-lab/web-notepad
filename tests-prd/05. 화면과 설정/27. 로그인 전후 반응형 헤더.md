# 27. 로그인 전후 반응형 헤더

> E2E: `tests/05. 화면과 설정/27. 로그인 전후 반응형 헤더/`

1. 계정 영역은 헤더에서 제거하고 PC 푸터의 MENU·DASHBOARD·계정 핵심 진입점을 25px 간격의 한 묶음으로 중앙 배치한다. 로그인 전후에도 핵심 진입점 묶음의 중앙과 탭 추가 버튼 위치를 유지한다.
2. 모바일에서 긴 카카오 이름은 말줄임되고 프로필 이미지는 28.8px 고정 크기로 표시되며 가로 넘침이 없다.
3. 모바일에서 로그아웃한 뒤 로그인 영역이 원래 위치와 크기로 돌아온다.

4. 초기 로그인 상태를 확인하는 동안 계정 영역에 스켈레톤과 로딩 상태를 표시하고 확인 후에도 높이와 핵심 진입점 묶음의 중앙 배치를 유지한다.
