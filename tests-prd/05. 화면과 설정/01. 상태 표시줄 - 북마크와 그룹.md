# 01. 상태 표시줄 - 북마크와 그룹

> E2E: `tests/05. 화면과 설정/01. 상태 표시줄 - 북마크와 그룹/`

> 더보기 드롭다운의 표면과 항목 스타일은 [그룹 동작 메뉴](<../03. 그룹과 기록/11. 그룹 - 이름과 동작 메뉴.md>)의 공통 표시 규칙을 따른다.

1.  그룹 사이드바 맨 아래는 위쪽 가로 구분선 아래 GROUP | MORE 버튼을 한 줄에 놓고 버튼 사이에 세로 구분선을 표시한다. PC와 모바일 모두 MORE 아이콘 오른쪽에 라벨을 표시한다. GROUP 드롭다운은 All Group·Ungrouped만, MORE 드롭다운은 GUIDE·SEARCH·BOOKMARK·SETTINGS만 순서대로 제공하며 한 번에 하나만 연다. MORE 아이콘은 25px이고 하단 DASHBOARD 아이콘은 PC 25px, 모바일 29.8px다.

2.  그룹 사이드바 MORE의 BOOKMARK 명령은 그룹 사이드바를 닫고 북마크 팝업을 연다. MORE 버튼에는 북마크 개수·상태 표시를 포함하지 않는다.

3.  PC의 하단 왼쪽 그룹 버튼에는 그룹 아이콘과 현재 그룹 이름만 표시하고 `MENU` 텍스트는 표시하지 않는다. 모바일은 버튼에 그룹 아이콘과 `MENU`(한국어 설정에서는 `메뉴`) 라벨만 표시하고, 하단 메뉴 바로 위의 높이 38px인 별도 영역에 현재 그룹 이름을 18px 글자와 위·아래 1px padding으로 표시하며 그룹명 왼쪽에 그룹 아이콘을 7px 간격으로 배치한다.

4.  GROUP 메뉴의 All Group·Ungrouped 항목에는 그룹 동작 아이콘을 표시하지 않는다.

5.  PC에서 일반 그룹명을 우클릭해 연 드롭다운에는 고정·공유·수정·삭제만 표시하고 Bookmark를 표시하지 않으며 그룹 선택을 바꾸지 않는다.

6.  오늘 생성되거나 변경된 그룹이 있으면 GROUP 아이콘에 Bookmark와 같은 붉은 점을 표시하고, 오래된 그룹만 있으면 표시하지 않는다.

7.  그룹 사이드바 MORE의 마지막 SETTINGS 명령은 그룹 사이드바를 닫고 설정 패널을 연다.
