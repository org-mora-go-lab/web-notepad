# 01. 상태 표시줄 - 북마크와 그룹

> E2E: `tests/05. 화면과 설정/01. 상태 표시줄 - 북마크와 그룹/`

> 더보기 드롭다운의 표면과 항목 스타일은 [그룹 동작 메뉴](<../03. 그룹과 기록/11. 그룹 - 이름과 동작 메뉴.md>)의 공통 표시 규칙을 따른다.

1.  하단 더보기 버튼은 PC에서 아이콘 오른쪽에, 모바일에서 아이콘 아래에 라벨을 표시하고 드롭다운에 GUIDE·SEARCH·Bookmark·BOARD를 제공한다. 하단 더보기·DASHBOARD 아이콘은 가로·세로 PC 25px, 모바일 29.8px로 표시한다.

2.  하단 더보기의 Bookmark 명령은 현재 그룹의 북마크 팝업을 열되, 이미 열린 그룹 패널은 닫지 않는다. 더보기 버튼에는 북마크 개수·상태 표시를 포함하지 않는다.

3.  PC의 하단 왼쪽 그룹 버튼에는 그룹 아이콘과 현재 그룹 이름만 표시하고 `GROUP` 텍스트는 표시하지 않는다. 모바일은 버튼에 그룹 아이콘과 `GROUP` 라벨만 표시하고, 하단 메뉴 바로 위의 높이 38px인 별도 영역에 현재 그룹 이름을 18px 글자와 위·아래 1px padding으로 표시하며 그룹명 왼쪽에 그룹 아이콘을 7px 간격으로 배치한다.

4.  Bookmark 진입점이 없는 All Group·Ungrouped 행에는 우측 세로 점 세 개 동작 아이콘을 표시하지 않는다.

5.  PC에서 일반 그룹명을 우클릭해 연 드롭다운에는 고정·공유·수정·삭제만 표시하고 Bookmark를 표시하지 않으며 그룹 선택을 바꾸지 않는다.

6.  오늘 생성되거나 변경된 그룹이 있으면 GROUP 아이콘에 Bookmark와 같은 붉은 점을 표시하고, 오래된 그룹만 있으면 표시하지 않는다.
