# 01. 상태 표시줄 - 북마크와 그룹

> E2E: `tests/05. 화면과 설정/01. 상태 표시줄 - 북마크와 그룹/`

1.  BOOKMARK는 PC에서 아이콘 오른쪽에, 모바일에서 아이콘 아래에 라벨을 표시한다. 하단 BOOKMARK·DASHBOARD 아이콘은 가로·세로 PC 25px, 모바일 29.8px로 표시한다.

2.  BOOKMARK에는 북마크 개수를 표시하지 않고, 현재 그룹에 오늘 생성된 북마크가 있으면 붉은 점을 표시한다.

3.  PC와 모바일의 사이드바 버튼에는 아이콘과 `SIDEBAR` 라벨을 표시한다. 모바일에서는 다른 하단 명령처럼 아이콘 아래 라벨을 표시하고, 하단 메뉴 바로 위의 높이 38px인 별도 영역에 현재 그룹 이름을 18px 글자와 위·아래 1px padding으로 표시하며 그룹명 왼쪽에 그룹 아이콘을 7px 간격으로 배치한다.

4.  오늘 생성·갱신된 북마크가 없으면 붉은 점을 표시하지 않는다. 이후 연결된 탭의 내용을 수정하면 붉은 점을 다시 표시한다.

5.  오래된 북마크와 연결된 탭의 색상을 오늘 변경하면 BOOKMARK에 붉은 점을 표시한다.

6.  오늘 생성되거나 변경된 그룹이 있으면 SIDEBAR 아이콘에 BOOKMARK와 같은 붉은 점을 표시하고, 오래된 그룹만 있으면 표시하지 않는다.
