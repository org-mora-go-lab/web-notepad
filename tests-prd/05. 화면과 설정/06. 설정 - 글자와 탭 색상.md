# 06. 설정 - 글자와 탭 색상

> E2E: `tests/05. 화면과 설정/06. 설정 - 글자와 탭 색상/`

1. 그룹 사이드바 MORE의 Settings / 설정을 선택하면 사이드바를 닫고 설정 패널을 연다. 로그인 계정 메뉴에는 설정 진입점을 표시하지 않는다.

2. 설정 패널의 `Font Size`에서 전체 폰트 크기를 80%·90%·100%·110%·120%·130% 중에서 선택할 수 있으며 기본값은 90%다.

3. 설정 패널의 `Tab Colors`에서 탭 색상 순서의 1·2·3번째 To Do·Ready·Doing 색상을 기본 9가지 색상(Gray·Red·Orange·Yellow·Green·Teal·Indigo·Purple·Pink) 중에서 선택할 수 있으며 기본값은 Gray → Orange → Indigo이다. 색상 안내 칩에는 상태 이름을 붙이지 않고 색상 이름만 표시한다.

4. 탭 색상 아이콘을 클릭하면 설정한 1 → 2 → 3번째 색상 순서로 순환하고 새 탭은 1번째 색상으로 시작한다. 순서에 없는 색상의 탭은 클릭 시 1번째 색상으로 바뀐다.

5. 설정한 폰트 크기와 탭 색상 순서는 브라우저에 저장해 새로고침 후에도 유지한다. 110%에서 에디터는 2px 축소를 적용한 18.9px로 표시한다.
