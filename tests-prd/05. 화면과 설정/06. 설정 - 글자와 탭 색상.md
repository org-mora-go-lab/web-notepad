# 06. 설정 - 글자와 탭 색상

> E2E: `tests/05. 화면과 설정/06. 설정 - 글자와 탭 색상/`

1.  헤더 `MENU`의 `SETTINGS`(설정)를 선택하면 메뉴를 닫고 우측 패널 영역에 설정 패널을 연다.

2.  설정 패널의 `Font Size`에서 전체 폰트 크기를 80%·90%·100%·110%·120%·130% 중에서 선택할 수 있으며 기본값은 90%다.

3.  설정 패널의 `Tab Colors`에서 탭 색상 순서의 1·2·3번째 색상을 기본 9가지 색상(Gray·Red·Orange·Yellow·Green·Teal·Indigo·Purple·Pink) 중에서 선택할 수 있으며 기본값은 Gray → Indigo → Teal이다.

4.  탭 색상 아이콘을 클릭하면 설정한 1 → 2 → 3번째 색상 순서로 순환하고 새 탭은 1번째 색상으로 시작한다. 순서에 없는 색상의 탭은 클릭 시 1번째 색상으로 바뀐다.

5.  설정한 폰트 크기와 탭 색상 순서는 브라우저에 저장해 새로고침 후에도 유지한다.
