# 05. 테마

> E2E: `tests/05. 화면과 설정/05. 테마/`

1.  `SETTINGS` 패널의 `FONT SIZE` 위에 `THEME`와 좌우로 이동하는 토글 버튼을 표시하고, DARK와 LIGHT를 전환할 수 있으며 기본값은 DARK다. PC와 모바일에서 원형이 오른쪽에 있을 때의 우측 내부 여백은 왼쪽에 있을 때의 좌측 내부 여백과 같아야 한다.

2.  YouTube 테마는 DARK의 #0f0f0f와 LIGHT의 흰색 작업 영역, 중립 표면과 빨간 강조색을 사용한다. LIGHT의 편집기 글자는 #0f0f0f, 하단 메뉴는 흰색, 그룹 메뉴는 #f2f2f2다. 메뉴·카드·설정·보드·My Page까지 둥근 컨트롤과 산세리프 UI를 일관되게 적용하고 편집기·줄 번호의 고정폭 글꼴 및 상태별 색상은 유지한다.

3.  선택한 테마는 노트와 별도로 브라우저에 저장하고 새로고침·재접속 시 복원한다.

4.  다른 브라우저 탭에서 테마 설정을 변경하면 현재 열린 앱에도 반영한다.

5.  테마 저장소를 사용할 수 없어도 현재 화면의 테마 전환은 동작한다.
