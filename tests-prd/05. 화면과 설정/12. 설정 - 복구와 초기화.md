# 설정 - 복구와 초기화

> E2E: `tests/05. 화면과 설정/12. 설정 - 복구와 초기화/`

1.  잘못된 폰트 크기 저장값은 기본값 90%로 복원한다.

2.  중복되거나 잘못된 탭 색상 순서 저장값은 Gray → Orange → Indigo로 복원한다.

3.  설정 초기화 버튼을 누르면 `Reset settings` 제목과 안내 문구를 표시하고 Cancel 버튼에 기본 포커스를 둔다.

4.  설정 초기화 확인 팝업을 Escape로 닫으면 현재 설정을 유지하고 설정 패널로 돌아간다.

5.  설정 초기화로 폰트 크기(90%)·탭 색상 순서(Gray → Orange → Indigo)·언어(English)·패널 슬라이드 효과(Off)·패널 위치(Right)를 기본값으로 되돌리고 화면과 브라우저 저장소에 함께 반영한다.

6.  탭 색상만 초기화하면 비기본 폰트 크기와 언어를 그대로 유지한다.

> 초기화 검증 환경: 원격 이력이 없는 세션에서 현재 브라우저의 초기화를 검증한다. 로그인 후 서버 이력 복원은 기기 간 동기화 요구사항에서 별도로 검증한다.
