# 설정 - 복구와 초기화

> E2E: `tests/05. 화면과 설정/12. 설정 - 복구와 초기화/`

1.  잘못된 폰트 크기 저장값은 기본값 100%로 복원한다.

2.  중복되거나 잘못된 탭 색상 순서 저장값은 Gray → Indigo → Teal로 복원한다.

3.  설정 초기화 버튼을 누르면 `Reset settings` 제목과 안내 문구를 표시하고 Cancel 버튼에 기본 포커스를 둔다.

4.  설정 초기화 확인 팝업을 Escape로 닫으면 현재 설정을 유지하고 설정 패널로 돌아간다.

5.  설정 초기화로 폰트 크기(100%)·탭 색상 순서(Gray → Indigo → Teal)·언어(English)·패널 슬라이드 효과(Off)·패널 위치(Right)를 기본값으로 되돌리고 화면과 브라우저 저장소에 함께 반영한다.

6.  탭 색상만 초기화하면 비기본 폰트 크기와 언어를 그대로 유지한다.

7.  앞 순번에서 사용 중인 탭 색상은 뒤 순번에서 키보드로도 선택할 수 없다.

8.  설정 패널의 전체 데이터 삭제는 확인 팝업에서 재확인한 뒤 메모·그룹·북마크·닫은 탭과 설정·테마·패널 저장값을 모두 삭제하고 기본 작업공간으로 다시 연다. 모바일에서도 팝업 액션 버튼의 아이콘과 문구를 한 줄로 중앙 정렬한다.
