# 22. 설정 폼 접근성과 저장

> E2E: `tests/05. 화면과 설정/22. 설정 폼 접근성과 저장/`

1. Font Size 설정은 제목으로 이름이 지정된 radiogroup이다.
2. Font Size는 여섯 가지 선택지를 제공하고 기본 100%를 선택한다.
3. Language 설정은 두 언어를 각 언어 표기로 제공한다.
4. English와 한국어 선택지는 올바른 lang 속성을 가진다.
5. Panel Slide는 On과 Off를 제공하고 기본 Off를 선택한다.
6. Panel Position은 Left와 Right를 제공하고 기본 Right를 선택한다.
7. 글자 크기 변경을 새로고침 후 복원한다.
8. 패널 슬라이드 변경을 새로고침 후 복원한다.
9. 패널 위치 변경을 새로고침 후 복원한다.
10. 설정 초기화 버튼은 접근 가능한 이름과 툴팁을 제공한다.
