# 설정 - 패널과 즉시 적용

> E2E: `tests/05. 화면과 설정/08. 설정 - 패널과 즉시 적용/`

1.  설정 패널의 `Language` 아래 `Panel Slide`에서 사이드 패널 슬라이드 효과를 `On`·`Off` 중 선택할 수 있으며 기본값은 Off다.

2.  Tab Colors에서 순번의 색상을 바꾸면 열린 탭의 이전 색상을 같은 순번의 새 색상으로 바꾸고 대시보드의 To Do·Ready·Doing 상태를 유지한다.

3.  `Panel Slide` 아래 `Panel Position`에서 Left·Right(한국어 왼쪽·오른쪽)를 선택한다. 기본값은 Right이며 선택한 위치를 모든 사이드 패널에 즉시 적용한다.

4.  `Panel Slide` 선택은 브라우저에 저장해 새로고침 후에도 유지한다.

5.  탭 색상 순서를 초기화하면 열린 탭·북마크·닫은 탭 중 To Do·Ready·Doing의 색상을 같은 순번의 기본 색상으로 바꾸고 Note·Done과 대시보드 상태를 유지한다.

6.  선택한 폰트 비율은 탭·편집기·하단 메뉴·우측 패널에 즉시 적용한다. 탭 타이틀은 비율 적용 후 3px 줄이고 편집기는 2px 줄이며 PC 기본 90%에서 각각 10.5px·15.1px, 120%에서 15px·20.8px로 표시한다.

7.  선택한 `Panel Slide` 값은 모바일 설정 패널의 전환 시간에 즉시 반영한다.
