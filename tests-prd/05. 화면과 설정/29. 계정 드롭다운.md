# 29. 계정 드롭다운

> E2E: `tests/05. 화면과 설정/29. 계정 드롭다운/`

1. 로그인한 계정의 이미지·이름을 클릭하면 바로 아래에 My Page·Alarm·Settings·Logout (한국어: 내 페이지·알람·설정·로그아웃)을 순서대로 표시하고 PC와 모바일 화면 안에 배치한다.
2. 보드는 계정 메뉴에서 제외하고 더보기에서 공유 그룹 게시판을 연다.
3. 계정 메뉴의 Alarm을 열고 Escape로 닫으면 계정 버튼으로 포커스를 돌려준다.
4. 계정 메뉴는 방향키로 항목을 탐색하며 Escape와 바깥 클릭으로 닫는다.

5. 계정 메뉴의 Alarm 콘텐츠는 PC와 모바일에서 우측 상단에 배치한다.
