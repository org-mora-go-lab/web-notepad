# 29. 계정 드롭다운

> E2E: `tests/05. 화면과 설정/29. 계정 드롭다운/`

1. 하단의 로그인한 계정 이미지·이름을 클릭하면 버튼 위에 Logout·My Page·Board (한국어: 로그아웃·내 페이지·게시판)를 순서대로 표시하고 Settings는 제외하며 PC와 모바일 화면 안에 배치한다.
2. Board는 더보기에서 제거하고 계정 메뉴의 마지막 항목에서 공유 그룹 게시판 목록을 연다. 상세 화면에서 다시 Board를 선택해도 상세 상태를 제거하고 항상 목록으로 이동한다.
3. 계정의 Alarm 진입점·팝업과 클라이언트 알람 조회를 제거한다.
4. 계정 메뉴는 방향키로 항목을 탐색하며 Escape와 바깥 클릭으로 닫는다.
