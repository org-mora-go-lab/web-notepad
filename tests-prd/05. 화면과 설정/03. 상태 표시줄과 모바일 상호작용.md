# 상태 표시줄과 모바일 상호작용

> E2E: `tests/05. 화면과 설정/03. 상태 표시줄과 모바일 상호작용/`

1. PC와 모바일 하단 메뉴는 그룹·대시보드·계정 순서로 가로 스크롤 없이 표시하며 버튼 높이는 PC 35px, 모바일 61.2px다. 모바일 푸터 전체 높이는 81.8px이고 세 항목의 글자는 12px이며, 로그인 사용자 이미지는 30.8px 정사각형으로 표시한다. 모바일 푸터의 아이콘 버튼을 탭하면 유튜브와 같은 짧은 원형 클릭 피드백을 아이콘 중심에 기존 범위의 1.2배로 표시하되, 푸터 밖 아이콘과 스와이프에는 표시하지 않는다. 그룹은 좌측에 유지하고 PC의 나머지 항목은 우측에 배치한다. 모바일은 동일한 너비의 세 영역을 사용하며 로그인 전후에도 영역을 유지한다.

2. 하단 메뉴의 각 항목은 연결된 메뉴·패널을 열고 활성 아이콘을 강조한다. 그룹 동작 드롭다운의 북마크는 해당 그룹의 북마크 팝업을 연다.

3. 모바일에서 그룹을 전환하면 하단 메뉴 위의 현재 그룹 이름을 즉시 동기화하고, 사이드바 버튼은 열기·닫기 용도를 접근성 이름으로 제공한다.

4. PC 패널은 X, 모바일 패널은 Escape로 닫으며, 닫은 뒤 하단 메뉴의 활성 표시를 해제한다.

5. 모바일 UI는 화면 너비가 512px 이하일 때만 적용한다. PC에서 고정 패널 확대로 작업 영역이 512px 이하가 되면 기존 그룹 선택 UI는 유지하고 DASHBOARD 라벨을 숨겨 아이콘으로 표시하며, 작업 영역이 다시 넓어지면 라벨을 복원한다.

6. PC와 모바일에서 메뉴·버튼·상태 표시 등 UI 문구는 텍스트 선택을 막는다. 입력란·메모 편집기·검색 및 닫은 탭의 본문 미리보기는 입력과 복사를 위해 텍스트 선택을 유지한다.

7. 모바일 메인 편집기가 보이고 탭이 여러 개 열려 있으면 푸터에서만 왼쪽으로 스와이프해 다음 탭, 오른쪽으로 스와이프해 이전 탭으로 순환 이동하며 에디터에 방향별 전환 효과를 표시한다. 연속 스와이프는 매 입력 시점의 최신 활성 탭을 기준으로 빠짐없이 순환하고, 전환 뒤 에디터에 포커스를 주거나 키보드를 열지 않는다. 편집기 내부 스와이프, 세로 이동과 짧은 터치는 탭을 전환하지 않는다. 대시보드·메뉴 패널이 열린 동안에는 푸터 전환을 하지 않는다.

8. 모바일 푸터를 스와이프한 직후 다른 푸터 아이콘의 별도 click 이벤트가 발생하면 추가 입력 없이 즉시 해당 화면을 연다. 스와이프에서 브라우저가 시작 요소에 생성한 합성 클릭만 실행하지 않고, 다른 아이콘의 click이나 그 다음 실제 포인터 입력은 차단하지 않는다.

> PC와 모션 줄이기 설정에서는 클릭 강조를 표시하지 않는다. 비활성 버튼·텍스트만 있는 버튼에는 적용하지 않으며 스크롤만 할 때는 발생하지 않는다.
