# 상태 표시줄과 모바일 상호작용

> E2E: `tests/05. 화면과 설정/03. 상태 표시줄과 모바일 상호작용/`

1. PC와 모바일 하단 메뉴는 그룹·대시보드·계정 순서로 가로 스크롤 없이 표시하며 버튼 높이는 PC 35px, 모바일 61.2px다. 그룹은 좌측에 유지하고 PC의 나머지 항목은 우측에 배치한다. 모바일은 동일한 너비의 세 영역을 사용하며 로그인 전후에도 영역을 유지한다.

2. 하단 메뉴의 각 항목은 연결된 메뉴·패널을 열고 활성 아이콘을 강조한다. 그룹 동작 드롭다운의 북마크는 해당 그룹의 북마크 팝업을 연다.

3. 모바일에서 그룹을 전환하면 하단 메뉴 위의 현재 그룹 이름을 즉시 동기화하고, 사이드바 버튼은 열기·닫기 용도를 접근성 이름으로 제공한다.

4. PC 패널은 X, 모바일 패널은 Escape로 닫으며, 닫은 뒤 하단 메뉴의 활성 표시를 해제한다.

5. 모바일 UI는 화면 너비가 512px 이하일 때만 적용한다. PC에서 고정 패널 확대로 작업 영역이 512px 이하가 되면 기존 그룹 선택 UI는 유지하고 DASHBOARD 라벨을 숨겨 아이콘으로 표시하며, 작업 영역이 다시 넓어지면 라벨을 복원한다.

6. PC와 모바일에서 메뉴·버튼·상태 표시 등 UI 문구는 텍스트 선택을 막는다. 입력란·메모 편집기·검색 및 닫은 탭의 본문 미리보기는 입력과 복사를 위해 텍스트 선택을 유지한다.

7. 모바일에서 아이콘 버튼을 누르면 유튜브 아이콘 버튼처럼 아이콘 중심에 반투명한 원형 배경을 표시하고 180ms 동안 부드럽게 사라진다. 배경은 테두리·그라데이션·크기 확산 없이 테마의 글자색을 14% 불투명도로 사용하며 지름은 아이콘 크기보다 16px 크고 최소 40px이다. 효과는 클릭을 가로막지 않고 기존 버튼 기능을 실행하며 종료 후 제거한다.

> PC와 모션 줄이기 설정에서는 클릭 강조를 표시하지 않는다. 비활성 버튼·텍스트만 있는 버튼에는 적용하지 않으며 스크롤만 할 때는 발생하지 않는다.

8.  PC의 버튼·메뉴 행·텍스트 링크와 주변 클릭 영역은 기본 마우스 커서를 사용하고, 화면에 보이는 SVG 또는 프로필 이미지 아이콘 위에 hover했을 때만 pointer 커서를 표시한다. 크기 조절과 드래그처럼 동작을 설명하는 전용 커서는 유지한다.

9.  PC·모바일에서 문서 바깥 스크롤을 막고 긴 노트는 에디터 내부에서 스크롤한다.

10. PC에서 하단 그룹·대시보드 버튼, 로그인 계정 이미지·이름 버튼, 사이드바 GROUP·MORE 버튼을 hover하면 버튼 전체에 같은 옅은 회색 배경과 3px 모서리를 표시하고 배경을 위아래 4px·좌우 6px 확장한다. 텍스트 위로 이동해도 같은 효과를 유지하며 아이콘이나 원형 프로필 이미지 자체에는 별도 사각형 배경을 표시하지 않는다.
