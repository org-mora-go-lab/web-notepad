# 메뉴와 가이드

> E2E: `tests/05. 화면과 설정/04. 메뉴와 가이드/`

1.  탭 줄 우측 상단에는 탭 목록과 겹치지 않는 메뉴 아이콘을 표시한다. 메뉴 버튼의 오른쪽 여백은 푸터와 같게 한다(PC 26px, 모바일 21px). 메뉴를 열면 `GUIDE`, `SETTINGS`, `SEARCH`, 카카오 로그인을 표시한다.

2.  User Guide의 첫 번째 1/11 `Keyboard shortcuts` 설명에 있는 `SHORTCUT` 진입점을 선택하면 기존 단축키 패널을 열고 가이드와 헤더 메뉴를 닫는다.

3.  헤더 `MENU`의 `GUIDE`를 선택하면 `User Guide` 팝업을 연다.

4.  헤더 메뉴에는 GUIDE·SETTINGS·SEARCH를 순서대로 표시하며 Tab 키로 탐색할 수 있다.

5.  `SHORTCUT` 패널은 편집 실행 취소 `Cmd + Z`와 다시 실행 `Cmd + Shift + Z`를 안내한다. 한 동작에 단축키가 두 개 이상이면 설명 오른쪽에서 각 키 조합을 한 줄씩 세로로 쌓아 오른쪽 정렬하고, 설명은 첫 키 조합과 나란히 표시한다.

> 표시 규칙: 가이드 Previous·Next 버튼의 텍스트와 아이콘은 같은 세로 중심선에 정렬한다. 이 세부 정렬만을 위한 별도 E2E는 두지 않는다.

6.  헤더 `MENU`에서 `SETTINGS`를 선택하면 메뉴를 닫고 설정 패널을 연다.

7.  사용 가이드 팝업은 Escape로 닫는다.

> 2단계 이상에서 닫은 사용 가이드를 다시 열면 1단계부터 표시한다.

> 사용자 가이드 팝업 바깥의 배경을 클릭하면 팝업을 닫는다.

8.  PC와 모바일 헤더 메뉴는 GUIDE·SETTINGS·SEARCH·카카오 로그인을 표시한다. 별도 SHORTCUT과 테마 항목은 표시하지 않으며 가이드는 1/11부터 시작한다.

> 사용 가이드 팝업을 처음 열면 `Next` 버튼에 포커스를 둔다.
