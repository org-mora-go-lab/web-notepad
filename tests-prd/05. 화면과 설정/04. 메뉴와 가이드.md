# 메뉴와 가이드

> E2E: `tests/05. 화면과 설정/04. 메뉴와 가이드/`

1.  PC와 모바일의 탭 줄 우측 상단에는 탭 목록과 겹치지 않는 로그인 아이콘과 `LOGIN` 문구를 표시한다. 아이콘과 텍스트 묶음을 로그인 영역의 가로·세로 정중앙에 배치하고 오른쪽 바깥 여백 없이 화면 끝에 맞춘다. 인증 후에는 프로필 이미지와 사용자 이름을 표시한다. 하단 더보기에는 `GUIDE`, `SETTINGS`, `SEARCH`, `Bookmark`, `BOARD`, `Group notifications`를 표시하고 로그인·단축키·테마 항목은 표시하지 않는다.

2. PC User Guide의 첫 번째 1/11 `Keyboard shortcuts` 설명에 있는 `SHORTCUT` 진입점을 선택하면 기존 단축키 패널을 열고 가이드와 하단 더보기를 닫는다.

3. 하단 더보기의 `GUIDE`를 선택하면 `User Guide` 팝업을 첫 단계부터 연다. PC는 단축키 안내를 포함한 11단계다.

4.  하단 더보기에는 GUIDE·SETTINGS·SEARCH·Bookmark·BOARD·Group notifications를 순서대로 표시하며 Tab 키로 탐색할 수 있다.

5.  `SHORTCUT` 패널은 편집 실행 취소 `Cmd + Z`와 다시 실행 `Cmd + Shift + Z`를 안내한다. 한 동작에 단축키가 두 개 이상이면 설명 오른쪽에서 각 키 조합을 한 줄씩 세로로 쌓아 오른쪽 정렬하고, 설명은 첫 키 조합과 나란히 표시한다.

> 표시 규칙: 가이드 Previous·Next 버튼의 텍스트와 아이콘은 같은 세로 중심선에 정렬한다. 이 세부 정렬만을 위한 별도 E2E는 두지 않는다.

6.  사용 가이드 팝업은 Escape로 닫는다.

7. 모바일 가이드는 단축키 안내 단계와 SHORTCUT 진입점을 제외한 10단계로 구성하고 `Write notes`부터 표시한다. 모바일 화면에는 단축키 패널을 여는 버튼을 표시하지 않으며 마지막 단계의 닫기까지 이동할 수 있다.

> 2단계 이상에서 닫은 사용 가이드를 다시 열면 1단계부터 표시한다.

> 사용자 가이드 팝업 바깥의 배경을 클릭하면 팝업을 닫는다.

> 사용 가이드 팝업을 처음 열면 `Next` 버튼에 포커스를 둔다.

8. PC 단축키 패널은 영어와 한국어에서 Cmd+B 볼드, Option+F11 그룹, Option+F12 대시보드 토글을 안내한다.

9. PC·모바일의 영어·한국어 탭 메뉴 가이드는 북마크와 그룹 이동을 안내하며 탭 고정 기능을 소개하지 않는다.
