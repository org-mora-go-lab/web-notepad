# 26. Turso 변경 이력

> E2E: `tests/05. 화면과 설정/26. Turso 변경 이력/`

1. 로그인 후 그룹과 글을 연속 변경하면 마지막 변경에서 0.25초 뒤 한 건의 최신 이력으로 저장한다. 저장 요청을 전송하는 동안 수정한 탭 상단 선에 왼쪽에서 오른쪽으로 흐르는 반짝임을 표시하고 대기 중과 완료 후에는 정지하며 우측 하단 상태 영역은 표시하지 않는다.
2. 노트 상태를 변경하면 Turso 이력의 스냅샷에 해당 상태를 저장한다.
3. 로그인하지 않은 요청은 이력 조회와 저장을 허용하지 않는다.
4. 저장 실패 후 대기 중인 변경을 유지하고 자동 재시도한다.
5. 저장 전 새로고침해도 대기 중인 변경을 복구해 저장한다.
6. 움직임 줄이기 환경에서는 저장 중 탭 상단 선의 반짝임을 정지한다.
7. 탭 본문은 공백 제외 3자부터 저장하고 2자 이하로 줄어들면 DB 스냅샷에서 제거한다.
8. 탭을 닫으면 저장 대기 중이던 본문도 DB 스냅샷에서 제거한다.
9. 로그인 사용자의 첫 진입은 최신 DB 동기화가 끝날 때까지 skeleton을 표시한다.
