# 24. 로그인 상태와 노트 보존

> E2E: `tests/05. 화면과 설정/24. 로그인 상태와 노트 보존/`

1. 서명 세션으로 접속하면 별도 로그아웃 아이콘 없이 닉네임을 기존 크기의 1.2배로 표시하고 계정 영역의 드롭다운을 열어 로그아웃할 수 있다.
2. 프로필 이미지가 없는 계정은 기존 크기의 1.2배인 사용자 아이콘을 표시한다.
3. 프로필 이미지가 있는 계정은 기존 크기의 1.2배인 실제 이미지를 대체 아이콘 없이 표시한다.
4. 로그아웃 후 새로고침해도 로그인 링크를 유지한다.
5. 세션 조회 네트워크 실패 후에도 로그인 진입점을 다시 활성화한다.
6. 로그아웃 서버 오류는 계정 표시를 보존하고 재시도를 허용한다.
