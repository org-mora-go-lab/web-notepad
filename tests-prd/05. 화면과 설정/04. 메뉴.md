# 04. 메뉴

> E2E: `tests/05. 화면과 설정/04. 메뉴/`

1.  탭 줄 우측 상단에는 문구 없는 검색 아이콘만 표시하고 메뉴 아이콘은 표시하지 않는다. 검색 버튼은 탭 목록과 겹치지 않으며 오른쪽 여백은 푸터 대시보드 영역과 같게 한다(PC 26px, 모바일 21px). 검색 아이콘은 가로·세로 22px로 표시한다.

2.  User Guide의 첫 번째 1/11 `Keyboard shortcuts` 설명에 있는 `SHORTCUT` 진입점을 선택하면 기존 단축키 패널을 열고 가이드와 사이드바를 닫는다.

3.  그룹 사이드바 `MENU`의 `GUIDE`를 선택하면 `User Guide` 팝업을 연다.

4.  그룹 사이드바에는 SETTINGS·GUIDE를 GROUP 위에 순서대로 표시하며 Tab 키로 탐색할 수 있다.

5.  `SHORTCUT` 패널은 편집 실행 취소 `Cmd + Z`와 다시 실행 `Cmd + Shift + Z`를 안내한다. 한 동작에 단축키가 두 개 이상이면 설명 오른쪽에서 각 키 조합을 한 줄씩 세로로 쌓아 오른쪽 정렬하고, 설명은 첫 키 조합과 나란히 표시한다.
