# 04. 메뉴

> E2E: `tests/05. 화면과 설정/04. 메뉴/`

1.  탭 줄 우측 상단에 문구 없는 가로 세 줄 메뉴 아이콘을 표시하고 바로 왼쪽에 검색 아이콘을 배치하며, 두 버튼은 탭 목록과 겹치지 않는다. 메뉴 버튼 영역의 오른쪽 여백은 푸터 대시보드 영역의 오른쪽 여백과 같게 한다(PC 26px, 모바일 21px). MENU 드롭다운과 푸터에는 SEARCH를 표시하지 않는다. 검색 아이콘은 가로·세로 22px, 메뉴 아이콘은 PC(641px 이상) 20px, 중간 너비(513~640px) 24px, 모바일 28.4px로 표시한다.

2.  PC에서 드롭다운의 `SHORTCUT`을 선택하면 기존 단축키 패널을 열고 드롭다운을 닫는다.

3.  드롭다운의 `GUIDE`를 선택하면 드롭다운을 닫고 `User Guide` 팝업을 연다.

4.  `MENU` 드롭다운은 위·아래 방향키·Home·End로 SHORTCUT부터 GUIDE까지 모든 항목을 탐색할 수 있다.

5.  `SHORTCUT` 패널은 편집 실행 취소 `Cmd + Z`와 다시 실행 `Cmd + Shift + Z`를 안내한다. 한 동작에 단축키가 두 개 이상이면 설명 오른쪽에서 각 키 조합을 한 줄씩 세로로 쌓아 오른쪽 정렬하고, 설명은 첫 키 조합과 나란히 표시한다.
