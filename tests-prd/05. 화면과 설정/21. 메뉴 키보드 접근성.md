# 21. 메뉴 키보드 접근성

> E2E: `tests/05. 화면과 설정/21. 메뉴 키보드 접근성/`

1. PC 헤더에는 카카오 로그인 버튼을 표시한다.
2. 모바일 헤더에도 카카오 로그인 버튼을 표시한다.
3. 하단 더보기의 검색 버튼은 검색 팝업을 제어한다.
4. 검색 버튼은 dialog 팝업임을 알린다.
5. 검색 버튼은 키보드 Tab 순서에 포함한다.
6. 검색 버튼을 Enter로 실행하면 검색 팝업을 연다.
7. 검색 팝업이 닫혀 있으면 검색 버튼의 펼침 상태는 false다.
8. 검색을 선택하면 더보기 드롭다운을 닫고 검색 팝업을 연다.
9. Escape로 검색 팝업을 닫으면 하단 더보기 진입점으로 포커스를 되돌린다.
10. 헤더는 카카오 로그인을 제공하고 하단 더보기는 GUIDE·SETTINGS·SEARCH 항목을 제공한다.
