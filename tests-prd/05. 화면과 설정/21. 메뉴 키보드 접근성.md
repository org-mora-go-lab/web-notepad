# 21. 메뉴 키보드 접근성

> E2E: `tests/05. 화면과 설정/21. 메뉴 키보드 접근성/`

1. PC 헤더에는 MENU 버튼을 표시하지 않는다.
2. 모바일 헤더에도 MENU 버튼을 표시하지 않는다.
3. 헤더의 검색 버튼은 검색 팝업을 제어한다.
4. 검색 버튼은 dialog 팝업임을 알린다.
5. 검색 버튼은 키보드 Tab 순서에 포함한다.
6. 검색 버튼을 Enter로 실행하면 검색 팝업을 연다.
7. 검색 팝업이 닫혀 있으면 검색 버튼의 펼침 상태는 false다.
8. 검색 팝업이 열리면 검색 버튼의 펼침 상태는 true다.
9. Escape로 검색 팝업을 닫으면 펼침 상태를 false로 되돌린다.
10. 헤더 도구 영역에는 검색 버튼 하나만 제공한다.
