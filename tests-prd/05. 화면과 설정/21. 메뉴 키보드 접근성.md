# 21. 메뉴 키보드 접근성

> E2E: `tests/05. 화면과 설정/21. 메뉴 키보드 접근성/`

1. MENU 명령은 menu 팝업 제어 대상과 펼침 상태를 제공한다.
2. 열린 메뉴는 MENU 이름의 menu 역할로 제공한다.
3. 메뉴를 열면 첫 번째 THEME 항목에 포커스를 둔다.
4. Escape로 메뉴를 닫으면 MENU 명령으로 포커스를 복원한다.
5. ArrowDown은 다음 메뉴 항목으로 포커스를 이동한다.
6. ArrowUp은 첫 항목에서 마지막 항목으로 순환한다.
7. Home은 첫 번째 메뉴 항목으로 포커스를 이동한다.
8. End는 마지막 메뉴 항목으로 포커스를 이동한다.
9. Tab으로 메뉴를 벗어나면 메뉴를 닫는다.
10. 메뉴에는 그룹 이동 항목과 separator를 제공하지 않는다.
