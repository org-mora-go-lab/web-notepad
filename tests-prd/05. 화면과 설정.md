# 05. 화면과 설정

> E2E: `tests/05. 화면과 설정/`


<br>

## 01. 상태 표시줄 - 북마크와 그룹

1.  BOOKMARK는 PC에서 아이콘 오른쪽에, 모바일에서 아이콘 아래에 라벨을 표시한다.

2.  BOOKMARK에는 북마크 개수를 표시하지 않고, 현재 그룹에 오늘 생성된 북마크가 있으면 붉은 점을 표시한다.

3.  PC의 그룹 선택 버튼에는 아이콘과 현재 그룹 이름을 12px 간격으로 표시한다. 모바일에서는 다른 하단 명령과 같이 아이콘 아래 `GROUP` 라벨을 표시하고, 하단 메뉴 바로 위의 높이 38px인 별도 영역에 현재 그룹 이름을 18px 글자와 위·아래 1px padding으로 표시한다.

4.  오늘 생성·갱신된 북마크가 없으면 붉은 점을 표시하지 않는다. 이후 연결된 탭의 내용을 수정하면 붉은 점을 다시 표시한다.

5.  오래된 북마크와 연결된 탭의 색상을 오늘 변경하면 BOOKMARK에 붉은 점을 표시한다.

6.  오늘 생성되거나 변경된 그룹이 있으면 GROUP 아이콘에 BOOKMARK와 같은 붉은 점을 표시하고, 오래된 그룹만 있으면 표시하지 않는다.

<br>

## 03. 상태 표시줄 - 패널과 모바일

1.  PC와 모바일 하단 메뉴는 화면 하단에서 가로 스크롤 없이 모든 항목을 표시하며 각 버튼 높이는 PC에서 35px, 모바일에서 61.2px(1.2배)다. 모바일의 그룹·북마크·대시보드 아이콘은 동일한 너비의 세 영역 중앙에서 위로 3px 옮겨 푸터 상단에 가깝게 표시하며, 라벨과 버튼 위치는 유지한다.

2.  하단 메뉴의 각 항목은 연결된 메뉴·패널을 열고 활성 아이콘을 강조한다.

3.  모바일에서 그룹을 전환하면 하단 메뉴 위의 현재 그룹 이름과 그룹 선택 버튼의 접근성 라벨을 즉시 동기화한다.

4.  미고정 패널은 Escape로 닫으며, 닫은 뒤 하단 메뉴의 활성 표시를 해제한다.

5.  모바일 UI는 화면 너비가 512px 이하일 때만 적용한다. PC에서 고정 패널 확대로 작업 영역이 512px 이하가 되면 기존 그룹 선택 UI는 유지하고 BOOKMARK·DASHBOARD 라벨만 숨겨 아이콘으로 표시하며, 작업 영역이 다시 넓어지면 두 라벨을 복원한다.

<br>

## 04. 메뉴

1.  탭 줄 우측 상단에 문구 없는 가로 세 줄 메뉴 아이콘을 표시하고 바로 왼쪽에 검색 아이콘을 배치하며, 두 버튼은 탭 목록과 겹치지 않는다. 검색 아이콘은 가로·세로 22px, 메뉴 아이콘은 PC(641px 이상) 20px, 중간 너비(513~640px) 24px, 모바일 28.4px로 표시한다.

2.  PC에서 드롭다운의 `SHORTCUT`을 선택하면 기존 단축키 패널을 열고 드롭다운을 닫는다.

3.  드롭다운의 `GUIDE`를 선택하면 드롭다운을 닫고 `User Guide` 팝업을 연다.

4.  `MENU` 드롭다운은 위·아래 방향키·Home·End로 THEME부터 Ungrouped까지 모든 항목을 탐색할 수 있다.

5.  `SHORTCUT` 패널은 편집 실행 취소 `Cmd + Z`와 다시 실행 `Cmd + Shift + Z`를 안내한다. 한 동작에 단축키가 두 개 이상이면 설명 오른쪽에서 각 키 조합을 한 줄씩 세로로 쌓아 오른쪽 정렬하고, 설명은 첫 키 조합과 나란히 표시한다.

<br>

## 05. 테마

1.  `MENU`의 `THEME` 우측에 좌우로 이동하는 토글 버튼을 표시하고, 토글해도 메뉴를 닫지 않은 채 DARK와 LIGHT를 전환할 수 있으며 기본값은 DARK다. PC와 모바일에서 원형이 오른쪽에 있을 때의 우측 내부 여백은 왼쪽에 있을 때의 좌측 내부 여백과 같아야 한다.

2.  LIGHT는 밝은 중립 배경과 짙은 글자를 사용하고 작업 영역·편집기·하단 메뉴·그룹 메뉴를 일관된 색상으로 표시한다.

3.  선택한 테마는 노트와 별도로 브라우저에 저장하고 새로고침·재접속 시 복원한다.

4.  다른 브라우저 탭에서 테마 설정을 변경하면 현재 열린 앱에도 반영한다.

5.  테마 저장소를 사용할 수 없어도 현재 화면의 테마 전환은 동작한다.

<br>

## 06. 설정 - 글자와 탭 색상

1.  `MENU`의 `SETTINGS`(설정)를 선택하면 드롭다운을 닫고 우측 패널 영역에 설정 패널을 연다.

2.  설정 패널의 `Font Size`에서 전체 폰트 크기를 80%·90%·100%·110%·120%·130% 중에서 선택할 수 있으며 기본값은 100%다.

3.  설정 패널의 `Tab Colors`에서 탭 색상 순서의 1·2·3번째 색상을 기본 9가지 색상(Gray·Red·Orange·Yellow·Green·Teal·Indigo·Purple·Pink) 중에서 선택할 수 있으며 기본값은 Gray → Green → Purple이다.

4.  탭 색상 아이콘을 클릭하면 설정한 1 → 2 → 3번째 색상 순서로 순환하고 새 탭은 1번째 색상으로 시작한다. 순서에 없는 색상의 탭은 클릭 시 1번째 색상으로 바뀐다.

5.  설정한 폰트 크기와 탭 색상 순서는 브라우저에 저장해 새로고침 후에도 유지한다.

<br>

## 07. 설정 - 언어와 초기화

> 설정 초기화의 기본값 복원과 저장은 13. 설정 - 초기화 상호작용의 3번에서 통합 검증한다.

1.  설정 패널의 `Tab Colors` 아래 `Language`에서 `English`·`한국어` 중 언어를 선택할 수 있으며 기본값은 English다. 각 언어 이름은 해당 언어로 표시한다.

2.  선택한 언어는 브라우저에 저장해 새로고침 후에도 유지하고 문서의 `lang` 속성에 반영한다.

3.  `Tab Colors` 제목 오른쪽에 탭 색상 초기화 버튼을 표시한다. 누르면 확인 팝업 없이 탭 색상 순서를 기본값(Gray → Green → Purple)으로 되돌리고 저장한다.

4.  선택한 언어는 MENU·하단 메뉴·탭 메뉴·우측 패널·팝업·검색창 안내 문구 등 화면에 표시되는 문구에 즉시 적용한다. 한국어의 기본 그룹 이름은 `모든 그룹`·`미지정 그룹`으로 표시하고 영어로 전환하면 `All Group`·`Ungrouped`로 되돌린다. 번역은 기본 그룹 ID에만 적용하며 저장된 그룹 이름과 사용자가 만든 그룹 이름은 변경하지 않는다.

<br>

## 08. 설정 - 패널과 색상 동기화

1.  설정 패널의 `Language` 아래 `Panel Slide`에서 사이드 패널 슬라이드 효과를 `On`·`Off` 중 선택할 수 있으며 기본값은 Off다.

2.  Tab Colors에서 순번의 색상을 바꾸면 열린 탭의 이전 색상을 같은 순번의 새 색상으로 바꾸고 대시보드의 Todo·Doing·Done 상태를 유지한다.

3.  `Panel Slide` 아래 `Panel Position`에서 Left·Right(한국어 왼쪽·오른쪽)를 선택한다. 기본값은 Right이며 선택한 위치를 모든 사이드 패널에 즉시 적용한다.

4.  `Panel Slide` 선택은 브라우저에 저장해 새로고침 후에도 유지한다.

5.  탭 색상 순서를 초기화하면 열린 탭·북마크·닫은 탭의 색상을 같은 순번의 기본 색상으로 바꾸고 대시보드 상태를 유지한다.

<br>

## 09. 설정 - 언어별 접근성

1.  언어를 바꾸면 탭 목록·새 탭·탭 색상·탭 닫기와 편집기·줄 번호의 접근성 이름을 같은 언어로 즉시 바꾼다.

2.  언어를 바꾸면 설정 패널의 이름·크기 조절·고정·초기화·닫기 조작의 접근성 이름을 같은 언어로 즉시 바꾼다.

<br>

## 10. 메뉴 - 닫기와 가이드

> 표시 규칙: 가이드 Previous·Next 버튼의 텍스트와 아이콘은 같은 세로 중심선에 정렬한다. 이 세부 정렬만을 위한 별도 E2E는 두지 않는다.

1.  `MENU` 드롭다운에서 Tab을 누르면 드롭다운을 닫는다.

2.  사용 가이드 팝업은 Escape로 닫는다.

3.  2단계 이상에서 닫은 사용 가이드를 다시 열면 1단계부터 표시한다.

4.  모바일 `MENU` 드롭다운에는 `SHORTCUT`을 표시하지 않는다.

5.  사용자 가이드 팝업 바깥의 배경을 클릭하면 팝업을 닫는다.

<br>

## 12. 설정 - 저장값 복구와 예외

1.  잘못된 폰트 크기 저장값은 기본값 100%로 복원한다.

2.  중복되거나 잘못된 탭 색상 순서 저장값은 Gray → Green → Purple로 복원한다.

<br>

## 13. 설정 - 초기화 상호작용

1.  설정 초기화 버튼을 누르면 `Reset settings` 제목과 안내 문구를 표시하고 Cancel 버튼에 기본 포커스를 둔다.

2.  설정 초기화 확인 팝업을 Escape로 닫으면 현재 설정을 유지하고 설정 패널로 돌아간다.

3.  설정 초기화로 폰트 크기(100%)·탭 색상 순서(Gray → Green → Purple)·언어(English)·패널 슬라이드 효과(Off)·패널 위치(Right)를 기본값으로 되돌리고 화면과 브라우저 저장소에 함께 반영한다.

4.  탭 색상만 초기화하면 비기본 폰트 크기와 언어를 그대로 유지한다.

5.  앞 순번에서 사용 중인 탭 색상은 뒤 순번에서 키보드로도 선택할 수 없다.

6.  설정 패널의 전체 데이터 삭제는 확인 팝업에서 재확인한 뒤 메모·그룹·북마크·닫은 탭과 설정·테마·패널 저장값을 모두 삭제하고 기본 작업공간으로 다시 연다. 모바일에서도 팝업 액션 버튼의 아이콘과 문구를 한 줄로 중앙 정렬한다.

<br>

## 15. 설정 - 패널 접근성

1.  언어를 바꾸면 북마크 패널의 이름과 닫기 조작의 접근성 이름을 같은 언어로 즉시 바꾼다.

2.  언어를 바꾸면 전체 검색 팝업과 검색 입력·닫기 조작의 접근성 이름을 같은 언어로 즉시 바꾼다.

<br>

## 17. 메뉴 - 항목 순서와 가이드 초기 상태

1.  드롭다운은 PC에서 THEME·SHORTCUT·SETTINGS·GUIDE, 모바일에서 THEME·SETTINGS·GUIDE 순서로 표시한 뒤 GUIDE 아래에 구분선을 두고 `All Group`·`Ungrouped`를 공통으로 표시한다.

2.  MENU 드롭다운과 푸터에는 SEARCH를 표시하지 않고 헤더의 메뉴 아이콘 왼쪽에 검색 아이콘을 표시한다.

3.  사용 가이드 팝업을 처음 열면 `Next` 버튼에 포커스를 둔다.

<br>

## 18. 설정 - 즉시 적용

1.  선택한 폰트 비율은 탭·편집기·하단 메뉴·우측 패널의 글자 크기에 즉시 적용한다.

2.  선택한 `Panel Slide` 값은 현재 설정 패널의 전환 시간에 즉시 반영한다.
