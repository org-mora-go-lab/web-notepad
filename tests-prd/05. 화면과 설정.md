# 05. 화면과 설정

> E2E: `tests/05. 화면과 설정/`

## 01. 상태 표시줄 - 북마크와 그룹

1.  BOOKMARK는 PC에서 아이콘 오른쪽에, 모바일에서 아이콘 아래에 라벨을 표시한다.

2.  BOOKMARK에는 북마크 개수를 표시하지 않고, 현재 그룹에 오늘 생성된 북마크가 있으면 붉은 점을 표시한다.

3.  PC와 모바일 모두 하단 메뉴의 그룹 선택 버튼에 아이콘과 실제 현재 그룹 이름을 표시하며 그룹 개수 배지나 별도의 그룹 이름 표시를 두지 않는다.

4.  맨 왼쪽에 아이콘과 현재 그룹 이름의 그룹 선택 버튼을 표시하고 누르면 버튼 위쪽에 그룹 드롭다운을 연다.

5. PC와 모바일 어디에도 CLOSED 명령을 표시하지 않고, SHORTCUT은 PC MENU에서만 제공한다.

6.  오늘 생성·갱신된 북마크가 없으면 붉은 점을 표시하지 않는다. 이후 연결된 탭의 내용을 수정하면 붉은 점을 다시 표시한다.

7. BOOKMARK의 붉은 점은 아이콘 우측 상단에서 오른쪽으로 5px, 위로 3px 벗어난 위치에 표시하고 라벨과 겹치지 않는다.

8. 오래된 북마크와 연결된 탭의 색상을 오늘 변경하면 BOOKMARK에 붉은 점을 표시한다.

9. 오래된 북마크와 연결된 탭의 줄 선택을 오늘 변경하면 BOOKMARK에 붉은 점을 표시한다.

## 03. 상태 표시줄 - 패널과 모바일

1. PC와 모바일 하단 메뉴는 화면 하단에서 가로 스크롤 없이 모든 항목을 표시하며 각 버튼 높이는 PC에서 35px, 모바일에서 61.2px(1.2배)다.

2. 모바일에서 별도 현재 그룹 표시줄을 두지 않고 하단 그룹 선택 버튼에 현재 그룹명을 표시한다.

3. 모바일 그룹명은 17px 한 줄로 표시하고 길면 말줄임하며, 전체 이름을 툴팁과 접근성 라벨로 제공한다.

4. 하단 메뉴의 각 항목은 연결된 메뉴나 패널을 열고 활성 아이콘을 강조한다.

5. PC에서 고정된 열린 BOOKMARK·DASHBOARD 아이콘을 다시 클릭하면 해당 패널을 닫고 활성 표시를 해제한다.

6. 미고정 패널은 패널 닫기 버튼으로 닫으며, 닫은 뒤 하단 메뉴의 활성 표시를 해제한다.

7. 모바일에서 그룹을 전환하면 하단 그룹 선택 버튼의 이름과 접근성 라벨을 즉시 동기화한다.

8. 모바일에서 새로고침해도 하단 그룹 선택 버튼에 저장된 현재 그룹 이름을 표시한다.

9. PC와 모바일의 미고정 사이드 패널은 화면 전체 높이를 채우고 하단 메뉴 위를 덮어 표시한다.

10. 미고정 패널은 Escape로 닫으며, 닫은 뒤 하단 메뉴의 활성 표시를 해제한다.

## 04. 메뉴

1.  탭 줄 우측 상단에 가로 세 줄 메뉴 아이콘의 `MENU` 버튼을 표시하고 탭 목록과 겹치지 않는다.

2. PC `MENU` 버튼은 너비 112px, 아이콘 18px, 산세리프 라벨 15px로 표시하고 드롭다운은 너비 208px·모서리 6px를 사용한다.

3.  모바일 `MENU` 버튼은 너비 45px·아이콘 26.4px로 표시하고 라벨을 숨기며 드롭다운은 너비 240px로 표시한다.

4.  드롭다운 항목은 PC에서 아이콘 18px·글자 15px, 모바일에서 아이콘 21.6px·글자 18px로 표시한다.

5.  PC에서 드롭다운의 `SHORTCUT`을 선택하면 기존 단축키 패널을 열고 드롭다운을 닫는다.

6.  `MENU` 드롭다운은 바깥 영역을 클릭하면 닫는다.

7.  드롭다운의 `GUIDE`를 선택하면 드롭다운을 닫고 `User Guide` 팝업을 연다.

8. 사용 가이드 팝업의 진행 표시 오른쪽에 텍스트 없는 X 버튼을 표시하고, 누르면 팝업을 닫는다.

9. `MENU` 드롭다운은 위·아래 방향키·Home·End로 항목을 탐색할 수 있다.

10. 사용 가이드 팝업의 `Previous`·`Next` 버튼으로 단계를 이동한다. 10단계에서는 Next 버튼을 같은 위치의 `Close` 버튼으로 바꾸고, 누르면 팝업을 닫는다.

## 05. 테마

1. `MENU`의 `THEME` 우측에 좌우로 이동하는 토글 버튼을 표시하고, 토글해도 메뉴를 닫지 않은 채 DARK와 LIGHT를 전환할 수 있으며 기본값은 DARK다.

2.  LIGHT는 밝은 중립 배경과 짙은 글자를 사용하고 작업 영역·편집기·하단 메뉴·그룹 메뉴를 일관된 색상으로 표시한다.

3.  LIGHT의 그레이·그린 탭은 일반 배경을 10%, 활성 배경을 22% 불투명도로 표시한다.

4.  선택한 테마는 노트와 별도로 브라우저에 저장하고 새로고침·재접속 시 복원한다.

5.  다른 브라우저 탭에서 테마 설정을 변경하면 현재 열린 앱에도 반영한다.

6.  LIGHT에서 선택한 라인 번호와 편집기의 선택 줄 영역은 같은 배경색을 사용한다. 흰 바탕에서도 보이도록 그린 `#258356`·그레이 `#68776e`는 15%, 레드 `#b84b45`는 13% 불투명도로 표시한다.

7. LIGHT에서 그레이·그린 탭 아이콘 강조색은 각각 `#68776e`, `#258356`을 사용한다. 레드 탭 배경과 DARK 탭 색상은 기존 색상을 유지한다.

8. DARK에서 선택한 라인 번호와 편집기 선택 줄 영역은 기존 선택 색상을 유지한다.

9. 저장된 테마 값이 잘못되었으면 DARK로 복원한다.

10. 테마 저장소를 사용할 수 없어도 현재 화면의 테마 전환은 동작한다.

## 06. 설정 - 글자와 탭 색상

1.  `MENU`의 `SETTINGS`(설정)를 선택하면 드롭다운을 닫고 우측 패널 영역에 설정 패널을 연다.

2.  설정 패널의 `Font Size`에서 전체 폰트 크기를 80%·90%·100%·110%·120%·130% 중에서 선택할 수 있으며 기본값은 100%다.

3.  설정 패널의 `Tab Colors`에서 탭 색상 순서의 1·2·3번째 색상을 기본 9가지 색상(Gray·Red·Orange·Yellow·Green·Teal·Indigo·Purple·Pink) 중에서 선택할 수 있으며 기본값은 Gray → Green → Purple다.

4.  탭 색상 아이콘을 클릭하면 설정한 1 → 2 → 3번째 색상 순서로 순환하고 새 탭은 1번째 색상으로 시작한다. 순서에 없는 색상의 탭은 클릭 시 1번째 색상으로 바뀐다.

5.  앞 순번에서 뒤 순번이 사용 중인 색상을 선택하면 두 순번의 색상을 서로 바꿔 탭 색상 순서에 중복 색상이 없도록 유지한다.

6.  설정한 폰트 크기와 탭 색상 순서는 브라우저에 저장해 새로고침 후에도 유지한다.

7. 선택한 폰트 비율에 맞춰 편집기 줄 높이와 줄 번호 높이를 함께 바꾼다. 100% 기준 줄 높이는 PC 35px, 모바일 39px다.

8. 탭 색상 설명은 `New tabs start with the first color.` 아래 10px 간격을 두고 현재 순서를 괄호 없이 표시한다.

9. 탭 색상 이름과 설정 패널 문구는 선택한 언어로 표시하고, 1·2·3번째 색상 선택 행 앞에는 순번 숫자를 표시하지 않는다.

10. 순서 안내의 각 색상 이름은 위아래 2px·좌우 5px 안쪽 여백과 해당 탭 색상 배경을 사용한다. 테마에 맞는 글자색과 PC 15px·모바일 18px 크기로 표시한다.

## 07. 설정 - 언어와 초기화

1.  설정 패널의 `Tab Colors` 아래 `Language`에서 `English`·`한국어` 중 언어를 선택할 수 있으며 기본값은 English다. 각 언어 이름은 해당 언어로 표시한다.

2.  선택한 언어는 브라우저에 저장해 새로고침 후에도 유지하고 문서의 `lang` 속성에 반영한다.

3.  설정 패널 헤더의 고정 버튼 왼쪽에 설정 초기화 버튼을 표시해 초기화·고정·닫기 순서로 배치한다.

4. `Tab Colors` 제목 오른쪽에 탭 색상 초기화 버튼을 표시한다. 누르면 확인 팝업 없이 탭 색상 순서를 기본값(Gray → Green → Purple)으로 되돌리고 저장한다.

5. 탭 색상 초기화 버튼 오른쪽에 셔플 버튼을 표시한다. 누르면 확인 팝업 없이 기본 9가지 색상 중 서로 다른 3가지를 무작위로 골라 탭 색상 순서에 적용하고 저장하며, 결과는 항상 현재 순서와 달라진다.

6. 앞 순번에서 선택된 색상은 뒤 순번에서 불투명도 25%로 흐리게 표시하고 클릭으로 선택되지 않게 비활성화한다.

7. 확인 팝업의 Cancel을 누르면 현재 설정을 유지하고 설정 패널로 돌아간다.

8. 확인 팝업에서 `Reset`을 선택하면 폰트 크기(100%)·탭 색상 순서(Gray → Green → Purple)·언어(English)·패널 슬라이드 효과(Off)·패널 위치(Right)를 기본값으로 되돌린다.

9. 선택한 언어는 MENU·하단 메뉴·탭 메뉴·우측 패널·팝업·검색창 안내 문구 등 화면에 표시되는 문구에 즉시 적용한다.

10. 저장된 언어 값이 잘못되었으면 English로 복원하고 문서의 `lang` 속성에도 반영한다.

## 08. 설정 - 패널과 색상 동기화

1. 설정 패널의 `Language` 아래 `Panel Slide`에서 사이드 패널 슬라이드 효과를 `On`·`Off` 중 선택할 수 있으며 기본값은 Off다.

2. PC에서 `Tab Colors` 오른쪽의 탭 색상 초기화·셔플 버튼은 기존 크기의 1.2배인 28.8px, 아이콘은 15.6px로 표시한다. 모바일도 28.8px·15.6px로 표시한다.

3. Tab Colors에서 순번의 색상을 바꾸면 열린 탭의 이전 색상을 같은 순번의 새 색상으로 바꾸고 대시보드의 Todo·WIP·Closed 상태를 유지한다.

4. `Panel Slide` 아래 `Panel Position`에서 Left·Right(한국어 왼쪽·오른쪽)를 선택한다. 기본값은 Right이며 선택한 위치를 모든 사이드 패널에 즉시 적용한다.

5. `Panel Slide` 선택은 브라우저에 저장해 새로고침 후에도 유지한다.

6. 저장된 `Panel Slide` 값이 잘못되었으면 Off로 복원한다.

7. `Panel Position` 선택은 브라우저에 저장하고 새로고침 후에도 유지한다.

8. PC에서 패널을 고정하면 선택한 쪽에 편집 공간을 확보하고 크기 조절 손잡이를 편집기 쪽에 표시한다.

9. 탭 색상 순서를 초기화하면 열린 탭·북마크·닫은 탭의 색상을 같은 순번의 기본 색상으로 바꾸고 대시보드 상태를 유지한다.

10. 탭 색상 순서를 셔플하면 열린 탭·북마크·닫은 탭의 색상을 같은 순번의 새 색상으로 바꾸고 대시보드 상태를 유지한다.

## 09. 설정 - 언어별 접근성

1. 언어를 바꾸면 탭 목록·새 탭·탭 색상·탭 닫기와 편집기·줄 번호의 접근성 이름을 같은 언어로 즉시 바꾼다.

2. 언어를 바꾸면 하단 메뉴의 현재 그룹·북마크 갱신 표시와 그룹 메뉴 입력·생성 조작의 접근성 이름을 같은 언어로 즉시 바꾼다.

3. 언어를 바꾸면 MENU 버튼·드롭다운과 항목의 접근성 이름을 같은 언어로 즉시 바꾼다.

4. 언어를 바꾸면 설정 패널의 이름·크기 조절·고정·초기화·닫기 조작의 접근성 이름을 같은 언어로 즉시 바꾼다.

5. English로 되돌리면 MENU와 설정 패널의 영문 접근성 이름을 복원한다.

## 10. 메뉴 - 닫기와 가이드

1. `MENU` 드롭다운에서 Tab을 누르면 드롭다운을 닫는다.

2. 사용 가이드 팝업은 Escape로 닫는다.

3. 2단계 이상에서 닫은 사용 가이드를 다시 열면 1단계부터 표시한다.

4. `MENU` 드롭다운을 Escape로 닫으면 `MENU` 버튼에 포커스를 복원한다.

5. 한국어에서 `MENU`의 `사용 가이드`를 선택하면 `사용 가이드` 팝업을 1단계부터 열고 `이전` 버튼을 비활성화한다.

6. 한국어 사용 가이드는 `이전`·`다음`으로 이동하고 10단계에서 `닫기`로 종료한다.

7. 모바일 `MENU` 드롭다운에는 `SHORTCUT`을 표시하지 않는다.

## 12. 설정 - 저장값 복구와 예외

1. 잘못된 폰트 크기 저장값은 기본값 100%로 복원한다.

2. 중복되거나 잘못된 탭 색상 순서 저장값은 Gray → Green → Purple로 복원한다.

3. 폰트 비율을 바꾸면 설정 초기화 확인 팝업의 글자 크기에도 즉시 적용한다.

4. 현재 설정 순서에 없는 색상의 탭은 색상 아이콘을 누르면 1번째 색상으로 바뀐다.

## 13. 설정 - 초기화 상호작용

1. 설정 초기화 버튼을 누르면 `Reset settings` 제목과 안내 문구를 표시하고 Cancel 버튼에 기본 포커스를 둔다.

2. 설정 초기화 확인 팝업의 닫기 버튼을 누르면 현재 설정을 유지하고 설정 패널로 돌아간다.

3. 설정 초기화 확인 팝업을 Escape로 닫으면 현재 설정을 유지하고 설정 패널로 돌아간다.

4. 설정 초기화로 되돌린 모든 기본값을 브라우저에 저장한다.

5. 설정 초기화를 완료한 뒤에도 설정 패널을 열린 상태로 유지한다.

6. 탭 색상만 초기화하면 비기본 폰트 크기와 언어를 그대로 유지한다.

7. 탭 색상을 셔플하면 비기본 폰트 크기와 언어를 그대로 유지한다.

8. 앞 순번에서 사용 중인 탭 색상은 뒤 순번에서 키보드로도 선택할 수 없다.

## 15. 설정 - 패널 접근성

1. 언어를 바꾸면 북마크 패널의 이름과 닫기 조작의 접근성 이름을 같은 언어로 즉시 바꾼다.

2. 언어를 바꾸면 대시보드 패널의 이름과 닫기 조작의 접근성 이름을 같은 언어로 즉시 바꾼다.

3. 언어를 바꾸면 대시보드 카드의 북마크 표시 접근성 이름을 같은 언어로 즉시 바꾼다.

4. 언어를 바꾼 뒤에도 메뉴에 닫은 탭 항목을 표시하지 않는다.

5. 언어를 바꾸면 전체 검색 패널과 검색 입력·닫기 조작의 접근성 이름을 같은 언어로 즉시 바꾼다.

6. 언어를 바꾸면 단축키 패널의 이름과 닫기 조작의 접근성 이름을 같은 언어로 즉시 바꾼다.

## 17. 메뉴 - 항목 순서와 가이드 초기 상태

1. 드롭다운은 PC에서 THEME·SHORTCUT·SETTINGS·GUIDE·SEARCH, 모바일에서 THEME·SETTINGS·GUIDE·SEARCH 순서로 표시한다.

2. SEARCH는 우측 상단 MENU의 마지막 항목으로 표시한다.

3. 사용 가이드 팝업을 열면 `1 / 10`처럼 현재 단계와 전체 단계를 표시한다.

4. 사용 가이드 팝업을 처음 열면 `Previous` 버튼을 비활성화한다.

5. 사용 가이드 팝업을 처음 열면 `Next` 버튼에 포커스를 둔다.

## 18. 설정 - 즉시 적용

1. 선택한 폰트 비율은 탭·편집기·하단 메뉴·우측 패널의 글자 크기에 즉시 적용한다.

2. 선택한 `Panel Slide` 값은 현재 설정 패널의 전환 시간에 즉시 반영한다.
