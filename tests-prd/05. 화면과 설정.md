# 05. 화면과 설정

> E2E: `tests/05. 화면과 설정/`


## 01. 상태 표시줄 - 북마크와 그룹

1.  BOOKMARK는 PC에서 아이콘 오른쪽에, 모바일에서 아이콘 아래에 라벨을 표시한다.

2.  BOOKMARK에는 북마크 개수를 표시하지 않고, 현재 그룹에 오늘 생성된 북마크가 있으면 붉은 점을 표시한다.

3.  PC의 그룹 선택 버튼에는 아이콘과 현재 그룹 이름을 표시한다. 모바일에서는 다른 하단 명령과 같이 아이콘 아래 `GROUP` 라벨을 표시하고, 하단 메뉴 바로 위의 별도 영역에 현재 그룹 이름을 표시한다.

4.  오늘 생성·갱신된 북마크가 없으면 붉은 점을 표시하지 않는다. 이후 연결된 탭의 내용을 수정하면 붉은 점을 다시 표시한다.

5.  오래된 북마크와 연결된 탭의 색상을 오늘 변경하면 BOOKMARK에 붉은 점을 표시한다.

## 03. 상태 표시줄 - 패널과 모바일

1.  PC와 모바일 하단 메뉴는 화면 하단에서 가로 스크롤 없이 모든 항목을 표시하며 각 버튼 높이는 PC에서 35px, 모바일에서 61.2px(1.2배)다.

2.  하단 메뉴의 각 항목은 연결된 메뉴나 패널을 열고 활성 아이콘을 강조한다.

3.  모바일에서 그룹을 전환하면 하단 메뉴 위의 현재 그룹 이름과 그룹 선택 버튼의 접근성 라벨을 즉시 동기화한다.

4.  미고정 패널은 Escape로 닫으며, 닫은 뒤 하단 메뉴의 활성 표시를 해제한다.

## 04. 메뉴

1.  탭 줄 우측 상단에 가로 세 줄 메뉴 아이콘의 `MENU` 버튼을 표시하고 탭 목록과 겹치지 않는다.

2.  PC에서 드롭다운의 `SHORTCUT`을 선택하면 기존 단축키 패널을 열고 드롭다운을 닫는다.

3.  드롭다운의 `GUIDE`를 선택하면 드롭다운을 닫고 `User Guide` 팝업을 연다.

4.  `MENU` 드롭다운은 위·아래 방향키·Home·End로 항목을 탐색할 수 있다.

## 05. 테마

1.  `MENU`의 `THEME` 우측에 좌우로 이동하는 토글 버튼을 표시하고, 토글해도 메뉴를 닫지 않은 채 DARK와 LIGHT를 전환할 수 있으며 기본값은 DARK다.

2.  LIGHT는 밝은 중립 배경과 짙은 글자를 사용하고 작업 영역·편집기·하단 메뉴·그룹 메뉴를 일관된 색상으로 표시한다.

3.  선택한 테마는 노트와 별도로 브라우저에 저장하고 새로고침·재접속 시 복원한다.

4.  다른 브라우저 탭에서 테마 설정을 변경하면 현재 열린 앱에도 반영한다.

5.  테마 저장소를 사용할 수 없어도 현재 화면의 테마 전환은 동작한다.

## 06. 설정 - 글자와 탭 색상

1.  `MENU`의 `SETTINGS`(설정)를 선택하면 드롭다운을 닫고 우측 패널 영역에 설정 패널을 연다.

2.  설정 패널의 `Font Size`에서 전체 폰트 크기를 80%·90%·100%·110%·120%·130% 중에서 선택할 수 있으며 기본값은 100%다.

3.  설정 패널의 `Tab Colors`에서 탭 색상 순서의 1·2·3번째 색상을 기본 9가지 색상(Gray·Red·Orange·Yellow·Green·Teal·Indigo·Purple·Pink) 중에서 선택할 수 있으며 기본값은 Gray → Green → Purple다.

4.  탭 색상 아이콘을 클릭하면 설정한 1 → 2 → 3번째 색상 순서로 순환하고 새 탭은 1번째 색상으로 시작한다. 순서에 없는 색상의 탭은 클릭 시 1번째 색상으로 바뀐다.

5.  설정한 폰트 크기와 탭 색상 순서는 브라우저에 저장해 새로고침 후에도 유지한다.

## 07. 설정 - 언어와 초기화

1.  설정 패널의 `Tab Colors` 아래 `Language`에서 `English`·`한국어` 중 언어를 선택할 수 있으며 기본값은 English다. 각 언어 이름은 해당 언어로 표시한다.

2.  선택한 언어는 브라우저에 저장해 새로고침 후에도 유지하고 문서의 `lang` 속성에 반영한다.

3.  `Tab Colors` 제목 오른쪽에 탭 색상 초기화 버튼을 표시한다. 누르면 확인 팝업 없이 탭 색상 순서를 기본값(Gray → Green → Purple)으로 되돌리고 저장한다.

4.  확인 팝업에서 `Reset`을 선택하면 폰트 크기(100%)·탭 색상 순서(Gray → Green → Purple)·언어(English)·패널 슬라이드 효과(Off)·패널 위치(Right)를 기본값으로 되돌린다.

5.  선택한 언어는 MENU·하단 메뉴·탭 메뉴·우측 패널·팝업·검색창 안내 문구 등 화면에 표시되는 문구에 즉시 적용한다.

## 08. 설정 - 패널과 색상 동기화

1.  설정 패널의 `Language` 아래 `Panel Slide`에서 사이드 패널 슬라이드 효과를 `On`·`Off` 중 선택할 수 있으며 기본값은 Off다.

2.  Tab Colors에서 순번의 색상을 바꾸면 열린 탭의 이전 색상을 같은 순번의 새 색상으로 바꾸고 대시보드의 Todo·WIP·Done 상태를 유지한다.

3.  `Panel Slide` 아래 `Panel Position`에서 Left·Right(한국어 왼쪽·오른쪽)를 선택한다. 기본값은 Right이며 선택한 위치를 모든 사이드 패널에 즉시 적용한다.

4.  `Panel Slide` 선택은 브라우저에 저장해 새로고침 후에도 유지한다.

5.  탭 색상 순서를 초기화하면 열린 탭·북마크·닫은 탭의 색상을 같은 순번의 기본 색상으로 바꾸고 대시보드 상태를 유지한다.

## 09. 설정 - 언어별 접근성

1.  언어를 바꾸면 탭 목록·새 탭·탭 색상·탭 닫기와 편집기·줄 번호의 접근성 이름을 같은 언어로 즉시 바꾼다.

2.  언어를 바꾸면 설정 패널의 이름·크기 조절·고정·초기화·닫기 조작의 접근성 이름을 같은 언어로 즉시 바꾼다.

## 10. 메뉴 - 닫기와 가이드

1.  `MENU` 드롭다운에서 Tab을 누르면 드롭다운을 닫는다.

2.  사용 가이드 팝업은 Escape로 닫는다.

3.  2단계 이상에서 닫은 사용 가이드를 다시 열면 1단계부터 표시한다.

4.  모바일 `MENU` 드롭다운에는 `SHORTCUT`을 표시하지 않는다.

## 12. 설정 - 저장값 복구와 예외

1.  잘못된 폰트 크기 저장값은 기본값 100%로 복원한다.

2.  중복되거나 잘못된 탭 색상 순서 저장값은 Gray → Green → Purple로 복원한다.

3.  현재 설정 순서에 없는 색상의 탭은 색상 아이콘을 누르면 1번째 색상으로 바뀐다.

## 13. 설정 - 초기화 상호작용

1.  설정 초기화 버튼을 누르면 `Reset settings` 제목과 안내 문구를 표시하고 Cancel 버튼에 기본 포커스를 둔다.

2.  설정 초기화 확인 팝업을 Escape로 닫으면 현재 설정을 유지하고 설정 패널로 돌아간다.

3.  설정 초기화로 되돌린 모든 기본값을 브라우저에 저장한다.

4.  탭 색상만 초기화하면 비기본 폰트 크기와 언어를 그대로 유지한다.

5.  앞 순번에서 사용 중인 탭 색상은 뒤 순번에서 키보드로도 선택할 수 없다.

## 15. 설정 - 패널 접근성

1.  언어를 바꾸면 북마크 패널의 이름과 닫기 조작의 접근성 이름을 같은 언어로 즉시 바꾼다.

2.  언어를 바꾸면 전체 검색 패널과 검색 입력·닫기 조작의 접근성 이름을 같은 언어로 즉시 바꾼다.

## 17. 메뉴 - 항목 순서와 가이드 초기 상태

1.  드롭다운은 PC에서 THEME·SHORTCUT·SETTINGS·GUIDE, 모바일에서 THEME·SETTINGS·GUIDE 순서로 표시한다.

2.  MENU에는 SEARCH를 표시하지 않고 푸터에서 BOOKMARK 바로 왼쪽에 표시한다.

3.  사용 가이드 팝업을 처음 열면 `Next` 버튼에 포커스를 둔다.

## 18. 설정 - 즉시 적용

1.  선택한 폰트 비율은 탭·편집기·하단 메뉴·우측 패널의 글자 크기에 즉시 적용한다.

2.  선택한 `Panel Slide` 값은 현재 설정 패널의 전환 시간에 즉시 반영한다.
