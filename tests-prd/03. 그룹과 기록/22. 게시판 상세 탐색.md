# 22. 게시판 상세 탐색

> E2E: `tests/03. 그룹과 기록/22. 게시판 상세 탐색/`

1. PC 브라우저와 갤럭시 크기 모바일에서 목록과 상세의 뒤로가기는 목록 기준의 동일한 상단 위치·높이·글자 크기·줄 높이, 왼쪽 Chevron 아이콘과 hover 배경을 사용한다. 게시글 상세를 연 뒤 브라우저 기록의 뒤로가기를 실행하면 게시판 목록으로 돌아온다.
2. 공유 그룹 보드 상세는 그룹 소개·작업공간 요약·공유 노트 내용·공동 작업 및 접근 구역으로 구성한다. 작업공간 요약에는 노트 수·참여자 수·최근 변경일을 카드로 표시하고, 공유 노트 내용에는 모든 노트의 제목과 전체 본문을 표시한다. 노트 편집기 높이 조절은 제공하지 않으며, 모바일 상세 편집기 내부 스와이프는 탭을 전환하지 않고 푸터 스와이프만 탭을 전환한다. `Back`·그룹명·작성자·제목·메타 정보와 설명 글자를 확대해 표시하고 안내·작업 버튼의 확대 크기를 유지한다.
3. 모바일 보드 상세의 푸터를 왼쪽으로 스와이프하면 다음 노트 탭, 오른쪽으로 스와이프하면 이전 노트 탭으로 순환 이동하며 탭 영역도 활성 탭을 보이도록 맞춘다. 이후 메뉴·대시보드·사용자 아이콘을 실제로 한 번 탭하면 추가 탭 없이 즉시 연결된 화면이나 메뉴를 연다.
4. PC 보드 상세의 노트 편집기는 기본 높이를 475.2px로 고정하고 높이 조절 기능을 제공하지 않는다. 탭을 전환해도 편집기 위치·크기와 본문 transform을 바꾸는 애니메이션이 없어 텍스트가 흔들리지 않으며, 모바일에서는 방향별 슬라이드 효과를 유지한다.
5. 보드 상세 노트의 본문이 길어 내부 스크롤이 생기면 편집기 안에서 끝까지 읽을 수 있고, 최하단에서 계속 아래로 스크롤하면 입력을 가두지 않고 상세 페이지의 다음 콘텐츠로 자연스럽게 이동한다.
6. 보드 목록을 아래로 스크롤한 상태에서 그룹을 열어 상세화면으로 진입하면 페이지 스크롤을 항상 최상단으로 초기화한다.
