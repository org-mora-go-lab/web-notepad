# 22. 게시판 상세 탐색

> E2E: `tests/03. 그룹과 기록/22. 게시판 상세 탐색/`

1. PC 브라우저와 갤럭시 크기 모바일에서 목록과 상세의 뒤로가기는 목록 기준의 동일한 상단 위치·높이·글자 크기·줄 높이, 왼쪽 Chevron 아이콘과 hover 배경을 사용한다. 게시글 상세를 연 뒤 브라우저 기록의 뒤로가기를 실행하면 게시판 목록으로 돌아온다.
2. 공유 그룹 보드 상세는 그룹 소개·작업공간 요약·공유 노트 내용·공동 작업 및 접근 구역으로 구성한다. 작업공간 요약에는 노트 수·참여자 수·최근 변경일을 카드로 표시하고, 공유 노트 내용에는 모든 노트의 제목과 전체 본문을 표시한다. 노트 편집기 높이 조절은 제공하지 않으며, 모바일에서는 상세 편집기 내부 또는 푸터 스와이프로 탭을 순환하고 탭 포커스를 함께 이동한다. `Back`·그룹명·작성자·제목·메타 정보와 설명 글자를 확대해 표시하고 안내·작업 버튼의 확대 크기를 유지한다.
