# 북마크 - 열기와 표시

> E2E: `tests/03. 그룹과 기록/05. 북마크 - 열기와 표시/`

1.  북마크를 패널에서 제거할 수 있다.

2.  별도 Open 버튼 대신 북마크 카드 본문을 클릭해 원본 탭이 남아 있는 북마크를 열면 해당 탭을 활성화한다.

3.  북마크 카드를 클릭해 원본 탭이 없는 북마크를 열면 내용·탭 색상·선택한 줄 번호를 함께 복원한다.

4.  북마크 내용에서 제목과 중복되는 첫 줄을 제외한다.

5.  북마크의 나머지 전체 내용은 DOM에 유지하되 카드에서는 대시보드 탭 카드와 같은 3줄 본문 미리보기로 표시한다.

6.  제목을 제외한 내용이 없으면 높이 30px의 빈 내용 영역을 표시한다.

7.  모바일에서 북마크 카드를 클릭하면 북마크 탭을 연 뒤 북마크 팝업과 뒤의 메뉴 사이드바를 모두 닫아 열린 탭을 즉시 표시한다.
