# 24. 공유 탭 링크

> E2E: `tests/03. 그룹과 기록/24. 공유 탭 링크/`

1. 공유 그룹의 탭 우클릭 메뉴에는 `Link → Bookmark → Move Group` 순서로 항목을 표시하고, Link를 선택하면 그룹 ID와 탭 ID가 담긴 사이트 주소를 클립보드에 복사하며 결과를 알린다.
2. 같은 공유 그룹의 구성원이 탭 링크로 새로 접속하면 공유 그룹 동기화 후 해당 그룹을 선택하고 대상 탭 내용을 편집기에 표시한다.
3. 공유 그룹의 구성원이 아닌 사용자는 탭 링크만으로 해당 그룹이나 탭 내용을 열 수 없다.
4. 개인 그룹의 탭 우클릭 메뉴에는 공유 탭 Link를 표시하지 않는다.
5. 공유 그룹 구성원이 로그아웃 상태에서 탭 링크를 열고 로그인하면 원래 링크의 그룹과 탭을 복원한다.
