# 21. 게시판 자동 목록과 접근

> E2E: `tests/03. 그룹과 기록/21. 게시판 자동 목록과 접근/`

1. role admin URL은 게시판을 자동으로 열거나 관리자 표시·등록·수정·삭제 기능을 활성화하지 않는다.
2. 게시판 API는 조회만 지원하며 역할 파라미터로 쓰기 기능을 사용할 수 없다.
3. Board는 별도 등록 없이 현재 공유 중인 모든 그룹을 표시하고, 로그인한 사용자의 공유 그룹과 다른 사용자의 그룹을 모두 포함한다.
4. 그룹 이름의 HTML은 글자로 표시하며 목록 API에 노트 본문을 노출하지 않는다.
