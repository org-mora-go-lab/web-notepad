# 22. 그룹 영역 접기와 펼치기

> E2E: `tests/03. 그룹과 기록/22. 그룹 영역 접기와 펼치기/`

1. 소유권 확인 전에는 공유 그룹을 임시 영역에 배치하지 않고 Shared Group 목록 내부에 스켈레톤을 표시하고 My Group 목록과 50:50 배치를 유지한다. 확인 후 내가 공유한 그룹과 초대받은 그룹은 모두 Shared Group에 표시하고 개인 그룹은 My Group에 표시한다. 공유를 취소한 내 그룹은 My Group으로 돌린다.
2. 영역 우측 화살표 버튼은 키보드와 클릭으로 독립적으로 접고 펼치며 현재 노트를 보존한다.
3. 접기 상태를 사이드바 재진입과 새로고침 뒤에도 유지한다.
4. My Group을 접은 채 새 그룹을 생성하면 펼쳐서 보여주며 시스템 그룹은 하단 MORE 메뉴에 유지한다.

5. 소유권 조회 실패 시 임시 분류 없이 Shared Group 목록 안에 안내와 다시 시도를 제공하고, 재시도 성공 후 올바른 영역에 표시한다.

6. My Group과 Shared Group은 그룹 생성·하단 MORE 사이의 남은 높이를 50%씩 차지하며 My Group 제목 위의 중복 경계선을 제거한다.
7. 각 그룹 목록만 독립적으로 스크롤하고 그룹 생성·Shared Group 제목·하단 MORE는 제자리에 유지한다.
