# 22. 그룹 영역 접기와 펼치기

> E2E: `tests/03. 그룹과 기록/22. 그룹 영역 접기와 펼치기/`

1. 소유권 확인 전에는 공유 그룹을 임시 영역에 배치하지 않고 스켈레톤을 표시한다. 확인 후 내가 만든 공유 그룹은 My Group, 다른 사람에게 받은 그룹은 Share Group에 처음부터 표시한다.
2. 영역 우측 화살표 버튼은 키보드와 클릭으로 독립적으로 접고 펼치며 현재 노트를 보존한다.
3. 접기 상태를 사이드바 재진입과 새로고침 뒤에도 유지한다.
4. My Group을 접은 채 새 그룹을 생성하면 펼쳐서 보여주며 시스템 그룹은 하단에 유지한다.

5. 소유권 조회 실패 시 임시 분류 없이 안내와 다시 시도를 제공하고, 재시도 성공 후 올바른 영역에 표시한다.
