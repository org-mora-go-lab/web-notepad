# 03. 그룹 - 정렬과 표시

> E2E: `tests/03. 그룹과 기록/03. 그룹 - 정렬과 표시/`

1.  푸터 그룹 패널에서는 `All Group`과 `Ungrouped`, `Closed` 진입점을 제거하고 이름 있는 그룹만 배치한다.

2.  사용자가 변경한 그룹 순서는 브라우저에 저장하고 새로고침 후 복원한다.

3.  현재 그룹 이름은 PC와 모바일 모두 그룹 선택 버튼에 아이콘과 함께 표시한다. PC는 최대 너비 351px의 한 줄 말줄임으로 표시한다.

4.  긴 그룹 이름은 전체 이름을 툴팁과 접근성 라벨로 제공한다.

5.  PC에서 그룹 왼쪽 이동 손잡이를 드래그해 그룹 순서를 변경한다. 변경 전에는 한글 우선 문자순으로 표시하고, 고정 그룹은 상단에 유지하며 같은 고정 상태 안에서 이동한다.
