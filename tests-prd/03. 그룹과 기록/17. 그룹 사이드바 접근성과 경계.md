# 17. 그룹 사이드바 접근성과 경계

> E2E: `tests/03. 그룹과 기록/17. 그룹 사이드바 접근성과 경계/`

1. GROUP 명령은 제어 대상과 펼침 상태를 제공한다.
2. 열린 사이드바는 Groups 이름의 complementary 랜드마크다.
3. 사이드바 닫기 버튼은 대상 이름을 제공한다.
4. GROUP 접기 버튼은 제어 대상 목록 ID를 제공한다.
5. All Group 선택 상태는 aria-pressed로 표시한다.
6. 사이드바의 열림과 닫힘 상태를 새로고침 후 복원한다.
7. 크기 조절선은 수직 separator 역할과 이름을 제공한다.
8. 조절한 PC 사이드바 너비를 새로고침 후 복원한다.
9. 닫기 버튼으로 사이드바를 닫으면 명령의 펼침 상태를 해제한다.
10. 모바일 사이드바에서는 PC 크기 조절선을 숨긴다.
