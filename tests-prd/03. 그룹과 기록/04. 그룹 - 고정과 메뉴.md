# 04. 그룹 - 섹션과 메뉴

> E2E: `tests/03. 그룹과 기록/04. 그룹 - 고정과 메뉴/`

1.  그룹 메뉴에서 `Pin`을 제거하고 `Close All`을 제공한다.

2.  그룹 드롭다운에는 그룹 추가 입력만 표시하며 사용자 섹션 추가·이동 기능은 제공하지 않는다. 그룹명 입력란은 추가 버튼보다 최소 5배 넓게 표시한다.

3.  `Close All`을 누르면 해당 그룹의 열린 에디터 탭을 모두 닫는다.

4.  Escape로 사이드바를 닫으면 `MENU` 버튼에 포커스를 복원한다.

5.  모바일에서는 별도 이동 손잡이 없이 그룹 항목을 직접 터치해 끌어 순서를 변경한다. 이동 후에도 사이드바를 유지하고 그룹 선택은 변경하지 않는다.
