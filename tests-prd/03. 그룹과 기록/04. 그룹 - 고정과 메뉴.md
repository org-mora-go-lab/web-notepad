# 04. 그룹 - 고정과 메뉴

> E2E: `tests/03. 그룹과 기록/04. 그룹 - 고정과 메뉴/`

1.  `Pin`을 누르면 그룹을 이름 있는 그룹 목록의 맨 위로 옮기고 핀 아이콘을 표시한다.

2.  그룹 고정 상태는 브라우저에 저장하고 새로고침 후 복원한다.

3.  고정한 그룹에는 `Unpin`(`고정 해제`)을 표시한다. 고정을 해제하면 핀 아이콘을 제거하고 일반 정렬 위치로 되돌린다.

4.  Escape로 사이드바를 닫으면 `MENU` 버튼에 포커스를 복원한다.

5.  모바일에서는 별도 이동 손잡이 없이 그룹 항목을 직접 터치해 끌어 순서를 변경한다. 이동 후에도 사이드바를 유지하고 그룹 선택은 변경하지 않는다.
