# 20. 공유 그룹 - 참여와 공유 해제

> E2E: `tests/03. 그룹과 기록/20. 공유 그룹 - 참여와 공유 해제/`

1. 공유 중인 주최자의 우클릭·우측 아이콘 메뉴에서는 공유하기 위치에 Unlink 아이콘과 Cancel Sharing / 공유 취소를 표시한다. 공유하기와 그룹 나가기는 표시하지 않는다.
2. 참여자의 두 메뉴에는 그룹 나가기를 표시하고 공유·공유 취소·삭제는 숨긴다. 모바일 우측 아이콘 메뉴에도 나가기를 제공한다.
3. 그룹 나가기는 자신의 참여만 해제하며 주최자의 노트는 보존하고 내 목록에서 제거한다.
4. 주최자가 공유를 취소하면 원문은 보존하고 다른 참여자·기존 초대 링크·게시판의 접근을 해제한다.
5. 취소한 그룹을 다시 공유하면 새 초대 링크를 발급하고 이전 링크는 계속 거부한다.
6. 나가기·공유 취소·재공유는 로그인과 소유권을 검사하고 다른 출처의 변경 요청은 거부한다.
7. 나가기 요청이 실패하면 원문을 유지하고 확인창에 오류와 재시도 진입점을 제공한다.
8. 공유 취소 확인창을 취소하면 기존 참여 권한과 초대 링크를 유지한다.

9. 공유 그룹도 에디터 수정 후 0.5초 대기가 끝나 실제 전송 중인 탭에만 저장 애니메이션을 표시한다.

10. Alarm 항목을 클릭하면 진행 중인 갱신을 기다려 최신 그룹을 확인하고 변경된 탭을 활성화하여 내용을 표시한다. 개인 이력 복원이나 단순 이동으로 공유 내용을 다시 저장하지 않고 원격 노트를 보존한다.
