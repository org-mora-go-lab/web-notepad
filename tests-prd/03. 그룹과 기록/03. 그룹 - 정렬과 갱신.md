# 그룹 - 정렬과 갱신

> E2E: `tests/03. 그룹과 기록/03. 그룹 - 정렬과 갱신/`

1.  초기 사이드바는 My Group 영역을 펼쳐 이름 있는 그룹을 표시한다. `All Group`, `All My Group`, `All Shared Group`, `Ungrouped`는 하단 GROUP 메뉴에 순서대로 표시하며 `Closed` 진입점은 표시하지 않는다.

2.  사용자가 변경한 그룹 순서는 브라우저에 저장하고 새로고침 후 복원한다.

3.  하단 그룹 버튼은 PC에서 그룹 아이콘과 현재 그룹 이름만 표시한다. 모바일 버튼은 그룹 아이콘과 `MENU` 라벨만 표시하고 하단 메뉴 위의 별도 영역에는 현재 그룹 이름을 계속 표시한다.

4.  사이드바 맨 아래 GROUP 메뉴에 `All Group`, `All My Group`, `All Shared Group`, `Ungrouped`를 순서대로 배치하고 그룹 추가 입력을 드롭다운의 마지막 영역에 배치한다. 옆의 MORE 메뉴에서 가이드를 열고 가이드의 `SHORTCUT` 버튼으로 단축키 패널을 연다.

5.  PC에서 별도 이동 손잡이 없이 그룹 항목을 직접 드래그해 그룹 순서를 변경한다. 변경 전에는 한글 우선 문자순으로 표시하고, 고정 그룹은 상단에 유지하며 같은 고정 상태 안에서 이동한다.

6.  새 그룹을 생성한 직후 이름 있는 그룹에 같은 정렬을 적용한다.
