# 그룹 - 정렬과 갱신

> E2E: `tests/03. 그룹과 기록/03. 그룹 - 정렬과 갱신/`

1.  사이드바에는 별도의 화살표·`GROUP` 접기 영역 없이 이름 있는 그룹을 항상 표시한다. `All Group`과 `Ungrouped`는 사이드바 하단에 항상 표시하며 `Closed` 진입점은 표시하지 않는다.

2.  사용자가 변경한 그룹 순서는 브라우저에 저장하고 새로고침 후 복원한다.

3.  하단 그룹 버튼은 PC에서 그룹 아이콘과 현재 그룹 이름만 표시한다. 모바일 버튼은 그룹 아이콘과 `GROUP` 라벨만 표시하고 하단 메뉴 위의 별도 영역에는 현재 그룹 이름을 계속 표시한다.

4.  사이드바는 이름 있는 그룹 목록 아래에 `All Group`과 `Ungrouped`를 배치한다. 가이드와 설정은 하단 더보기에서 열며 가이드의 `SHORTCUT` 버튼으로 단축키 패널을 연다.

5.  PC에서 별도 이동 손잡이 없이 그룹 항목을 직접 드래그해 그룹 순서를 변경한다. 변경 전에는 한글 우선 문자순으로 표시하고, 고정 그룹은 상단에 유지하며 같은 고정 상태 안에서 이동한다.

6.  새 그룹을 생성한 직후 이름 있는 그룹에 같은 정렬을 적용한다.

7.  그룹 이름을 수정한 직후 이름 있는 그룹에 같은 정렬을 적용한다.
