# 그룹 - 정렬과 갱신

> E2E: `tests/03. 그룹과 기록/03. 그룹 - 정렬과 갱신/`

1.  사이드바의 `GROUP` 영역에 `All Group`, `Ungrouped`, 이름 있는 그룹을 표시하고 화살표 버튼으로 전체 그룹 영역을 접고 펼친다. `Closed` 진입점은 표시하지 않는다.

2.  사용자가 변경한 그룹 순서는 브라우저에 저장하고 새로고침 후 복원한다.

3.  PC와 모바일 하단 메뉴에는 햄버거 메뉴 아이콘과 `MENU` 라벨을 표시한다. 모바일은 하단 메뉴 위의 별도 영역에 현재 그룹 이름을 계속 표시한다.

4.  사이드바는 GROUP 영역 아래 메뉴 맨 아래에 SETTINGS·GUIDE를 순서대로 배치하고 GROUP은 화살표로 여닫는다. 별도 SHORTCUT 항목은 표시하지 않으며 테마는 SETTINGS의 FONT SIZE 위에서 설정한다.

5.  PC에서 별도 이동 손잡이 없이 그룹 항목을 직접 드래그해 그룹 순서를 변경한다. 변경 전에는 한글 우선 문자순으로 표시하고, 고정 그룹은 상단에 유지하며 같은 고정 상태 안에서 이동한다.

6.  새 그룹을 생성한 직후 이름 있는 그룹에 같은 정렬을 적용한다.

7.  그룹 이름을 수정한 직후 이름 있는 그룹에 같은 정렬을 적용한다.
