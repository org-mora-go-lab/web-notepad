# 19. 그룹 공유 게시판

> E2E: `tests/03. 그룹과 기록/19. 그룹 공유 게시판/`

1. 게시판은 별도 /board 페이지에 그룹·공유자·노트 수·참여자 수·최근 변경 테이블을 표시하고 방문자에게 관리 버튼을 노출하지 않는다. 공유자는 아이콘과 카카오 이름으로 표시한다.
2. 게시글 상세는 공유자 아이콘·카카오 이름, 일반 안내와 참여 링크를 제공하고 클릭만으로 그룹을 추가하지 않는다.
3. 로그인한 방문자는 게시글 초대를 수락해 실제 공유 그룹에 참여한다.
4. 비로그인 방문자가 초대를 열면 로그인 안내와 원래 공유 링크를 유지한다.
5. 검색은 그룹 이름을 찾고 결과가 없을 때 명확하게 안내한다.
6. 작은 모바일과 라이트 테마에서 목록과 참여 버튼이 화면 안에 표시된다.
7. 게시판 요청 실패 후 다시 시도로 목록을 복구한다.
8. 초대 링크 복사 버튼은 아이콘을 문구 오른쪽에 표시하고 관리자 파라미터 없이 참여 링크만 복사한다.

9. PC와 좁은 모바일에서 목록으로 돌아가기의 왼쪽 화살표와 문구는 한 줄로 표시한다.

10. 게시판 수신 중에는 테이블 형태의 스켈레톤을 표시하고 수신 완료 후 실제 테이블을 렌더링한다. 로딩 상태를 보조 기술에 알리며 움직임 줄이기 설정을 지원한다.
