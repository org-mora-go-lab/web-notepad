# 19. 그룹 공유 게시판

> E2E: `tests/03. 그룹과 기록/19. 그룹 공유 게시판/`

1. 게시판은 별도 /board 페이지에 그룹·공유자·노트 수·참여자 수·최근 변경 테이블을 표시하고 방문자에게 관리 버튼을 노출하지 않는다. 로딩 중에도 실제 컬럼 헤더를 그대로 표시하고 헤더 아래의 행만 실제 데이터 행 높이에 맞춘 스켈레톤으로 표시한다. 리스트의 그룹 항목은 아이콘 없이 그룹명만 표시하고 Group과 Shared by 열 사이를 기존보다 10px 좁히며, Shared by 헤더와 값은 기본 위치에서 왼쪽으로 60px 이동한다. 공유자는 아이콘과 카카오 이름으로 표시한다.
2. 게시글 상세는 공유자 아이콘·카카오 이름, 공유 그룹의 모든 노트 제목과 본문, 일반 안내와 참여 링크를 제공하고 클릭만으로 그룹을 추가하지 않는다.
3. 로그인한 방문자는 게시글 초대를 수락해 실제 공유 그룹에 참여한다.
4. 비로그인 방문자가 초대를 열면 로그인 안내와 원래 공유 링크를 유지한다.
5. 검색은 그룹 이름을 찾고 결과가 없을 때 명확하게 안내한다.
6. 작은 모바일과 라이트 테마에서 목록과 참여 버튼이 화면 안에 표시된다.
7. Board 목록은 내 그룹과 공유 그룹을 함께 표시한다.
