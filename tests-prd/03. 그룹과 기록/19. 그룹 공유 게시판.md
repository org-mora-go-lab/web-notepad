# 19. 그룹 공유 게시판

> E2E: `tests/03. 그룹과 기록/19. 그룹 공유 게시판/`

1. 게시판은 별도 /board 페이지에 그룹·공유자·노트 수·참여자 수·최근 변경 테이블을 표시하고 방문자에게 관리 버튼을 노출하지 않는다. 다섯 컬럼은 같은 간격으로 배치하고 헤더 글자색은 대시보드 상태 표시 글자색과 일치시키며, 로딩 Skeleton과 실제 목록의 헤더 위치를 일치시킨다. 헤더 아래의 Skeleton 행 높이는 실제 데이터 행과 같고, 리스트의 그룹 항목은 아이콘 없이 그룹명만 표시한다. 공유자는 아이콘과 카카오 이름으로 표시한다. 목록 아래에는 `All Group`, `All My Group`, `All Shared Group`, `Ungrouped` 바로가기를 순서대로 배치한다.
2. 게시글 상세는 공유자 아이콘·카카오 이름, 공유 그룹의 모든 노트 제목과 본문, 일반 안내와 참여 링크를 제공하고 클릭만으로 그룹을 추가하지 않는다. 상세 에디터의 높이 조절 핸들은 제거하며, 모바일에서는 상세 에디터 내부와 하단 푸터를 좌우로 스와이프해 메인 에디터와 동일하게 이전·다음 노트 탭으로 이동한다. 목록과 상세를 반복해서 오가도 스와이프를 유지한다.
3. 로그인한 방문자는 게시글 초대를 수락해 실제 공유 그룹에 참여한다.
4. 비로그인 방문자가 초대를 열면 로그인 안내와 원래 공유 링크를 유지한다.
5. 검색은 그룹 이름을 찾고 결과가 없을 때 명확하게 안내한다.
6. 작은 모바일과 라이트 테마에서 목록과 참여 버튼이 화면 안에 표시된다. 고정 뒤로가기 헤더의 하단 경계와 모바일 푸터의 상단 경계에는 대시보드 상태 표시줄과 같은 2px blur 그라데이션을 적용한다.
7. Board 목록은 내 그룹과 공유 그룹을 함께 표시한다.
