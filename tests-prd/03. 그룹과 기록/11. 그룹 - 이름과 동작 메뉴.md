# 그룹 - 이름과 동작 메뉴

> E2E: `tests/03. 그룹과 기록/11. 그룹 - 이름과 동작 메뉴/`

1.  이름 수정 입력에서 Enter를 누르면 앞뒤 공백을 제거해 저장한다.

2.  취소 버튼은 입력한 이름을 버리고 기존 이름을 유지한다.

3.  그룹 이름을 바꿔도 그룹 ID와 북마크를 유지하고 새로고침 후 복원한다.

4.  새 그룹 이름의 앞뒤 공백을 제거해 저장한다.

5.  새 그룹 이름은 최대 60자로 입력하고 저장한다.

6.  새 그룹 이름 입력란에서 Enter를 누르면 그룹을 만든다.

7.  이름 있는 그룹 오른쪽의 세로 점 세 개(`⋮`) 버튼에서 고정·수정·삭제 명령을 세로 드롭다운으로 연다. 각 명령의 아이콘과 텍스트는 한 줄에 정렬한다.

8.  수정한 그룹 이름의 앞뒤 공백을 제거해 저장한다.

9.  수정할 그룹 이름은 최대 60자로 입력하고 저장한다.

10. PC 그룹 사이드바에서 그룹명을 우클릭하면 해당 그룹의 고정·공유·수정·삭제 드롭다운을 열고 그룹 선택은 바꾸지 않는다.

> 그룹 동작 드롭다운은 하단 더보기와 같은 배경, 1px 테두리, 6px 모서리, 그림자와 5px 내부 여백을 사용한다. 항목은 PC 높이 40px·모바일 44px, 15px 글자, 18px 아이콘, 아이콘과 텍스트 간격 10px, 좌우 여백 10px, 4px 모서리와 같은 hover 배경으로 통일한다.
