# 09. All Group

> E2E: `tests/03. 그룹과 기록/09. All Group/`

1.  `All Group`은 모든 그룹의 탭을 하나의 편집기에 모아 표시한다.

2.  `All Group` 선택을 저장하고 새로고침 후 복원한다.

3.  `All Group`의 분할 배치는 개별 그룹의 분할 배치와 별도로 관리한다.

4.  `All Group`에서 기존 탭의 내용을 편집하면 그 탭이 속한 그룹에 반영한다.

5.  `All Group`에서 기존 탭을 닫으면 Closed로 이동하지 않고 그 탭이 속한 그룹에 숨긴 상태로 유지한다.
