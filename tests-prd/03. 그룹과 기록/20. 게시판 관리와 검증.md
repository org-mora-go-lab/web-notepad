# 20. 게시판 관리와 검증

> E2E: `tests/03. 그룹과 기록/20. 게시판 관리와 검증/`

1. role admin으로 접속하면 관리 화면을 열고 수정 내용은 다른 방문자에게도 저장된다.
2. 게시글 내리기는 취소할 수 있고 내린 뒤에도 원본 그룹 초대는 유효하다.
3. 일반 방문자는 관리 API로 게시글을 등록하거나 수정하거나 내릴 수 없다.
4. 관리 모드여도 다른 출처에서 보낸 변경 요청은 거부한다.
5. 같은 공유 그룹의 중복 등록을 거부하고 기존 글을 유지한다.
6. 잘못된 초대 링크나 빈 제목과 초과 길이 소개는 저장하지 않는다.
7. 저장 실패 시 작성 중 내용을 유지하고 다시 저장할 수 있다.
8. 관리자는 유효한 공유 링크로 새 게시글을 등록하고 새로고침 후 확인한다.

> 게시글 입력란의 네이티브 편집 키는 뒤쪽 노트 단축키로 전달하지 않으며, 저장 실패 시에도 노트와 입력 내용을 보존한다.
