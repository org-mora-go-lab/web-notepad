# 18. 공유 그룹과 알림

> E2E: `tests/03. 그룹과 기록/18. 공유 그룹과 알림/`

1. 그룹 메뉴의 공유하기 팝업은 공유 링크와 복사하기·닫기 버튼을 제공한다.
2. 공유 링크를 연 비로그인 사용자는 카카오 로그인을 안내받고 로그인 후 돌아올 링크를 유지한다.
3. 공유받은 사용자의 글 수정은 최초 공유자가 화면을 다시 활성화하면 반영된다.
4. 최초 공유자의 글 수정은 공유받은 사용자가 화면을 다시 활성화하면 반영된다.
5. 공유 권한이 없는 사용자는 그룹 조회와 수정을 할 수 없다.
6. 같은 버전에서 두 사용자가 동시에 수정하면 오래된 버전의 저장을 거부한다.
7. PC·모바일의 더보기에는 설정과 알림 항목 및 알림 배지를 표시하지 않는다.
8. 작은 모바일 화면에서도 공유 팝업의 링크·복사·닫기 버튼은 화면 안에서 스크롤하여 사용할 수 있다.
9. PC에서 공유 팝업은 키보드 포커스를 안에 두고 Escape로 닫으면 그룹 동작 버튼에 포커스를 돌려준다.
10. 320px 한국어 모바일의 계정 메뉴 게시판 아이콘과 라벨은 한 줄로 정렬되고 화면을 넘지 않는다.
