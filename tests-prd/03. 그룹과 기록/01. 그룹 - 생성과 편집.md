# 01. 그룹 - 생성과 편집

> E2E: `tests/03. 그룹과 기록/01. 그룹 - 생성과 편집/`

1.  하단 `MENU` 버튼을 누르면 PC 작업공간 왼쪽을 차지하고 고정 푸터 바로 위까지 이어지는 그룹 사이드바가 열린다.

2.  PC에서 그룹을 선택하면 사이드바를 열린 채 유지한다.

3.  모바일에서 그룹을 선택하면 사이드바를 바로 닫는다.

4.  하단 GROUP 메뉴의 기본 `Ungrouped` 그룹은 삭제할 수 없다.

5.  그룹 사이드바는 PC에서 최대 폭 이내의 기본 280px을 사용하며 모바일에서는 화면 전체 너비를 사용한다.

6.  PC 그룹 사이드바의 우측 구분선을 가로로 드래그해 최소 192px부터 기존 최대 너비에서 15% 줄인 화면 너비의 51%까지 조절하며 작업공간 크기를 함께 변경한다.
