# 01. 그룹 - 생성과 편집

> E2E: `tests/03. 그룹과 기록/01. 그룹 - 생성과 편집/`

1.  하단 `MENU` 버튼을 누르면 PC 작업공간 왼쪽을 차지하는 그룹 사이드바가 열린다.

2.  PC에서 그룹을 선택하면 사이드바를 열린 채 유지한다.

3.  모바일에서 그룹을 선택하면 사이드바를 바로 닫는다.

4.  기본 `Ungrouped` 그룹은 삭제할 수 없다.

5.  그룹 사이드바 기본 너비는 PC 280px이며 모바일에서는 화면 전체 너비를 사용한다.

6.  PC 그룹 사이드바의 우측 구분선을 가로로 드래그해 최소 240px부터 화면 너비의 60%까지 조절하며 작업공간 크기를 함께 변경한다.

7.  모바일에서 `MENU` 버튼을 누르면 기존 오버레이 패널처럼 그룹 사이드바를 화면 전체에 표시한다.
