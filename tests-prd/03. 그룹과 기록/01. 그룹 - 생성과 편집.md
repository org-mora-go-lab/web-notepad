# 01. 그룹 - 생성과 편집

> E2E: `tests/03. 그룹과 기록/01. 그룹 - 생성과 편집/`

1.  하단 그룹 선택 버튼을 누르면 버튼 위에 그룹 드롭다운이 열리며, 패널 상단에는 불필요한 구분선을 표시하지 않는다.

2.  PC에서 그룹을 선택하면 드롭다운을 열린 채 유지한다.

3.  모바일에서 그룹을 선택하면 드롭다운을 바로 닫는다.

4.  기본 `Ungrouped` 그룹은 삭제할 수 없다.

5.  그룹 드롭다운 기본 너비는 기존보다 15% 작은 PC 273.7px, 모바일 328.44px이며 화면이 더 좁으면 좌우 8px 여백 안으로 제한한다.

6.  그룹 드롭다운의 우측 경계를 가로로 드래그해 최소 240px부터 화면 좌우 8px 여백 안의 최대 폭까지 조절할 수 있다.

7.  모바일에서 그룹 버튼을 누르면 그룹 드롭다운을 별도 그룹명 패널 바로 위에 배치한다.
