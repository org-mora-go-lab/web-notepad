# 23. 알람 대상 유효성

> E2E: `tests/03. 그룹과 기록/23. 알람 대상 유효성/`

1. 현재 그룹에서 삭제된 탭의 이전 수정 알림과 삭제 알림을 목록에서 제외한다.
2. X로 닫은 탭은 영구 삭제가 아니므로 알림을 보존하며 다시 열 수 있다.

3. 알람은 현재 사용자가 아닌 다른 사용자 ID의 변경만 표시하고 내 변경은 서버와 클라이언트에서 제외한다.

4. 이미 삭제를 확인한 탭의 늦게 도착한 알람은 다음 그룹 조회 중에도 다시 표시하지 않는다.

5. 알람에서 해당 그룹과 탭으로 이동할 때 열려 있던 그룹 사이드바를 닫지 않고 선택 상태를 갱신한다.

6. 읽지 않은 알람은 점·배경·굵기로 구분하고 패널을 열 때 읽음 처리하지 않는다. 클릭한 알람만 읽음 처리하며 새로고침 후에도 유지한다.
7. 패널 우측 상단 휴지통은 내 전체 알람을 비우며 새로고침 후에도 이전 알람이 돌아오지 않는다. 다른 사용자의 알람·그룹·탭은 유지하고 이후 새 알람을 수신한다.
8. 전체 비우기 실패 시 기존 목록과 오류를 표시하고 재시도할 수 있다. 처리 중·빈 목록에서는 휴지통을 비활성화한다.
9. 알람 변경 API는 로그인·동일 출처·유효한 읽음 ID를 검증하며 다른 사용자의 읽음 상태를 변경할 수 없다.
