# 18. E2E 문서와 구현 계약

> E2E: `tests/01. 앱 기반/18. E2E 문서와 구현 계약/`

1. 모든 상세 PRD 요구사항은 같은 번호의 E2E 파일과 일대일로 대응한다.
2. E2E 테스트 제목은 대응하는 PRD 요구사항 번호로 시작하고 독립 동작을 설명한다.
3. 각 E2E 파일은 하나의 최상위 테스트만 선언한다.
4. E2E 파일은 품질 계약 반복 주석 없이 실행 코드 20줄 이상으로 구성한다.
5. E2E 검증 전체를 번호 기반 실행 함수나 단일 외부 함수에 위임하지 않는다.
6. 테스트 공통 리소스 디렉터리는 외부 진입점인 index.ts 배럴을 제공한다.
7. 상세 PRD는 1개 이상 10개 이하의 연속된 번호 요구사항으로 구성한다.
8. 상세 PRD 문서와 E2E 디렉터리는 동일한 카테고리와 제목 경로를 사용한다.
