# 17. 서버 응답과 게시판 계약

> E2E: `tests/01. 앱 기반/17. 서버 응답과 게시판 계약/`

1. 비로그인 사용자의 공유 그룹 목록 조회를 거부한다.
2. 공유 그룹 목록은 인증 후 private no-store 배열로 반환한다.
3. 비로그인 사용자의 알림 목록 조회를 거부한다.
4. 알림 목록은 private no-store 배열로 반환한다.
5. 외부 Origin의 알림 전체 삭제를 거부한다.
6. 깨진 JSON 알림 읽음 요청을 거부한다.
7. 0 이하의 알림 ID를 읽음 처리하지 않는다.
8. 익명 게시판 조회는 no-store posts 배열을 반환한다.
9. role admin 쿼리는 게시판 응답에 관리자 권한을 추가하지 않는다.
10. 게시판은 지원하지 않는 POST 메서드를 405로 거부한다.
