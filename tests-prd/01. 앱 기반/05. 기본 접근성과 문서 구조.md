# 05. 기본 접근성과 문서 구조

> E2E: `tests/01. 앱 기반/05. 기본 접근성과 문서 구조/`

1. 앱의 주 콘텐츠는 하나의 main 랜드마크로 제공한다.
2. 기본 문서 언어는 영어로 설정한다.
3. PC 화면에서 문서에 가로 오버플로를 만들지 않는다.
4. 모바일 화면에서 문서에 가로 오버플로를 만들지 않는다.
5. 하단 상태 영역은 footer 요소로 제공한다.
6. 모든 표시 중인 버튼은 명시적인 button 타입을 사용한다.
7. 하단 그룹·대시보드·더보기 진입점은 각각 접근성 이름과 연결 대상을 제공한다.
8. 비로그인 상태의 헤더 우측에는 로그인 아이콘과 `LOGIN` 문구를 제공하고, 로그인 요청은 CSRF 방지 상태값과 등록된 콜백 주소를 포함해 카카오 인증 서버로 이동한다. 인증 후에는 카카오 프로필 이미지와 사용자 이름을 표시한다.
9. 기본 화면의 핵심 조작은 키보드 Tab 순서에 포함한다.

## 문서 구조

작업 영역은 main 내부의 section으로 제공한다.
