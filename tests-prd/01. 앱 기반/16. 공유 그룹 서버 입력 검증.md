# 16. 공유 그룹 서버 입력 검증

> E2E: `tests/01. 앱 기반/16. 공유 그룹 서버 입력 검증/`

> 품질 기준: 각 E2E 파일에서 인증·Origin·그룹 입력을 구성하고 공유 API의 거부 결과를 직접 확인할 수 있어야 한다.

1. 비로그인 공유 생성 요청을 거부한다.
2. 외부 Origin의 공유 생성 요청을 거부한다.
3. 깨진 JSON 공유 생성 요청을 400으로 거부한다.
4. Ungrouped 그룹의 공유 생성을 거부한다.
5. 공백이 포함된 잘못된 로컬 그룹 ID를 거부한다.
6. 60자를 초과한 공유 그룹 이름을 거부한다.
7. 본문 문자열이 없는 공유 탭을 거부한다.
8. 서명이 잘못된 공유 참여 토큰을 거부한다.
9. shared UUID 형식이 아닌 그룹 업데이트를 거부한다.
10. shared UUID 형식이 아닌 그룹 나가기 요청을 거부한다.
