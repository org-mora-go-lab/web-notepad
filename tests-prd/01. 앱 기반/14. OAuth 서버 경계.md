# 14. OAuth 서버 경계

> E2E: `tests/01. 앱 기반/14. OAuth 서버 경계/`

> 품질 기준: 각 E2E 파일에서 OAuth 입력, 리다이렉트 요청, 호스트·쿼리·쿠키·세션 결과 검증을 직접 확인할 수 있어야 한다.

1. OAuth 시작은 카카오 인증 호스트로만 리다이렉트한다.
2. OAuth 인증 URL은 code 응답과 설정된 REST API 키를 사용한다.
3. OAuth 인증 URL은 정확한 callback과 프로필 scope를 사용한다.
4. OAuth state는 32바이트 기반의 URL 안전 난수다.
5. OAuth를 다시 시작하면 이전과 다른 state를 발급한다.
6. OAuth state 쿠키는 HttpOnly SameSite Lax와 10분 수명을 적용한다.
7. 유효하지 않은 공유 토큰은 복귀 쿠키에서 제거한다.
8. 외부 return 쿼리는 OAuth 리다이렉트 목적지를 바꾸지 못한다.
9. code 없는 callback은 로컬 invalid_state로 복귀한다.
10. state 불일치 callback은 세션을 만들지 않고 임시 쿠키를 만료한다.
