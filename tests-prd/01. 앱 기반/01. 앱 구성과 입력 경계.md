# 앱 구성과 입력 경계

> E2E: `tests/01. 앱 기반/01. 앱 구성과 입력 경계/`

> 구현 참고: Next.js App Router와 React 기반의 브라우저 노트 앱이다. 단순 화면 표시 확인은 저장·복원 시나리오에서 함께 검증한다.

1.  노트 상태는 Zustand로 관리하며 `web-notepad-storage` 키를 사용해 브라우저 로컬 저장소에 저장한다.

2.  저장 상태를 복원한 뒤 편집 화면을 표시하며, 복원 전에는 로딩 화면을 표시한다.

3.  `web-notepad-storage`의 JSON이 손상되어도 기본 작업공간으로 복구해 앱을 열고, 이후 편집한 정상 상태를 다시 저장한다.

4.  브라우저가 `web-notepad-storage` 읽기·쓰기·삭제를 차단해도 기본 작업공간을 열고 현재 세션의 노트를 계속 편집할 수 있다.

> 표시 규칙: 모바일의 모든 요소는 터치 시 브라우저 탭 하이라이트를 표시하지 않는다. 정적인 CSS 속성의 전수 검사는 별도 E2E 대상에서 제외한다.

5.  탭 타이틀은 설정 비율 적용 후 기존 표시 크기에서 3px 줄이고, 에디터는 기존 축소 크기에서 1px 늘린다. 기본 90%에서 모바일 탭은 13.38px, 편집기는 15.1px 글자를 표시하며 라인 번호 10.8px를 유지하고 줄 높이는 동일한 정수 픽셀 간격으로 맞춘다.

6.  터치 에디터는 기존 최소 16px에 2px 축소를 적용해 최소 14px로 표시한다. 검색창·그룹 이름 생성·수정 입력란은 전체 폰트 설정과 관계없이 최소 16px를 유지한다.

> 표시 규칙: 로그인한 사용자 이름과 모바일 하단 아이콘 아래 라벨은 기존 설정 배율 적용 크기에서 각각 1px 늘린다. 다른 로그인 안내·데스크톱 하단 라벨은 유지한다.
