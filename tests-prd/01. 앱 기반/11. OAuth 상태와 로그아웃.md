# 11. OAuth 상태와 로그아웃

> E2E: `tests/01. 앱 기반/11. OAuth 상태와 로그아웃/`

1. 인증을 다시 시작하면 이전과 다른 상태값을 발급한다.
2. OAuth 상태 쿠키는 짧은 수명과 스크립트 접근 차단을 적용한다.
3. 코드가 없는 콜백은 카카오 호출 없이 invalid_state로 돌아온다.
4. 쿠키와 다른 상태값의 콜백은 인증을 거부하고 상태 쿠키를 지운다.
5. 상태 쿠키 없이 직접 연 콜백은 세션을 만들지 않는다.
6. 로그아웃은 세션과 진행 중인 OAuth 상태를 모두 만료시킨다.

7. 로그인은 닉네임과 프로필 사진의 추가 동의를 요청한다.
8. 카카오에서 받은 계정 프로필을 로그인 이름과 사진으로 표시한다.
9. 원본 프로필 사진이 없으면 계정 썸네일을 사용한다.
10. 다른 사용자 ID의 카카오톡 프로필은 표시하지 않는다.
