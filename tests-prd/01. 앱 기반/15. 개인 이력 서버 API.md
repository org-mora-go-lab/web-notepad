# 15. 개인 이력 서버 API

> E2E: `tests/01. 앱 기반/15. 개인 이력 서버 API/`

> 품질 기준: 각 E2E 파일에서 인증·입력 조건, 이력 API 요청, 상태·저장·충돌 결과 검증을 직접 확인할 수 있어야 한다.

1. 비로그인 사용자는 개인 이력을 조회할 수 없다.
2. 비로그인 사용자는 개인 이력을 저장할 수 없다.
3. 외부 Origin의 개인 이력 저장 요청을 거부한다.
4. 깨진 JSON 개인 이력 요청을 400으로 거부한다.
5. UUID가 아닌 이력 event ID를 거부한다.
6. 필수 배열이 빠진 스냅샷을 거부한다.
7. 현재 세션과 다른 userId의 저장 요청을 거부한다.
8. 5MB를 초과한 스냅샷을 저장하지 않는다.
9. 개인 이력 서버는 짧은 탭과 긴 탭을 글자 수만으로 임의 삭제하지 않고 모두 보존한다.
10. 잘못된 기준 event ID는 최신 이력을 포함한 409를 반환한다.
