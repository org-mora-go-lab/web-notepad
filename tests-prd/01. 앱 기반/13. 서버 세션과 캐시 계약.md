# 13. 서버 세션과 캐시 계약

> E2E: `tests/01. 앱 기반/13. 서버 세션과 캐시 계약/`

> 품질 기준: 각 E2E 파일에서 세션 준비, 실제 API 요청, 상태·헤더·응답 본문 검증을 직접 확인할 수 있어야 한다.

1. 익명 세션 조회는 user null과 200을 반환한다.
2. 세션 응답은 private no-store 캐시 정책을 적용한다.
3. 유효한 세션은 만료 시각 없이 최소 프로필만 반환한다.
4. 구분자가 과도한 세션 쿠키를 거부한다.
5. 사용자 ID가 빈 서명 세션을 거부한다.
6. 닉네임이 빈 서명 세션을 거부한다.
7. role 쿼리로 세션 권한을 추가할 수 없다.
8. 로그아웃은 성공 JSON을 반환하고 세션을 무효화한다.
9. 로그아웃 세션 쿠키는 HttpOnly SameSite Lax와 즉시 만료를 사용한다.
10. 로그아웃은 OAuth 상태만 지우고 무관한 쿠키는 유지한다.
