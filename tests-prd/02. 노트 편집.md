# 02. 노트 편집

> E2E: `tests/02. 노트 편집/`

## 01. 탭

1.  워크스페이스마다 하나 이상의 노트 탭을 관리한다. 마지막 탭을 닫으면 빈 탭을 새로 만든다.

2.  새 탭을 추가하고 원하는 탭을 선택할 수 있다.

3.  탭 제목에서 드래그를 시작해 탭 순서를 바꿀 수 있다.

4.  모바일에서 탭을 선택해도 편집기에 자동 포커스하지 않아 가상 키보드가 다시 열리지 않게 한다.

5.  내용이 저장 기준 내용과 다르면 탭에 변경 표시를 보여준다.

6.  탭 제목은 내용의 첫 번째 비어 있지 않은 줄을 앞뒤 공백 제거 후 최대 28자로 표시한다.

7.  새 탭 또는 내용이 비어 있는 탭의 제목은 `-`로 표시하며, 제목에는 탭 번호를 표시하지 않는다.

8.  탭이 가로로 넘치면 현재 스크롤 위치에 따라 탭 영역의 좌우 가장자리에 페이드 효과를 표시한다.

9. 탭 제목을 최대 28개의 표시 문자로 제한하며 이모지와 결합 문자를 중간에서 잘라 깨뜨리지 않는다.

## 02. 탭 - 닫기

1. 닫기 버튼으로 일반 탭을 닫을 수 있다.

2. 가운데 클릭으로 일반 탭을 닫을 수 있다.

3. 고정 탭에는 일반 닫기 버튼을 표시하지 않는다.

4. 고정 탭은 가운데 클릭으로 닫히지 않는다.

5. 내용 길이나 북마크 여부와 관계없이 닫기 버튼을 누르면 확인 없이 바로 닫는다.

6. 내용 길이나 북마크 여부와 관계없이 가운데 클릭하면 확인 없이 바로 닫는다.

## 03. 탭 메뉴 - 열기와 표시

1. PC 우클릭 메뉴에서 탭의 고정 상태를 전환할 수 있다.

2. PC 우클릭 메뉴에서 탭의 북마크 상태를 전환할 수 있다.

3. PC에서는 더블클릭으로 탭 메뉴를 열지 않는다.

4. 모바일에서 탭 제목을 더블탭하면 고정 메뉴를 열고 상태를 전환할 수 있다.

5. 모바일에서 탭 제목을 더블탭하면 북마크 메뉴를 열고 상태를 전환할 수 있다.

6. 모바일에서는 탭 제목을 한 번 탭해도 탭 메뉴를 열지 않는다.

7. 모바일에서는 탭 제목을 우클릭해도 탭 메뉴를 열지 않는다.

8. 모바일에서는 탭 제목을 길게 눌러도 탭 메뉴를 열지 않는다.

9. 모바일에서 핀 아이콘을 더블탭하면 해당 탭의 고정·북마크 메뉴를 연다.

10. 모바일에서 북마크 아이콘을 더블탭하면 해당 탭의 고정·북마크 메뉴를 연다.

## 04. 탭 메뉴 - 그룹 이동 동작

1.  `Move Group`에서 대상 그룹을 선택하면 해당 탭을 옮기며 ID, 내용, 저장 기준 내용, 색상, 고정 상태, 줄 선택과 연결 북마크를 유지한다.

2.  그룹 이동 후 현재 그룹 화면은 유지하고 대상 그룹에서는 옮긴 탭을 왼쪽 패널의 활성 탭으로 지정한다.

3.  원래 그룹의 마지막 탭을 이동하면 빈 탭을 새로 만든다.

4. 그룹 이동 결과는 새로고침 후에도 유지한다.

5. 오른쪽 패널의 탭을 `Move Group`으로 옮겨 비워지면 분할을 해제하고 남은 탭을 왼쪽 활성 탭으로 지정한다.

6. 왼쪽 패널의 마지막 탭을 `Move Group`으로 옮기면 오른쪽의 남은 탭을 왼쪽으로 모아 분할을 해제한다.

7. 분할 패널의 탭을 이동해도 대상 그룹의 기존 오른쪽 패널과 나머지 탭은 유지한다.

## 05. 탭 메뉴 - 그룹 이동 화면

1. PC 탭 우클릭 메뉴와 모바일 탭 더블탭 메뉴에 `Move Group`을 표시한다. 선택하면 현재 그룹을 제외한 대상 그룹 목록을 표시한다.

2. 다른 그룹이 없으면 `Move Group`을 비활성화한다.

3. 상단 뒤로가기 버튼으로 이동 없이 기존 탭 메뉴로 돌아간다.

4. Escape로 이동 없이 그룹 목록과 탭 메뉴를 닫는다.

5. 바깥 영역 클릭으로 이동 없이 그룹 목록과 탭 메뉴를 닫는다.

6. 기본 탭 메뉴와 그룹 목록은 PC와 모바일 화면의 여백 안에 배치한다.

7. 긴 그룹 이름은 말줄임과 전체 이름 툴팁으로 표시한다.

8. 그룹 항목에는 아이콘을 표시하지 않고 상단 뒤로가기 화살표만 표시한다.

9. 그룹 선택 화면과 기본 탭 메뉴의 너비는 모두 201px를 유지한다.

10. 그룹 선택 화면과 기본 탭 메뉴 항목의 최소 높이는 39px로 표시한다.

## 08. 편집기 - 입력

1.  여러 줄 일반 텍스트를 편집하며 줄 번호를 표시한다.

2.  Enter는 커서 위치에 줄바꿈을 삽입한다.

3.  편집기 높이를 넘어가는 위치로 커서가 이동하면 커서가 보이도록 편집기와 줄 번호 영역을 함께 스크롤한다.

4.  Tab은 커서 위치에 탭 문자를 삽입한다.

5.  한글 IME 조합 중에도 입력을 처리한다.

6.  자동 줄바꿈된 긴 원본 줄에서도 커서가 편집기 높이를 벗어나면 커서가 보이도록 편집기와 줄 번호 영역을 함께 스크롤한다.

7. Shift+Tab은 탭 문자를 삽입하지 않고 브라우저의 기본 역방향 포커스 이동으로 편집기에서 빠져나간다.

## 09. 편집기 - 줄바꿈과 표시

1. 자동 줄바꿈으로 표시 줄이 늘어나면 LINE 번호도 같은 개수로 연속해서 표시한다.

2. 편집 내용을 바꾸면 새 자동 줄바꿈 결과에 맞춰 LINE 번호를 갱신한다.

3. 화면 너비가 좁아지거나 넓어지면 표시 줄 수와 LINE 번호를 함께 늘리거나 줄인다.

4. 분할 패널의 너비를 조정하면 해당 편집기의 표시 줄과 LINE 번호를 다시 계산한다.

5. 자동 줄바꿈된 번호를 선택하면 같은 원본 줄의 모든 표시 줄을 강조한다.

6. PC 편집기 글자 크기는 19px, 줄 높이는 35px, 줄 번호 영역 너비는 39px로 표시한다.

7. 모바일 편집기 글자 크기는 19px, 줄 높이는 39px, 줄 번호 영역 너비는 41px로 표시한다.

8. 줄 번호와 선택 강조 영역을 같은 줄 높이에 맞춰 정렬하고 선택 색상은 줄 전체를 채운다.

9. 화면 너비가 바뀌어 자동 줄바꿈 수가 달라져도 개행 기준 줄 선택 데이터를 유지하고 같은 원본 줄의 표시 줄을 다시 강조한다.

10. PC와 모바일 편집기는 10px 상단 여백과 동일한 편집기·줄 번호 안쪽 여백을 유지한다.

## 10. 편집기 - 실행 취소

1. Cmd/Ctrl+Z로 실행 취소하고 Cmd/Ctrl+Shift+Z 또는 Cmd/Ctrl+Y로 다시 실행한다.

2. 실행 취소 기록은 탭별로 독립적으로 관리한다.

3. 탭별 실행 취소 기록은 최대 100개를 보관한다.

4. 탭을 분할 패널 사이로 이동해도 해당 탭의 실행 취소와 다시 실행 기록을 유지한다.

5. 실행 취소 후 새 내용을 편집하면 기존 다시 실행 기록을 제거해 새 편집 분기에서 Redo가 이전 내용을 복원하지 않게 한다.

## 11. 줄 선택

1. Shift+클릭으로 기준 줄부터 클릭한 줄까지 범위를 선택하고, 선택한 범위를 다시 Shift+클릭하면 해제한다.

2. Shift+클릭한 줄이 이미 선택된 연속 블록에 속하면 해당 블록 전체를 해제하고 나머지 선택 블록은 유지한다.

3. 줄 번호를 클릭하거나 키보드로 선택하면 줄 번호의 배경색과 글자색을 활성 탭 색상으로 강조한다. 선택하지 않은 줄 번호는 검은 배경을 유지한다.

4. 첫 번째 줄의 선택 배경은 편집기 상단 여백까지 이어진다.

5. 첫 번째 줄을 선택한 채 스크롤하면 선택 배경이 줄 번호와 함께 이동해 상단에 잔상을 남기지 않는다.

6. 줄 번호를 마우스로 클릭하거나 Shift+클릭해도 줄 주변에 포커스 테두리를 표시하지 않는다.

7. 선택한 줄은 노트별로 저장하고 탭을 전환해도 각 노트의 선택을 복원한다.

8. 줄 선택과 선택 해제 결과는 새로고침 후 복원한다.

9. 저장한 줄 선택은 PC와 모바일에서 동일하게 유지한다.

## 12. 분할 패널 - 기본 동작

1. 탭 제목을 다른 패널의 편집기 영역에 직접 드롭해 해당 패널로 이동할 수 있다.

2. 탭 제목을 다른 패널의 탭 행에 드롭해 해당 패널로 이동할 수 있다.

3. 왼쪽 패널의 탭을 `Split right` 영역에 드롭해 좌우 분할 화면을 만든다.

4. 분할 표시가 렌더링되기 전에 편집기 오른쪽 위가 드롭을 받아도 좌우 분할한다.

5. 각 패널은 자체 탭 목록과 활성 탭을 가진다.

6. 구분선을 드래그해 너비 비율을 조정하며 각 패널은 20%~80% 범위로 제한한다.

7. 오른쪽 패널의 마지막 탭을 왼쪽으로 옮기면 분할 화면을 해제한다.

8. 오른쪽 패널의 내용이 있는 탭도 확인 없이 닫고 남은 패널 배치를 정리한다.

9. 분할 비율은 앱 재접속 시 중앙으로 초기화한다.

10. 오른쪽 패널에 새 탭을 추가하면 분할선을 중앙으로 조정한다.

## 13. 분할 패널 - 다중 분할

1. 좌우 각 열은 `Split down`으로 상하 분할하며 좌상·좌하·우상·우하 최대 4개 패널까지 확장한다.

2. 상하 구분선으로 각 패널의 높이 비율을 조정하며 20%~80% 범위로 제한한다.

3. 왼쪽과 오른쪽 열의 상하 분할 비율은 서로 독립적으로 관리한다.

4. 상하 분할 비율은 앱 재접속 시 중앙으로 초기화한다.

5. 하단 패널의 마지막 탭을 닫으면 해당 열의 상하 분할을 해제한다.

6. 상단 패널이 비면 같은 열의 하단 패널을 상단으로 올린다.

7. 왼쪽 열이 모두 비면 오른쪽 열을 왼쪽으로 옮긴다.

8. 4분할 배치와 각 패널의 활성 탭은 새로고침 후 복원한다.

9. Alt+위/아래 화살표는 좌상→좌하→우상→우하 순서로 패널 경계를 넘어 이동한다.

## 14. 분할 패널 - All Group

1. All Group에서도 탭 제목을 드래그해 좌우 분할한다.

2. All Group의 좌우 분할 배치는 별도로 저장해 새로고침 후 복원한다.

3. All Group 분할은 탭 소속과 각 소속 그룹의 분할 배치를 변경하지 않는다.

4. All Group에서도 `Split down`과 `Split right`로 최대 4분할한다.

5. 그룹을 전환했다 All Group으로 돌아오면 이전 활성 탭과 활성 편집기를 유지한다.

6. 그룹을 전환했다 All Group으로 돌아오면 이전 4분할 배치를 복원한다.

7. All Group의 분할 편집기 사이로 탭을 옮기고 활성 상태를 저장한다.

8. All Group 분할 편집기의 새 탭은 현재 패널에 표시하고 `Ungrouped` 소속으로 저장한다.

9. All Group 분할 편집기에서 추가한 탭을 닫으면 원래 탭으로 돌아온다.

10. All Group 분할 편집기의 마지막 탭을 닫으면 빈 패널을 정리한다.

## 15. 단축키

1. Alt+Tab은 활성 패널에 새 탭을 추가한다.

2. Alt+위/아래 화살표는 같은 패널의 탭 사이를 이동한다.

3. 분할 상태의 Alt+위/아래 화살표는 패널 경계를 넘어 이동한다.

4. 편집기에 포커스가 있을 때 Cmd+A 또는 Alt+A로 편집기 내용 전체를 선택한다.

5. 북마크 검색 입력에 포커스가 있으면 Cmd+A 입력 즉시 검색어 전체를 선택한다.

6. 그룹 이름 입력에 포커스가 있으면 Cmd+A 입력 즉시 그룹 이름 전체를 선택한다.

## 17. 탭 - 단축키 닫기

1. Alt/Option+Backspace는 빈 활성 탭을 바로 닫는다.

2. Alt/Option+Backspace는 내용이 있는 활성 탭도 확인 없이 바로 닫는다.

## 19. 편집기 - 터치 동작

1. 편집기를 한 번 터치하면 브라우저가 정한 접힌 커서 위치를 유지하고 문서 끝으로 재설정하지 않는다.

2. 좌우 분할 편집기를 터치해 전환할 때도 각 터치로 정한 커서 위치를 유지한다.

## 20. 줄 선택 - 편집 동기화

1. 줄을 삽입하면 기존 선택 위치를 새 줄 번호에 맞춰 이동한다.

2. 선택한 줄을 삭제하면 해당 선택을 제거하고 남은 선택 위치를 맞춘다.

3. 편집으로 이동한 줄 선택 위치는 새로고침 후 복원한다.

## 21. 분할 패널 - 드롭 영역

1. 우측 편집기가 비어 있으면 `Split right`를 대상 패널의 오른쪽 절반에 표시한다.

2. 우하단 편집기가 비어 있으면 좌하단 패널에도 `Split right`를 표시한다.

3. `Split right`와 `Split down`을 함께 표시하면 각각 우상단과 하단 영역을 사용한다.

4. `Move here`는 표시 중인 분할 영역과 겹치지 않는 나머지 영역을 사용한다.

5. `Split down`은 포인터가 편집기 높이의 중앙보다 아래에 있을 때만 표시한다.

6. 원래 패널에 탭이 하나뿐이면 해당 탭의 분할 영역을 표시하지 않는다.

7. 마지막 탭을 다른 기존 패널로 옮길 때 대상에는 `Move here`만 표시한다.

8. 4분할 상태의 기존 패널에는 추가 분할 없이 `Move here`만 표시한다.

9. 탭 제목을 편집기 하단으로 직접 드래그해 상하 분할한다.

10. 분할 표시가 렌더링되기 전에 편집기가 드롭을 받아도 현재 좌표에 맞춰 상하 분할한다.

## 23. 분할 패널 - 복합 우측 이동

1. 일반 그룹의 하단 탭은 기존 우상단 탭을 유지하고 비어 있는 우하단으로 이동한다.

2. All Group의 하단 탭도 기존 우상단 탭을 유지하고 비어 있는 우하단으로 이동한다.

3. 일반 그룹에 오른쪽 열이 없으면 하단 탭을 새 오른쪽 열의 상단으로 이동한다.

4. All Group에 오른쪽 열이 없으면 하단 탭을 새 오른쪽 열의 상단으로 이동한다.

5. 일반 그룹의 하단 탭 3을 `Split right`로 옮겨도 상단 탭 1과 하단 탭 2를 유지한다.

6. All Group의 하단 탭 3을 `Split right`로 옮겨도 상단 탭 1과 하단 탭 2를 유지한다.

7. 일반 그룹에서 하단 탭을 기존 우상단 아래로 옮긴 복합 분할 배치는 새로고침 후 복원한다.

8. All Group에서 하단 탭을 기존 우상단 아래로 옮긴 복합 분할 배치는 새로고침 후 복원한다.

## 24. 분할 패널 - 기존 영역 이동

1. 우측의 마지막 탭은 좌하단에 `Move here`로 합치고 비어진 우측 패널을 정리한다.

2. 우측에 다른 탭이 남으면 좌하단에는 `Move here`만 표시하고 기존 우측 패널을 유지한다.

## 25. 단축키 - 패널 이동

1. macOS에서 Option+F12는 활성 탭을 오른쪽 열의 상단 패널로 이동한다.

2. macOS에서 Option+F11은 활성 탭을 왼쪽 열의 상단 패널로 이동한다.

3. 이미 오른쪽 열에 있는 탭에는 Option+F12를 적용하지 않는다.

4. 왼쪽 패널에 탭이 하나만 남으면 Option+F12 이동을 수행하지 않는다.

5. 이미 왼쪽 열에 있는 탭에는 Option+F11을 적용하지 않는다.

## 28. 탭 메뉴 - 그룹 이동 정렬

1. 그룹 목록은 한글로 시작하는 이름을 먼저 배치하고 한국어 기준 문자순으로 정렬한다.

2. 그룹 목록은 고정 그룹을 일반 그룹보다 먼저 배치한다.

3. 그룹 이동 대상에 포함된 `Ungrouped`는 목록의 맨 아래에 배치한다.

## 29. 줄 선택 - 전환과 이동

1. 그룹을 전환했다 돌아와도 노트별 줄 선택을 유지한다.

2. 탭을 분할 패널 사이로 이동해도 해당 노트의 줄 선택을 유지한다.

3. 분할 패널로 이동한 탭의 줄 선택은 새로고침 후 복원한다.

## 30. 분할 패널 - 빈 영역 정리

1. 오른쪽 패널의 마지막 탭을 닫으면 분할 화면을 해제한다.

2. 하단 패널의 마지막 탭을 다른 패널로 옮기면 해당 열의 상하 분할을 해제한다.
