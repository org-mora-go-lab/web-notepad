# 13. 대시보드 설정 복구

> E2E: `tests/06. 데이터 복원/13. 대시보드 설정 복구/`

1. 보조 상태가 아닌 저장 상태 문자열은 탭 색상으로 다시 판정한다.
2. Note 보조 상태는 주기 색상보다 우선해 복원한다.
3. 상태 표시명이 배열로 손상되면 기본 상태명을 사용한다.
4. 저장된 사용자 상태명 양끝 공백은 제거한다.
5. 너무 긴 사용자 상태명은 30자로 제한해 복원한다.
6. 빈 상태명과 알 수 없는 상태 키는 복원하지 않는다.
7. 문자열로 저장된 보조 상태 표시값은 참으로 취급하지 않는다.
8. 전체 그룹과 개별 그룹의 보조 상태 표시 설정을 별도로 복구한다.
9. 색상 주기에 중복 색상이 있으면 기본 주기로 복구한다.
10. 지원하지 않는 색상을 포함한 주기는 기본 주기로 복구한다.
