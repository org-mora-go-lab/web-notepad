# 12. 북마크와 보관 기록 복구

> E2E: `tests/06. 데이터 복원/12. 북마크와 보관 기록 복구/`

1. 북마크 목록에서 ID가 없는 손상 항목만 제거한다.
2. 원본 ID가 손상된 북마크도 내용을 보존해 검색할 수 있다.
3. 문자열이 아닌 북마크 제목과 내용은 안전한 표시값으로 복구한다.
4. 북마크 줄 선택은 유효한 인덱스만 중복 없이 복구한다.
5. 북마크 수정 시간이 손상되면 유효한 생성 시간을 사용한다.
6. 보관 기록 목록이 손상되어도 현재 편집 노트를 복구한다.
7. 보관 기록의 필수 ID나 원본 탭이 없으면 해당 기록만 제외한다.
8. 보관된 탭은 잘못 저장된 열림과 고정 상태를 해제한다.
9. 보관된 노트도 색상과 줄 선택을 정규화하면서 내용은 보존한다.
10. 그룹의 모든 탭이 닫혔으면 기존 데이터를 지우지 않고 새 편집 탭을 만든다.
