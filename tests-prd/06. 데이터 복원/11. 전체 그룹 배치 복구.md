# 11. 전체 그룹 배치 복구

> E2E: `tests/06. 데이터 복원/11. 전체 그룹 배치 복구/`

1. 전체 그룹에 저장된 유효한 분할은 개별 그룹 배치와 독립적으로 복원한다.
2. 전체 그룹 분할에서 사라진 원본 탭 ID를 제거한다.
3. 전체 그룹 분할에서 편집기에 닫힌 탭은 제외한다.
4. 전체 그룹의 중복 분할 배정도 탭을 복제하지 않는다.
5. 전체 그룹의 잘못된 활성 분할은 기본 분할로 복구한다.
6. 전체 그룹의 빈 왼쪽 열은 오른쪽 노트를 승격해 복구한다.
