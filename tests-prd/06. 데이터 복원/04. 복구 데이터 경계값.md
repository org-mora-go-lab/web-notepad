# 04. 복구 데이터 경계값

> E2E: `tests/06. 데이터 복원/04. 복구 데이터 경계값/`

1. 저장 상태가 null이면 기본 작업공간으로 복구한다.
2. 존재하지 않는 활성 그룹 ID는 Ungrouped로 복구한다.
3. 그룹 이름이 문자열이 아니면 Untitled Group으로 복구한다.
4. Ungrouped의 잘못된 고정 상태는 해제한다.
5. 지원하지 않는 글자 배율은 90%로 복구한다.
6. 지원하지 않는 언어는 영어로 복구한다.
7. 지원하지 않는 패널 위치는 오른쪽으로 복구한다.
8. 불리언이 아닌 패널 슬라이드 값은 Off로 복구한다.
9. 숫자가 아닌 다음 탭 번호를 기본 숫자로 복구해 새 탭을 생성한다.
