# 10. 분할 배치 복구

> E2E: `tests/06. 데이터 복원/10. 분할 배치 복구/`

1. 존재하지 않는 분할 탭 ID를 제거하고 유효한 노트는 유지한다.
2. 닫힌 탭이 분할 목록에 남아 있어도 편집기에 다시 열지 않는다.
3. 하나의 탭이 여러 분할에 중복 배정되면 한 분할에서만 연다.
4. 왼쪽 상단이 비면 왼쪽 하단 노트를 상단으로 승격한다.
5. 오른쪽 상단이 비면 오른쪽 하단 노트를 상단으로 승격한다.
6. 왼쪽 열이 비면 오른쪽 열을 왼쪽으로 옮겨 편집 공간을 복구한다.
7. 다른 분할의 탭을 가리키는 활성 ID는 해당 분할 첫 탭으로 복구한다.
8. 빈 하단 분할을 활성 영역으로 저장했으면 존재하는 상단으로 포커스를 복구한다.
9. 배열이 아닌 분할 목록은 무시하고 노트 전체를 기본 영역에 보존한다.
10. 재방문 시 분할 비율은 중앙으로 초기화하고 탭 배정은 보존한다.
