# 04. 패널과 검색

> E2E: `tests/04. 패널과 검색/`


<br>

## 01. 우측 패널 - 열기와 닫기

1.  하단 BOOKMARK·DASHBOARD 명령을 선택하면 각각 북마크·대시보드 패널을 연다.

2.  MENU의 SHORTCUT·SETTINGS 명령을 선택하면 해당 패널을 열고 SEARCH·CLOSED는 표시하지 않는다. SHORTCUT은 PC에서만 표시한다.

3.  우측 패널은 한 번에 하나만 연다.

4.  브라우저 뒤로가기를 누르면 모바일 패널은 닫고 PC의 고정 패널은 유지한다.

5.  패널 내부 버튼에 포커스가 있어도 PC는 X, 모바일은 Escape로 패널을 닫고 메모·그룹·북마크 데이터를 유지한다.

6.  모바일의 패널과 그룹 메뉴에서 삭제·추가·닫기처럼 아이콘만 표시하는 버튼은 아이콘을 가로·세로 정중앙에 배치한다.

<br>

## 03. 우측 패널 - 고정

1.  PC와 모바일의 패널 헤더에서 핀 고정 전환 버튼을 제거한다.

2.  PC 패널은 기본으로 항상 고정하여 화면 우측에서 작업 영역과 나란히 표시한다.

3.  X로 고정 패널을 닫으면 작업 영역을 복원한다.

4.  모바일 크기에서는 작업 영역을 줄이지 않고 오버레이로 표시하며 PC 크기로 돌아오면 다시 고정한다.

5.  이전에 저장한 고정 해제 값과 관계없이 새로고침 후에도 패널은 항상 고정한다.

<br>

## 04. 우측 패널 - 경계와 레이아웃

1.  모바일 오버레이 패널 경계 바깥 11.52px에 DARK 16%·LIGHT 22% 경계색의 다단계 그라데이션을 표시한다.

2.  경계 음영은 포인터 이벤트를 받지 않아 카드 클릭과 패널 크기 조절을 막지 않는다.

3.  PC에서 패널 바깥을 클릭해도 고정 패널을 유지한다.

4.  고정 중에는 배경 덮개와 그림자·경계 그라데이션을 표시하지 않아 편집기를 계속 사용할 수 있다.

<br>

## 05. 북마크 - 목록과 빈 상태

1.  PC와 모바일의 북마크 패널은 검색창·검색 필터·검색어 하이라이트 없이 모든 북마크의 제목과 내용을 표시한다.

2.  북마크가 없으면 검색 안내 대신 `Empty Bookmarks`를 표시하고, 북마크를 추가하면 빈 목록 안내를 실제 북마크 목록으로 바꾼다.

<br>

## 06. 검색 - 전체 검색

1.  헤더 메뉴 아이콘 왼쪽에 검색 아이콘을 표시하고 선택하면 해당 아이콘 아래에 그룹 선택 패널과 같은 raised 배경·얇은 테두리·그림자의 검색 팝오버를 연다. 푸터에는 검색 진입점을 표시하지 않는다.

2.  검색어가 없으면 `Enter a search term`을 표시한다.

3.  검색어가 있으나 결과가 없으면 `No search results`를 표시한다.

4.  검색어 입력이 멈춘 뒤 0.3초가 지나면 그룹과 북마크를 대소문자 구분 없이 부분 검색하며, 입력 중에는 기존 결과를 유지한다.

5.  그룹 결과를 선택하면 해당 그룹으로 이동한다.

6.  검색은 입력과 그룹·북마크 결과 목록을 한 열로 표시하고, 북마크를 선택하면 선택 행을 강조하고 제목·그룹·내용의 미리보기를 펼친다. PC는 우측, 좁은 화면은 아래에 미리보기를 표시하며 검색어를 하이라이트한다. 목록을 스크롤하면 검색창 바로 아래에 그라데이션을 표시하고 검색 입력과 목록 너비를 맞춘다.

7.  검색 팝오버는 기본 420×180px로 검색 아이콘 아래 6px에 표시하고 화면 밖으로 벗어나지 않게 보정한다. 화면을 어둡게 덮거나 편집기를 비활성화하지 않는다. 열면 검색 입력에 포커스를 주고 Escape로 닫으면 검색 아이콘으로 돌려준다. 바깥 클릭으로도 닫으며 모바일 키보드가 열리면 사용 가능한 화면 높이에 맞춘다.

8.  PC에서 검색 팝오버의 우측 경계로 너비를 조절할 수 있다. 기본 최소 너비는 320px이며 미리보기를 펼치면 기본 760px·최소 640px를 사용하고 화면 여백 안으로 제한한다. 펼친 미리보기의 좌우 구분선으로 결과와 미리보기 너비를 조절할 수 있다.

<br>

## 13. 우측 패널 - 접근성

1.  X로 패널을 닫으면 PC의 패널 진입 버튼 포커스를 해제한다.

2.  하단 패널 버튼은 X로 닫은 뒤에도 Tab 탐색에서 정상 포커스를 표시한다.

3.  닫힌 패널의 컨트롤은 Tab 순서와 접근성 탐색에서 제외하고 열린 패널의 컨트롤만 상호작용할 수 있다.

<br>

## 14. 우측 패널 - 크기 조절

1.  PC 패널 경계선은 접근 가능한 구분선과 2px 선·좌우 조절 커서·hover 강조로 표시한다.

2.  PC 패널 너비는 최소 336px부터 화면 너비의 최대 80%까지 조절한다.

3.  우측에 배치한 고정 패널의 크기를 조절할 수 있다.

4.  좌측에 배치한 고정 패널의 크기를 조절할 수 있다.

5.  화면 크기가 바뀌면 저장된 패널 너비를 현재 화면 너비의 80% 이하로 제한한다.

<br>

## 15. 고정 패널 - 닫기와 전환

1.  고정한 Bookmark 패널에서 BOOKMARK 명령을 다시 선택하면 패널을 닫는다.

2.  Escape를 눌러도 고정 패널을 닫지 않는다.

3.  그룹을 전환해도 고정 패널을 열린 상태로 유지한다.

4.  고정 대시보드에서 검색을 열면 대시보드를 유지한 채 검색 팝업을 겹쳐 표시하고, 검색을 닫아도 고정 대시보드를 계속 표시한다.

<br>

## 24. Closed 팝업

1.  대시보드 우측 상단 세로 점 메뉴의 `Note`와 유령 아이콘·`Closed` 항목은 각각 선택하면 해당 상태를 표시하고, 다시 선택하면 해당 상태를 숨긴다. 선택 후에도 메뉴를 유지하고, Closed 유령 아이콘은 채우지 않은 선 형태로 표시해 눈을 보이게 유지한다.

2.  Closed 상태의 탭을 에디터에서 열면 헤더 탭 제목에 1px 취소선을 표시하고 탭 아이콘과 강조 색상을 Green으로 표시한다. PC·모바일과 DARK·LIGHT 모두 같은 규칙을 적용하며 일반 탭에는 취소선을 표시하지 않는다.

> Note와 Closed는 기본 대시보드 카드 형식을 사용하며 Reopen·삭제 아이콘을 카드에 표시하지 않는다. 상태를 To Do·Doing·Done으로 옮기면 헤더의 Closed 표시를 해제한다.

3.  To Do·Doing·Done 카드를 Note로 이동하고, Note 카드도 To Do·Doing·Done으로 자유롭게 이동할 수 있다.

4.  To Do·Doing·Done 카드를 드래그해 Closed 상태로 이동할 수 있다.

5.  Closed 카드의 우클릭 메뉴에는 `Delete`만 표시하며 선택하면 해당 탭을 영구 삭제한다.

6.  Note 상태는 To Do 왼쪽에 밝은 검은색 컬럼으로 표시하고, To Do는 Gray, Doing은 Indigo, Done은 Teal, Closed는 Green 컬럼으로 표시한다. 두 보조 상태를 모두 선택하면 대시보드 상단 상태도 `Note · To Do · Doing · Done · Closed` 순서로 표시한다.
