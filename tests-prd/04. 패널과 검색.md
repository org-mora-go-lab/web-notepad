# 04. 패널과 검색

> E2E: `tests/04. 패널과 검색/`

## 01. 우측 패널 - 열기와 닫기

1. 하단 BOOKMARK와 DASHBOARD 명령을 선택하면 각각 북마크와 대시보드 패널을 연다.

2. MENU의 SHORTCUT·SETTINGS·SEARCH 명령을 선택하면 해당 패널을 열고 CLOSED는 표시하지 않는다. SHORTCUT은 PC에서만 표시한다.

3. 그룹 선택 버튼은 우측 패널 대신 그룹 드롭다운을 연다.

4. 우측 패널은 한 번에 하나만 연다.

5. 브라우저 뒤로가기를 누르면 열린 미고정 우측 패널을 닫는다.

6. PC와 모바일에서 검색창에 포커스가 있어도 Escape로 패널을 닫고 메모·그룹·북마크 데이터를 유지한다.

7. 그룹 삭제 팝업이 열린 상태의 Escape는 팝업 취소를 우선하고 그룹 드롭다운을 유지한다.

8. Escape로 패널을 닫은 뒤에도 다시 열기와 브라우저 뒤로가기가 정상 동작한다.

## 03. 우측 패널 - 고정

1. PC 패널 헤더에는 닫기 버튼 왼쪽에 고정 버튼을 표시하고 모바일에서는 숨긴다.

2. PC에서 고정한 패널은 화면 우측에서 작업 영역과 나란히 표시한다.

3. X로 고정 패널을 닫으면 작업 영역을 복원한다.

4. 고정을 해제하면 작업 영역을 복원하고 패널을 오버레이로 전환한다.

5. 패널 고정 상태는 브라우저에 저장하고 새로고침 후 복원한다.

6. 저장된 고정 상태가 있어도 모바일에서는 전체 너비 오버레이 패널로 표시한다.

7. PC 헤더 버튼은 33.6px로 표시한다. 초기화·닫기 아이콘은 14.4px, 단축키 닫기는 19.2px, 고정은 16.8px다.

8. 모바일 헤더 닫기 버튼은 33.6px, 아이콘은 14.4px로 표시한다.

9. X로 고정 패널을 닫아도 고정 상태를 유지해 다음 패널도 고정해 연다.

## 04. 우측 패널 - 경계와 레이아웃

1. 미고정 패널 경계 바깥 11.52px에 DARK 16%·LIGHT 22% 경계색의 다단계 그라데이션을 표시한다.

2. 그라데이션은 바깥 0%, 거리 30%의 25%, 거리 65%의 65%, 패널 경계의 100%로 진해지며 좌우 배치에 따라 방향을 반전한다.

3. 경계 음영은 포인터 이벤트를 받지 않아 카드 클릭과 패널 크기 조절을 막지 않는다.

4. 경계 그라데이션은 패널을 고정하거나 닫으면 제거하고 고정을 해제하면 복원한다.

5. PC에서 미고정 패널 바깥을 클릭하면 패널을 닫는다.

6. 고정 중에는 배경 덮개와 그림자·경계 그라데이션을 표시하지 않아 편집기를 계속 사용할 수 있다.

7. 고정 패널은 열기·닫기·다시 열기에 슬라이드 효과를 적용하지 않는다.

8. 모든 사이드 패널은 PC·모바일과 좌우 배치에서 화면 전체 높이를 채운다.

9. 미고정 패널은 헤더·푸터 배치를 유지한 채 두 영역 위를 덮고 바깥 클릭 영역은 화면 전체를 채운다.

## 05. 검색 - 북마크

1. 북마크 제목과 내용을 대소문자 구분 없이 부분 검색하며 placeholder는 `Search bookmarks`다.

2. 검색창은 헤더 아래에 위쪽 14px·아래쪽 6px 여백으로 표시한다.

3. 검색어가 있는 검색창의 지우기 아이콘은 패널 닫기 버튼과 같은 옅은 회색으로 표시한다.

## 06. 검색 - 전체 검색

1. MENU에 SEARCH 명령을 표시하고 선택하면 전체 검색 패널을 연다.

2. PC와 모바일 모두 SEARCH 아이콘 오른쪽에 라벨을 표시한다.

3. 검색어가 없으면 `Enter a search term`을 표시한다.

4. 검색어가 있으나 결과가 없으면 `No search results`를 표시한다.

5. 그룹과 북마크를 대소문자 구분 없이 부분 검색한다.

6. 그룹 결과를 선택하면 해당 그룹으로 이동한다.

7. 북마크 결과를 선택하면 해당 북마크를 연다.

8. 닫은 탭은 전체 검색 결과에 포함하지 않는다.

9. 전체 검색 패널을 Escape로 닫으면 검색어를 초기화하고 다시 열 때 빈 검색 상태를 표시한다.

## 07. 대시보드 - 기본 표시와 상태

1. 하단 BOOKMARK 오른쪽에 DASHBOARD 명령을 두고 PC는 아이콘 오른쪽, 모바일은 아이콘 아래에 라벨을 표시하며 선택하면 Dashboard 패널을 연다.

2. 현재 그룹의 탭을 색상 순서에 따라 Todo·WIP·Closed 컬럼에 분류하고 상태별 개수를 표시한다.

3. 대시보드는 현재 그룹의 탭만 표시하고 패널 상단에 그룹 이름 필드를 두지 않는다.

4. 카드를 누르면 해당 탭을 활성화하고 미고정 패널을 닫는다.

5. PC는 세 상태 제목과 카드 컬럼을 가로로 나란히 표시한다.

6. 모바일은 `Todo 제목·카드 → WIP 제목·카드 → Closed 제목·카드` 순서의 한 열로 표시한다.

7. PC의 빈 컬럼은 카드 하나가 들어갈 최소 높이를 유지하고 평상시 테두리를 표시하지 않는다.

8. 모바일 빈 컬럼은 남는 패널 높이를 늘리지 않고 다음 상태 제목을 바로 이어 표시한다.

9. 탭에서 색상을 변경하면 해당 카드를 새 색상에 대응하는 컬럼으로 즉시 옮긴다.

10. 현재 색상 순서에 없는 색상의 탭은 Todo 컬럼에 표시한다.

## 08. 대시보드 - 전체 그룹과 닫은 탭

1. All Group 대시보드는 모든 그룹의 열린 탭을 모으고 카드에 소속 그룹 이름을 표시한다.

2. All Group에서 카드를 옮기면 해당 탭이 속한 그룹의 상태를 변경한다.

3. 닫힌 탭도 색상 상태에 따라 현재 그룹의 Todo·WIP·Closed 컬럼에 표시하고 개수에 포함한다.

4. All Group은 모든 그룹의 닫힌 탭을 각각의 색상 상태 컬럼에 표시하고 개수에 포함한다.

5. 닫힌 탭 카드를 누르면 색상 상태와 내용을 유지한 채 편집기에 다시 연다.

6. 고정·북마크 탭의 카드 우측 상단에 해당 색상의 아이콘을 표시하고, 북마크 아이콘은 내부 채움 없이 윤곽선만 표시하며, 둘 다이면 가로로 나란히 둔다.

7. 내용이 비어 있는 탭은 카드와 컬럼 개수에서 제외한다.

8. 대시보드에서 다시 연 탭을 닫으면 내용 길이와 관계없이 확인 없이 다시 보관한다.

9. 원래 그룹이 삭제된 닫은 탭은 Ungrouped의 색상 상태 컬럼에 표시하고 Ungrouped로 복원한다.

10. 각 상태 컬럼의 카드는 고정, 북마크, 일반 순서로 표시하고 같은 우선순위에서는 기존 순서를 유지한다.

## 10. 대시보드 - 드래그 예외 처리

1. 대시보드 카드가 아닌 외부 데이터는 강조하거나 상태를 변경하지 않는다.

2. 닫힌 카드를 현재 상태 컬럼에 다시 드롭해도 복원하거나 중복 보관하지 않는다.

3. 공백·탭·개행만 있는 열린 탭은 카드와 개수에서 제외한다.

4. 공백·탭·개행만 있는 닫은 탭은 카드와 개수에서 제외한다.

5. 열린 카드를 원래 컬럼에 다시 드롭해도 카드·탭을 중복 생성하지 않는다.

6. 일반적이지 않은 ID의 닫힌 탭 카드를 WIP으로 옮기면 닫힌 상태를 유지하고 대상 색상을 적용한다.

7. 일반적이지 않은 ID의 닫힌 탭 카드를 Todo로 옮기면 닫힌 상태를 유지하고 대상 색상을 적용한다.

## 11. 대시보드 - 포커스와 스크롤

1. 현재 탭 카드는 상태 색상의 12% 배경과 50% 불투명도 1px 테두리로 강조하고 추가 외곽선 없이 접근성 현재 표시를 제공한다.

2. 고정 대시보드에서 다른 카드를 선택하면 편집기 활성 탭과 카드 강조를 함께 옮긴다.

3. PC 대시보드 헤더는 카드 목록을 스크롤해도 상단에 고정한다.

4. 모바일 대시보드 헤더는 카드 목록을 스크롤해도 상단에 고정한다.

5. PC 상태 제목은 카드 목록을 스크롤해도 고정되고 카드는 함께 이동한다.

6. 모바일 상태 제목과 카드는 하나의 세로 흐름에서 함께 스크롤한다.

7. 상태와 카드 콘텐츠는 컬럼별 스크롤 없이 `dashboard-list` 하나만 세로 스크롤한다.

8. PC 상태 제목 오른쪽 여백은 14px에 실제 스크롤바 너비를 더하고 스크롤바가 사라지면 14px로 돌아간다.

## 12. 대시보드 - 모바일 상태 표시

1. 모바일 카드에 Todo·WIP·Closed 상태 변경 버튼을 표시하지 않는다.

2. 모바일의 각 상태 영역 왼쪽에 상태 제목부터 카드 목록 끝까지 이어진 3px 세로선을 표시하고, 상태 색상을 70% 불투명도로 적용한다.

3. 모바일의 Todo·WIP·Closed 상태 영역 사이는 15px 간격으로 표시한다.

## 13. 우측 패널 - 접근성

1. Escape로 패널을 닫으면 PC의 패널 진입 버튼 포커스를 해제한다.

2. Escape로 패널을 닫으면 모바일의 패널 진입 버튼 포커스를 해제한다.

3. 하단 패널 버튼은 Escape로 닫은 뒤에도 Tab 탐색에서 정상 포커스를 표시한다.

4. MENU 패널 명령은 Escape로 닫은 뒤에도 방향키 탐색에서 정상 포커스를 표시한다.

5. 닫힌 패널의 컨트롤은 Tab 순서와 접근성 탐색에서 제외하고 열린 패널의 컨트롤만 상호작용할 수 있다.

## 14. 우측 패널 - 크기 조절

1. PC 패널 경계선은 접근 가능한 구분선과 2px 선·좌우 조절 커서·hover 강조로 표시한다.

2. PC 패널 너비는 최소 320px부터 화면 너비의 최대 80%까지 조절한다.

3. 우측에 배치한 미고정 패널의 크기를 조절할 수 있다.

4. 우측에 배치한 고정 패널의 크기를 조절할 수 있다.

5. 좌측에 배치한 미고정 패널의 크기를 조절할 수 있다.

6. 좌측에 배치한 고정 패널의 크기를 조절할 수 있다.

7. 화면 크기가 바뀌면 저장된 패널 너비를 현재 화면 너비의 80% 이하로 제한한다.

8. 모바일은 크기 조절 경계선을 숨기고 화면 전체 너비 패널을 유지한다.

## 15. 고정 패널 - 닫기와 전환

1. 고정한 Bookmark 패널에서 BOOKMARK 명령을 다시 선택하면 패널을 닫는다.

2. 고정한 Dashboard 패널에서 DASHBOARD 명령을 다시 선택하면 패널을 닫는다.

3. Escape를 눌러도 고정 패널을 닫지 않는다.

4. 그룹을 전환해도 고정 패널을 열린 상태로 유지한다.

5. 브라우저 뒤로가기로도 고정 패널을 닫지 않는다.

6. 북마크를 열어도 고정된 북마크 패널을 유지한다.

7. 닫힌 탭을 다시 열어도 고정된 Dashboard 패널을 유지한다.

8. 다른 패널 명령을 선택하면 고정 상태를 유지한 채 해당 패널로 전환한다.

## 17. 대시보드 - PC 상태 이동

1. PC 카드에는 모바일 상태 이동 버튼을 표시하지 않는다.

2. PC에서 카드를 다른 컬럼으로 드래그하면 상태와 탭 색상을 대상 컬럼에 맞게 변경한다.

3. 드래그로 변경한 상태는 브라우저에 저장하고 새로고침 후 복원한다.

4. 짧은 일반 탭의 열린 카드를 Closed로 옮겨도 편집기에 열린 상태를 유지한다.

5. 북마크된 긴 탭의 열린 카드를 Closed로 옮겨도 편집기에 열린 상태를 유지한다.

6. 고정 탭을 Closed로 옮기면 확인 팝업 없이 고정과 열린 상태를 유지한다.

7. 고정 탭의 Closed 상태는 새로고침 후에도 유지한다.

8. PC에서 대시보드 탭 카드에 마우스를 올려도 기본 포인터를 표시하며 드래그 동작은 유지한다.

## 18. 대시보드 - 닫은 탭 상태 이동

1. 닫힌 Closed 카드를 Todo로 옮기면 Todo 색상을 적용하고 닫힌 상태를 유지한다.

2. 닫힌 Closed 카드를 WIP으로 옮기면 WIP 색상을 적용하고 닫힌 상태를 유지한다.

## 23. 대시보드 - 탭 카드 메뉴

1. PC에서 대시보드 탭 카드의 우클릭 메뉴에는 Pin·Unpin을 표시하지 않는다.

2. PC에서 열린 탭 카드의 우클릭 메뉴로 북마크 상태를 전환할 수 있다.

3. PC에서 열린 탭 카드의 우클릭 메뉴로 현재 그룹이 아닌 다른 그룹으로 이동할 수 있다.

4. PC에서 Closed 컬럼의 닫힌 탭 카드를 우클릭하면 탭 메뉴를 열고, 북마크 상태를 전환해도 닫힌 상태를 유지한다.

5. PC에서 Closed 컬럼의 닫힌 탭 카드를 우클릭하면 탭 메뉴를 열고, 다른 그룹으로 이동해도 닫힌 상태를 유지한다.
