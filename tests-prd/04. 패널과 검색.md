# 04. 패널과 검색

> E2E: `tests/04. 패널과 검색/`


<br>

## 01. 우측 패널 - 열기와 닫기

1.  하단 BOOKMARK·DASHBOARD 명령을 선택하면 각각 북마크·대시보드 패널을 연다.

2.  MENU의 SHORTCUT·SETTINGS 명령을 선택하면 해당 패널을 열고 SEARCH·CLOSED는 표시하지 않는다. SHORTCUT은 PC에서만 표시한다.

3.  우측 패널은 한 번에 하나만 연다.

4.  브라우저 뒤로가기를 누르면 열린 미고정 우측 패널을 닫는다.

5.  PC와 모바일에서 검색창에 포커스가 있어도 Escape로 패널을 닫고 메모·그룹·북마크 데이터를 유지한다.

6.  모바일의 패널과 그룹 메뉴에서 삭제·추가·닫기처럼 아이콘만 표시하는 버튼은 아이콘을 가로·세로 정중앙에 배치한다.

<br>

## 03. 우측 패널 - 고정

1.  PC 패널 헤더에는 닫기 버튼 왼쪽에 고정 버튼을 표시하고 모바일에서는 숨긴다.

2.  PC에서 고정한 패널은 화면 우측에서 작업 영역과 나란히 표시한다.

3.  X로 고정 패널을 닫으면 작업 영역을 복원한다.

4.  고정을 해제하면 작업 영역을 복원하고 패널을 오버레이로 전환한다.

5.  패널 고정 상태는 브라우저에 저장하고 새로고침 후 복원한다.

<br>

## 04. 우측 패널 - 경계와 레이아웃

1.  미고정 패널 경계 바깥 11.52px에 DARK 16%·LIGHT 22% 경계색의 다단계 그라데이션을 표시한다.

2.  경계 음영은 포인터 이벤트를 받지 않아 카드 클릭과 패널 크기 조절을 막지 않는다.

3.  PC에서 미고정 패널 바깥을 클릭하면 패널을 닫는다.

4.  고정 중에는 배경 덮개와 그림자·경계 그라데이션을 표시하지 않아 편집기를 계속 사용할 수 있다.

<br>

## 05. 검색 - 북마크

1.  북마크 제목과 내용을 대소문자 구분 없이 부분 검색하며 placeholder는 `Search bookmarks`다.

2.  검색어가 있는 검색창의 지우기 아이콘은 패널 닫기 버튼과 같은 옅은 회색으로 표시한다.

<br>

## 06. 검색 - 전체 검색

1.  푸터의 BOOKMARK 왼쪽에 SEARCH 명령을 표시하고 선택하면 전체 검색 팝업을 연다.

2.  검색어가 없으면 `Enter a search term`을 표시한다.

3.  검색어가 있으나 결과가 없으면 `No search results`를 표시한다.

4.  그룹과 북마크를 대소문자 구분 없이 부분 검색한다.

5.  그룹 결과를 선택하면 해당 그룹으로 이동한다.

6.  북마크 결과를 선택하면 해당 북마크를 연다.

7.  전체 검색 팝업은 PC에서 중앙에 기존 팝업의 약 2배인 760×640px 크기로 표시하며 Escape와 배경 클릭으로 닫는다.

<br>

## 07. 대시보드 - 기본 표시와 상태

1.  하단 BOOKMARK 오른쪽에 DASHBOARD 명령을 두고 PC는 아이콘 오른쪽, 모바일은 아이콘 아래에 라벨을 표시하며 선택하면 Dashboard 패널을 연다.

2.  현재 그룹의 탭을 색상 순서에 따라 Todo·Doing·Done 컬럼에 분류하고 상태별 개수를 표시한다.

3.  대시보드는 현재 그룹의 탭만 표시하고 패널 상단에 그룹 이름 필드를 두지 않는다.

4.  카드를 누르면 해당 탭을 활성화하고 미고정 패널을 닫는다.

5.  탭에서 색상을 변경하면 해당 카드를 새 색상에 대응하는 컬럼으로 즉시 옮긴다.

6.  PC 대시보드 헤더는 고정 버튼 왼쪽에 확장 버튼을 표시하고, 브라우저 전체 화면 API를 사용하지 않은 채 페이지 viewport 전체로 확장하거나 기존 패널 크기로 축소한다.

<br>

## 08. 대시보드 - 전체 그룹과 카드 표시

1.  All 대시보드는 모든 그룹의 열린 탭을 모으고 카드에 소속 그룹 이름을 표시한다.

2.  All에서 카드를 옮기면 해당 탭이 속한 그룹의 상태를 변경한다.

3.  내용이 비어 있는 탭은 카드와 컬럼 개수에서 제외한다.

4.  각 상태 컬럼의 카드는 고정, 북마크, 일반 순서로 표시하고 같은 우선순위에서는 기존 순서를 유지한다.

<br>

## 10. 대시보드 - 드래그 예외 처리

1.  대시보드 카드가 아닌 외부 데이터는 강조하거나 상태를 변경하지 않는다.

2.  공백·탭·개행만 있는 열린 탭은 카드와 개수에서 제외한다.

<br>

## 11. 대시보드 - 포커스와 스크롤

1.  현재 탭 카드는 상태 색상의 12% 배경과 50% 불투명도 1px 테두리로 강조하고 추가 외곽선 없이 접근성 현재 표시를 제공한다.

2.  고정 대시보드에서 다른 카드를 선택하면 편집기 활성 탭과 카드 강조를 함께 옮긴다.

3.  PC 대시보드 헤더는 카드 목록을 스크롤해도 상단에 고정한다.

4.  모바일 상태 제목과 카드는 하나의 세로 흐름에서 함께 스크롤한다.

<br>

## 12. 대시보드 - 모바일 상태 표시

1.  모바일 카드에 Todo·Doing·Done 상태 변경 버튼을 표시하지 않는다.

2.  모바일의 각 상태 영역 왼쪽에 상태 제목부터 카드 목록 끝까지 이어진 3px 세로선을 표시하고, 상태 색상을 70% 불투명도로 적용한다.

3.  모바일의 Todo↔Doing과 Doing↔Done 상태 영역 사이는 각각 30px 간격으로 표시한다.

<br>

## 13. 우측 패널 - 접근성

1.  Escape로 패널을 닫으면 PC의 패널 진입 버튼 포커스를 해제한다.

2.  하단 패널 버튼은 Escape로 닫은 뒤에도 Tab 탐색에서 정상 포커스를 표시한다.

3.  닫힌 패널의 컨트롤은 Tab 순서와 접근성 탐색에서 제외하고 열린 패널의 컨트롤만 상호작용할 수 있다.

<br>

## 14. 우측 패널 - 크기 조절

1.  PC 패널 경계선은 접근 가능한 구분선과 2px 선·좌우 조절 커서·hover 강조로 표시한다.

2.  PC 패널 너비는 최소 336px부터 화면 너비의 최대 80%까지 조절한다.

3.  우측에 배치한 미고정 패널의 크기를 조절할 수 있다.

4.  좌측에 배치한 고정 패널의 크기를 조절할 수 있다.

5.  화면 크기가 바뀌면 저장된 패널 너비를 현재 화면 너비의 80% 이하로 제한한다.

<br>

## 15. 고정 패널 - 닫기와 전환

1.  고정한 Bookmark 패널에서 BOOKMARK 명령을 다시 선택하면 패널을 닫는다.

2.  Escape를 눌러도 고정 패널을 닫지 않는다.

3.  그룹을 전환해도 고정 패널을 열린 상태로 유지한다.

4.  닫힌 탭을 다시 열어도 고정된 Closed 패널을 유지한다.

5.  다른 패널 명령을 선택하면 고정 상태를 유지한 채 해당 패널로 전환한다.

<br>

## 17. 대시보드 - PC 상태 이동

1.  PC에서 카드를 다른 컬럼으로 드래그하면 상태와 탭 색상을 대상 컬럼에 맞게 변경한다.

2.  드래그로 변경한 상태는 브라우저에 저장하고 새로고침 후 복원한다.

3.  짧은 일반 탭의 열린 카드를 Done으로 옮겨도 편집기에 열린 상태를 유지한다.

4.  고정 탭을 Done으로 옮기면 확인 팝업 없이 고정과 열린 상태를 유지한다.

5.  고정 탭의 Done 상태는 새로고침 후에도 유지한다.

<br>

## 23. 대시보드 - 탭 카드 메뉴

1.  PC에서 대시보드 탭 카드의 우클릭 메뉴에는 Pin·Unpin을 표시하지 않는다.

2.  PC에서 열린 탭 카드의 우클릭 메뉴로 북마크 상태를 전환할 수 있다.

3.  PC에서 열린 탭 카드의 우클릭 메뉴로 현재 그룹이 아닌 다른 그룹으로 이동할 수 있다.

4.  PC에서 Done 카드의 우클릭 메뉴는 `Bookmark` 바로 아래에 `Closed`를 표시하고 그 아래에 그룹 이동을 표시한다.

<br>

## 24. Closed 패널

1.  그룹 드롭다운 첫 줄의 `Ungrouped` 오른쪽에 `Closed`를 표시하고, 선택하면 현재 그룹의 닫힌 탭만 Bookmark와 유사한 패널 목록으로 연다.

2.  Closed 항목의 좌측에는 `Reopen` 버튼만 표시하며, 누르면 항목이 Closed 패널에서 사라지고 원래 그룹의 Todo 열린 탭으로 추가된다.

3.  Closed 항목의 우측 삭제 버튼은 탭이 영구 삭제된다는 확인 팝업을 열며, 취소하면 항목을 유지한다.

4.  영구 삭제 확인 팝업에서 삭제를 확정하면 해당 Closed 항목을 저장 데이터에서 제거한다.

5.  대시보드의 열린 Done 탭 카드에서 `Closed`를 선택하면 해당 카드는 Done에서 사라지고 Closed 패널로 이동한다.
