# 04. 패널과 검색

> E2E: `tests/04. 패널과 검색/`


<br>

## 01. 우측 패널 - 열기와 닫기

1.  하단 BOOKMARK·DASHBOARD 명령을 선택하면 각각 북마크·대시보드 패널을 연다.

2.  MENU의 SHORTCUT·SETTINGS 명령을 선택하면 해당 패널을 열고 SEARCH·CLOSED는 표시하지 않는다. SHORTCUT은 PC에서만 표시한다.

3.  우측 패널은 한 번에 하나만 연다.

4.  브라우저 뒤로가기를 누르면 열린 미고정 우측 패널을 닫는다.

5.  PC와 모바일에서 검색창에 포커스가 있어도 Escape로 패널을 닫고 메모·그룹·북마크 데이터를 유지한다.

6.  모바일의 패널과 그룹 메뉴에서 삭제·추가·닫기처럼 아이콘만 표시하는 버튼은 아이콘을 가로·세로 정중앙에 배치한다.

<br>

## 03. 우측 패널 - 고정

1.  PC 패널 헤더에는 닫기 버튼 왼쪽에 고정 버튼을 표시하고 모바일에서는 숨긴다.

2.  PC에서 고정한 패널은 화면 우측에서 작업 영역과 나란히 표시한다.

3.  X로 고정 패널을 닫으면 작업 영역을 복원한다.

4.  고정을 해제하면 작업 영역을 복원하고 패널을 오버레이로 전환한다.

5.  패널 고정 상태는 브라우저에 저장하고 새로고침 후 복원한다.

<br>

## 04. 우측 패널 - 경계와 레이아웃

1.  미고정 패널 경계 바깥 11.52px에 DARK 16%·LIGHT 22% 경계색의 다단계 그라데이션을 표시한다.

2.  경계 음영은 포인터 이벤트를 받지 않아 카드 클릭과 패널 크기 조절을 막지 않는다.

3.  PC에서 미고정 패널 바깥을 클릭하면 패널을 닫는다.

4.  고정 중에는 배경 덮개와 그림자·경계 그라데이션을 표시하지 않아 편집기를 계속 사용할 수 있다.

<br>

## 05. 검색 - 북마크

1.  북마크 제목과 내용을 대소문자 구분 없이 부분 검색하며 placeholder는 `Search bookmarks`다.

2.  검색어가 있는 검색창의 지우기 아이콘은 패널 닫기 버튼과 같은 옅은 회색으로 표시한다.

<br>

## 06. 검색 - 전체 검색

1.  푸터의 BOOKMARK 왼쪽에 SEARCH 명령을 표시하고 선택하면 전체 검색 팝업을 연다.

2.  검색어가 없으면 `Enter a search term`을 표시한다.

3.  검색어가 있으나 결과가 없으면 `No search results`를 표시한다.

4.  그룹과 북마크를 대소문자 구분 없이 부분 검색한다.

5.  그룹 결과를 선택하면 해당 그룹으로 이동한다.

6.  북마크 결과를 선택하면 에디터나 활성 그룹을 바꾸지 않고 팝업 우측에 해당 탭의 제목·그룹·내용을 표시하며, 각 영역에 일치하는 검색어를 하이라이트한다. 기존 검색 입력과 결과 목록은 왼쪽에 유지한다.

7.  전체 검색 팝업은 PC에서 중앙에 912×640px 크기로 표시하며 Escape와 배경 클릭으로 닫는다.

8.  PC에서 전체 검색 팝업의 우측 경계를 가로로 드래그해 최소 640px부터 화면 여백 안의 최대 폭까지 조절할 수 있다.

<br>

## 13. 우측 패널 - 접근성

1.  Escape로 패널을 닫으면 PC의 패널 진입 버튼 포커스를 해제한다.

2.  하단 패널 버튼은 Escape로 닫은 뒤에도 Tab 탐색에서 정상 포커스를 표시한다.

3.  닫힌 패널의 컨트롤은 Tab 순서와 접근성 탐색에서 제외하고 열린 패널의 컨트롤만 상호작용할 수 있다.

<br>

## 14. 우측 패널 - 크기 조절

1.  PC 패널 경계선은 접근 가능한 구분선과 2px 선·좌우 조절 커서·hover 강조로 표시한다.

2.  PC 패널 너비는 최소 336px부터 화면 너비의 최대 80%까지 조절한다.

3.  우측에 배치한 미고정 패널의 크기를 조절할 수 있다.

4.  좌측에 배치한 고정 패널의 크기를 조절할 수 있다.

5.  화면 크기가 바뀌면 저장된 패널 너비를 현재 화면 너비의 80% 이하로 제한한다.

<br>

## 15. 고정 패널 - 닫기와 전환

1.  고정한 Bookmark 패널에서 BOOKMARK 명령을 다시 선택하면 패널을 닫는다.

2.  Escape를 눌러도 고정 패널을 닫지 않는다.

3.  그룹을 전환해도 고정 패널을 열린 상태로 유지한다.

4.  다른 패널 명령을 선택하면 고정 상태를 유지한 채 해당 패널로 전환한다.

<br>

## 24. Closed 팝업

1.  그룹 드롭다운 첫 줄의 `Ungrouped` 오른쪽에 `Closed`를 표시하고, 선택하면 현재 그룹의 닫힌 탭만 팝업 목록으로 연다.

2.  Closed 항목의 좌측에는 `Reopen` 버튼만 표시하며, 누르면 항목이 Closed 팝업에서 사라지고 원래 그룹의 Todo 열린 탭으로 추가된다.

3.  Closed 항목의 우측 삭제 버튼은 탭이 영구 삭제된다는 확인 팝업을 열며, 취소하면 항목을 유지한다.

4.  영구 삭제 확인 팝업에서 삭제를 확정하면 해당 Closed 항목을 저장 데이터에서 제거한다.

5.  대시보드의 열린 Done 탭 카드에서 `Closed`를 선택하면 해당 카드는 Done에서 사라지고 Closed 팝업으로 이동한다.

6.  Closed 팝업은 PC에서 760×640px 크기로 중앙에 표시하며 Escape와 배경 클릭으로 닫는다.
