# 24. Closed 팝업

> E2E: `tests/04. 패널과 검색/24. Closed 팝업/`

1.  대시보드 우측 상단 세로 점 메뉴의 `Note`와 유령 아이콘·`Closed` 항목은 각각 선택하면 해당 상태를 표시하고, 다시 선택하면 해당 상태를 숨긴다. 선택 후에도 메뉴를 유지하고, Closed 유령 아이콘은 채우지 않은 선 형태로 표시해 눈을 보이게 유지한다.

2.  Closed 상태의 탭을 에디터에서 열면 헤더 탭 제목에 1px 취소선을 표시하고 탭 아이콘과 강조 색상을 Green으로 표시한다. PC·모바일과 DARK·LIGHT 모두 같은 규칙을 적용하며 일반 탭에는 취소선을 표시하지 않는다.

> Note와 Closed는 기본 대시보드 카드 형식을 사용하며 Reopen·삭제 아이콘을 카드에 표시하지 않는다. 상태를 To Do·Doing·Done으로 옮기면 헤더의 Closed 표시를 해제한다.

3.  To Do·Doing·Done 카드를 Note로 이동하고, Note 카드도 To Do·Doing·Done으로 자유롭게 이동할 수 있다.

4.  To Do·Doing·Done 카드를 드래그해 Closed 상태로 이동할 수 있다.

5. Closed 카드의 우클릭 메뉴에는 `Delete`와 현재 상태를 제외한 Note·To Do·Doing·Done 이동 항목을 표시한다. Delete를 선택하면 해당 탭을 영구 삭제한다.

6. Note 상태는 To Do 왼쪽에 Yellow 컬럼으로 표시하고, To Do는 Gray, Doing은 Indigo, Done은 Teal, Closed는 Green 컬럼으로 표시한다. 두 보조 상태를 모두 선택하면 대시보드 상단 상태도 `Note · To Do · Doing · Done · Closed` 순서로 표시한다.

7. Note 상태는 저장된 원래 탭 색상에 관계없이 탭 아이콘·배경·강조, 대시보드 상태 표시와 컬럼·카드 강조에 같은 Yellow 테마 색상을 적용한다. PC·모바일과 DARK·LIGHT 모두 적용하며 To Do와 구분한다.
