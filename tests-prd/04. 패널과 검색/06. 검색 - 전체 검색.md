# 06. 검색 - 전체 검색

> E2E: `tests/04. 패널과 검색/06. 검색 - 전체 검색/`

1.  그룹 사이드바 MORE의 SEARCH를 선택하면 raised 배경·얇은 테두리의 검색 모달을 연다. 헤더에는 검색 진입점을 표시하지 않는다.

2.  검색어가 없으면 `Enter a search term`을 표시한다.

3.  검색어가 있으나 결과가 없으면 `No search results`를 표시한다.

4.  검색어 입력이 멈춘 뒤 0.3초가 지나면 그룹·북마크·탭 제목과 본문을 대소문자 구분 없이 부분 검색하며, 입력 중에는 기존 결과를 유지한다.

5.  그룹 결과를 선택하면 해당 그룹으로 이동한다.

6.  검색은 입력과 그룹·북마크 결과 목록을 한 열로 표시하고, 북마크를 선택하면 선택 행을 강조하고 제목·그룹·내용의 미리보기를 펼친다. 모든 화면에서 결과 아래에 미리보기를 표시하며 검색어를 하이라이트한다. 목록을 스크롤하면 검색창 바로 아래에 그라데이션을 표시하고 검색 입력과 목록 너비를 맞춘다.

7.  검색 모달은 Edit Status처럼 화면 중앙에 최대 너비 546px·높이 540.8px로 표시하고 가장자리에서 16px 이상 떨어진다. 배경을 어둡게 덮고 뒤쪽 화면을 비활성화한다. 열 때 검색 입력에 자동 포커스를 주지 않고 Escape로 닫으면 하단 GROUP 진입점으로 돌려준다. 배경 클릭으로도 닫으며 모바일 키보드가 열리면 사용 가능한 화면 높이에 맞춘다.

8.  검색과 북마크는 PC·모바일에서 동일한 중앙 배치와 고정 너비(최대 546px, 화면 좌우 여백 16px)·높이(최대 540.8px)를 사용한다. 빈 검색·결과·미리보기 간에 외곽 크기가 변하지 않으며 미리보기는 결과 아래에서 독립 스크롤한다. 별도 가로 크기 조절은 제공하지 않는다.

9.  검색 모달의 콘텐츠 높이는 빈 검색·검색 결과·결과 없음·북마크 미리보기·검색어 삭제 상태에서 동일하게 유지한다. 화면 높이가 부족하면 화면 안에서 제한한다.

10. 북마크하지 않은 다른 그룹의 탭 본문도 검색하며 결과를 선택하면 원본 그룹과 탭으로 이동해 닫힌 탭도 다시 연다.
