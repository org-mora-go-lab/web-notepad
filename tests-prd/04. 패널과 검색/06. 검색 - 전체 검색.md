# 06. 검색 - 전체 검색

> E2E: `tests/04. 패널과 검색/06. 검색 - 전체 검색/`

1.  헤더 MENU의 SEARCH를 선택하면 raised 배경·얇은 테두리·그림자의 검색 팝오버를 연다. 푸터에는 검색 진입점을 표시하지 않는다.

2.  검색어가 없으면 `Enter a search term`을 표시한다.

3.  검색어가 있으나 결과가 없으면 `No search results`를 표시한다.

4.  검색어 입력이 멈춘 뒤 0.3초가 지나면 그룹과 북마크를 대소문자 구분 없이 부분 검색하며, 입력 중에는 기존 결과를 유지한다.

5.  그룹 결과를 선택하면 해당 그룹으로 이동한다.

6.  검색은 입력과 그룹·북마크 결과 목록을 한 열로 표시하고, 북마크를 선택하면 선택 행을 강조하고 제목·그룹·내용의 미리보기를 펼친다. PC는 우측, 좁은 화면은 아래에 미리보기를 표시하며 검색어를 하이라이트한다. 목록을 스크롤하면 검색창 바로 아래에 그라데이션을 표시하고 검색 입력과 목록 너비를 맞춘다.

7.  검색 팝오버는 기본 420×180px로 헤더 메뉴의 SEARCH 항목 아래 6px에 표시하고 화면 밖으로 벗어나지 않게 보정한다. 화면을 어둡게 덮거나 편집기를 비활성화하지 않는다. 열면 검색 입력에 포커스를 주고 Escape로 닫으면 SEARCH 항목으로 돌려준다. 바깥 클릭으로도 닫으며 모바일 키보드가 열리면 사용 가능한 화면 높이에 맞춘다.

8.  PC에서 검색 팝오버의 우측 경계로 너비를 조절할 수 있다. 기본 최소 너비는 320px이며 미리보기를 펼치면 기본 760px·최소 640px를 사용하고 화면 여백 안으로 제한한다. 펼친 미리보기의 좌우 구분선으로 결과와 미리보기 너비를 조절할 수 있다.
