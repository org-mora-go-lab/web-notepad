# 06. 검색 - 전체 검색

> E2E: `tests/04. 패널과 검색/06. 검색 - 전체 검색/`

1.  그룹 사이드바 MORE의 SEARCH를 선택하면 raised 배경·얇은 테두리의 검색 모달을 연다. 헤더에는 검색 진입점을 표시하지 않는다.

2.  검색어가 없으면 `Enter a search term`을 표시한다.

3.  검색어가 있으나 결과가 없으면 `No search results`를 표시한다.

4.  검색어 입력이 멈춘 뒤 0.3초가 지나면 그룹·북마크·탭 제목과 본문을 대소문자 구분 없이 부분 검색하며, 입력 중에는 기존 결과를 유지한다.

5.  그룹 결과를 선택하면 해당 그룹으로 이동한다.

6.  검색은 입력과 그룹·북마크 결과 목록을 한 열로 표시하고, 북마크를 선택하면 선택 행을 강조하고 제목·그룹·내용의 미리보기를 펼친다. 모든 화면에서 결과 아래에 미리보기를 표시하며 검색어를 하이라이트한다. 목록을 스크롤하면 검색창 바로 아래에 그라데이션을 표시하고 검색 입력과 목록 너비를 맞춘다.
