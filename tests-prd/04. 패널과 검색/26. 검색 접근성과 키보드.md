# 26. 검색 접근성과 키보드

> E2E: `tests/04. 패널과 검색/26. 검색 접근성과 키보드/`

1. 더보기의 검색 명령은 팝업 제어 대상을 제공하며, 선택하면 더보기는 닫히고 검색 팝업이 열린다.
2. 검색 팝업은 Search 제목으로 이름이 지정된 dialog다.
3. 검색 팝업은 비모달 상태를 명시한다.
4. 검색 팝업을 열면 검색 입력란에 초기 포커스를 둔다.
5. 검색 입력란은 Search everything 이름과 안내 문구를 제공한다.
6. 검색 닫기 버튼은 Search 이름을 포함한다.
7. Escape로 검색을 닫으면 하단 더보기 명령으로 포커스를 복원한다.
8. 검색어를 모두 지우면 검색어 입력 안내 상태로 돌아간다.
9. 검색 팝업의 외부 영역을 누르면 팝업을 닫는다.
10. 검색 팝업 크기 조절선은 수직 separator로 제공한다.
