# 26. 검색 접근성과 키보드

> E2E: `tests/04. 패널과 검색/26. 검색 접근성과 키보드/`

1. 더보기의 검색 명령은 팝업 제어 대상을 제공하며, 선택하면 더보기는 닫히고 검색 팝업이 열린다.
2. 검색 팝업은 Search 제목으로 이름이 지정된 dialog다.
3. 검색 팝업은 모달 상태를 명시한다.
4. 검색 팝업을 열 때 검색 입력란에 자동 포커스를 주지 않는다. 입력란을 직접 선택하면 포커스된다.
5. 검색 입력란은 Search everything 이름과 안내 문구를 제공한다.
6. 검색 닫기 버튼은 Search 이름을 포함한다.
