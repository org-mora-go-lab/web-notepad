# 25. 패널 의미와 포커스

> E2E: `tests/04. 패널과 검색/25. 패널 의미와 포커스/`

1. 닫힌 사이드 패널은 aria-hidden과 inert로 상호작용을 차단한다.
2. 북마크 팝업은 Bookmarks 이름의 모달 dialog다.
3. 대시보드 패널은 Dashboard 이름의 complementary 랜드마크다.
4. 설정 패널은 Settings 이름의 complementary 랜드마크다.
5. 단축키 패널은 Shortcut 이름의 complementary 랜드마크다.
6. 열린 사이드 패널의 닫기 버튼은 패널 이름을 포함한다.
