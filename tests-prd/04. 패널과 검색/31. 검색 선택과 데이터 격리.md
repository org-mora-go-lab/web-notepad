# 31. 검색 선택과 데이터 격리

> E2E: `tests/04. 패널과 검색/31. 검색 선택과 데이터 격리/`

1. 그룹별로 같은 북마크 ID가 있어도 선택한 결과의 내용만 미리보기한다.
2. 다른 그룹의 북마크 미리보기는 활성 그룹과 편집 탭을 변경하지 않는다.
3. 미리보기 선택은 원본이 없는 북마크를 새 편집 탭으로 복원하지 않는다.
4. 새 검색어에 선택한 북마크가 없으면 오래된 미리보기를 숨긴다.
5. 검색어를 좁혀도 선택 결과가 남아 있으면 미리보기를 유지한다.
6. 검색 팝업을 닫았다 다시 열면 이전 미리보기 선택을 복원하지 않는다.
