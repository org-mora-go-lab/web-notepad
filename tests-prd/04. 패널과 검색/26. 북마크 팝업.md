# 26. 북마크 팝업

> E2E: `tests/04. 패널과 검색/26. 북마크 팝업/`

1. 북마크는 검색과 같은 최대 너비 655.2px와 높이 540.8px로 PC와 모바일 모두 모달로 열고 배경을 어둡게 덮는다. 두 팝업은 기존보다 너비를 20% 늘리고, 화면 안에 머무는 범위에서 중앙보다 80px 위에 표시한다. 화면이 작으면 가장자리에서 36px 이상 떨어진다. 작업 영역을 줄이지 않으며 패널 고정·크기 조절 버튼을 제공하지 않는다.
2. 고정 대시보드가 열려 있어도 북마크는 화면 중앙보다 80px 위에 표시하고 대시보드와 작업 영역 너비를 유지한다.
3. Escape로 북마크 팝업을 닫으면 하단 GROUP 버튼으로 포커스를 돌린다.
4. 모달 배경을 클릭하면 북마크를 닫고 편집기를 계속 사용할 수 있다.
5. 대시보드가 열려 있어도 검색과 북마크 모달을 같은 위치에 배치한다. 창과 작업 영역의 너비가 변경되어도 두 모달의 크기와 위쪽 배치를 일치시킨다.
6. MORE의 BOOKMARK 팝업에는 활성 그룹과 관계없이 모든 그룹의 북마크 제목·내용·그룹명을 표시한다. 북마크 카드는 대시보드 탭 카드처럼 제목·그룹·본문 미리보기를 최대 6줄 안에 표시하도록 최대 높이를 216px로 두고, 제목·그룹·본문의 글자 크기·글꼴·색상·줄 높이를 대시보드 탭 카드와 동일하게 사용한다.
