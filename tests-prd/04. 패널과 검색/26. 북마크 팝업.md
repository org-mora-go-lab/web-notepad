# 26. 북마크 팝업

> E2E: `tests/04. 패널과 검색/26. 북마크 팝업/`

1. 북마크는 검색과 같은 고정 너비 360px와 높이 416px로 PC와 모바일 모두 우측 하단에 알람과 같은 스타일의 목록 팝업으로 열고 작업 영역을 줄이지 않으며 패널 고정·크기 조절 버튼을 제공하지 않는다.
2. 고정 대시보드가 열려 있으면 남은 작업 영역의 우측 하단에 북마크를 배치하고 대시보드와 작업 영역 너비를 유지한다.
3. Escape로 북마크 팝업을 닫으면 더보기 버튼으로 포커스를 돌린다.
4. 팝업 바깥을 클릭하면 북마크를 닫고 편집기를 계속 사용할 수 있다.
5. 대시보드가 열려 있으면 검색과 북마크 목록 팝업을 같은 작업 영역 우측 하단에 배치하여 대시보드와 겹치지 않게 한다. 창과 작업 영역의 너비가 변경되어도 기준 위치와 동일한 크기를 유지한다.
