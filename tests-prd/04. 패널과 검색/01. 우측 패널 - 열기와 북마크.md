# 우측 패널 - 열기와 북마크

> E2E: `tests/04. 패널과 검색/01. 우측 패널 - 열기와 북마크/`

1.  그룹 사이드바 MORE의 Bookmark와 하단 DASHBOARD 명령을 선택하면 각각 북마크 팝업·대시보드 패널을 연다.

2.  계정 메뉴의 Settings와 User Guide 첫 항목의 SHORTCUT 진입점을 선택하면 해당 패널을 연다.

3.  우측 패널은 한 번에 하나만 연다.

4.  브라우저 뒤로가기를 누르면 모바일 패널은 닫고 PC의 고정 패널은 유지한다.

5.  패널 내부 버튼에 포커스가 있어도 북마크 팝업은 PC와 모바일 모두 Escape로 닫고, 고정 사이드 패널은 X로 닫아 메모·그룹·북마크 데이터를 유지한다.

6.  모바일의 패널과 그룹 메뉴에서 추가·닫기처럼 아이콘만 표시하는 버튼은 최소 44px 터치 영역을 확보하고 아이콘을 가로·세로 정중앙에 배치한다. 그룹 동작 드롭다운의 삭제 버튼도 최소 44px 높이를 확보한다.

7.  PC와 모바일의 북마크 팝업은 검색창·검색 필터·검색어 하이라이트 없이 모든 북마크의 제목과 내용을 표시한다.

8.  북마크가 없으면 검색 안내 대신 `Empty Bookmarks`를 표시하고, 북마크를 추가하면 빈 목록 안내를 실제 북마크 목록으로 바꾼다.
