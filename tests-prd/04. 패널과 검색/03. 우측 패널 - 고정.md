# 03. 우측 패널 - 고정

> E2E: `tests/04. 패널과 검색/03. 우측 패널 - 고정/`

1.  PC와 모바일의 패널 헤더에서 핀 고정 전환 버튼을 제거한다.

2.  PC 패널은 기본으로 항상 고정하여 푸터 위의 화면 우측에서 작업 영역과 나란히 표시한다. 헤더와 작업 영역은 패널 왼쪽으로 줄이되, 푸터는 전체 화면 너비와 중앙 배치를 유지한다.

3.  X로 고정 패널을 닫으면 작업 영역을 복원한다.

4.  모바일 크기에서는 작업 영역을 줄이지 않고 오버레이로 표시하며 PC 크기로 돌아오면 다시 고정한다.

5.  이전에 저장한 고정 해제 값과 관계없이 새로고침 후에도 패널은 항상 고정한다.
