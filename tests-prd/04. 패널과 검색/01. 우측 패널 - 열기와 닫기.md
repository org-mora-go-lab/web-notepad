# 01. 우측 패널 - 열기와 닫기

> E2E: `tests/04. 패널과 검색/01. 우측 패널 - 열기와 닫기/`

1.  하단 BOOKMARK·DASHBOARD 명령을 선택하면 각각 북마크·대시보드 패널을 연다.

2.  그룹 사이드바 MENU의 SHORTCUT·SETTINGS 명령을 선택하면 해당 패널을 연다.

3.  우측 패널은 한 번에 하나만 연다.

4.  브라우저 뒤로가기를 누르면 모바일 패널은 닫고 PC의 고정 패널은 유지한다.

5.  패널 내부 버튼에 포커스가 있어도 PC는 X, 모바일은 Escape로 패널을 닫고 메모·그룹·북마크 데이터를 유지한다.

6.  모바일의 패널과 그룹 메뉴에서 삭제·추가·닫기처럼 아이콘만 표시하는 버튼은 최소 44px 터치 영역을 확보하고 아이콘을 가로·세로 정중앙에 배치한다.
