# 06. 데이터 복원

> E2E: `tests/06. 데이터 복원/`


## 01. 기존 데이터 - 상태 복원

1.  누락되거나 잘못된 탭 색상은 그린으로 복원한다.

2.  이전 긴급 표시 값은 참이면 그린, 거짓이면 그레이로 변환한다.

3.  존재하지 않는 그룹이나 탭을 가리키는 활성 선택을 유효한 기본 선택으로 정리한다.

4.  그룹 구조 도입 전의 최상위 탭·북마크 데이터를 기본 그룹으로 옮겨 복원한다.

5.  저장된 선택 줄의 중복·범위 초과·잘못된 인덱스는 제거하고 유효한 줄 번호를 정렬해 복원한다.

6.  저장된 탭의 `pinned`·`bookmarked` 값이 문자열·숫자 등 boolean이 아니면 `false`로 복원한다.

## 02. 기존 데이터 - 북마크와 손상 복구

1.  기존 북마크에 색상·줄 선택 정보가 없으면 그린·선택 없음으로 복원한다.

2.  저장된 그룹 배열에 null·객체가 아닌 값·ID가 없는 항목이 섞여 있어도 잘못된 항목을 건너뛰고 유효한 그룹의 노트를 복원하며 편집할 수 있다.

3.  빈 기본 그룹을 복구할 때 생성하는 탭 ID는 모든 그룹의 기존 탭과 북마크 원본 ID를 재사용하지 않는다.

4.  저장 상태에 임의 필드나 스토어 액션과 같은 이름의 필드가 포함되어도 허용된 데이터 필드만 복원한다.

5.  저장 상태에서 스토어 액션과 같은 이름의 필드를 제거한 뒤에도 노트 편집은 정상 동작한다.

6.  기존 북마크의 선택 줄에서 중복·범위 초과·잘못된 인덱스를 제거하고 유효한 줄 번호만 복원한다.

## 03. 복구 - 기본값과 액션 안정성

1.  저장된 탭에 제목·내용·고정·북마크 필드가 누락되면 빈 문자열과 `false`로 정규화해 편집 가능한 탭으로 복원한다.

2.  저장 상태에서 스토어 액션과 같은 이름의 필드를 제거한 뒤에도 탭 추가는 정상 동작한다.

3.  기본 그룹이 누락된 상태를 복구할 때 생성하는 탭 ID는 모든 그룹의 기존 탭과 북마크 원본 ID를 재사용하지 않는다.
