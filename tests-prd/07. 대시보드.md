# 07. 대시보드

> E2E: `tests/07. 대시보드/`

> 상태 표시명은 영어 `Memo`·`Ready`, 한국어 `메모`·`준비`를 사용한다. 저장된 상태 식별자 `icebox`·`todo`와 나머지 상태 이름은 유지한다.


<br>

## 01. 기본 표시와 상태

1.  하단 BOOKMARK 오른쪽에 DASHBOARD 명령을 두고 PC는 아이콘 오른쪽, 모바일은 아이콘 아래에 라벨을 표시하며 선택하면 Dashboard 패널을 연다.

2.  현재 그룹의 탭을 색상 순서에 따라 Ready·Doing·Done 컬럼에 분류하고 상태별 개수를 표시한다.

3.  PC와 모바일에서 카드가 없는 Ready에는 짧은 안내와 Add(추가) 버튼, Doing에는 점선 테두리의 짧은 안내, Done에는 짧은 완료 안내를 표시한다. 카드가 있는 상태는 빈 안내를 표시하지 않는다. 모바일은 세로 상태 영역 안에, PC는 기존 가로 컬럼 안에 배치하고 표시 문구는 언어 설정에 따른다.

4.  에디터에서 숨긴 탭의 카드를 누르면 해당 탭을 다시 열어 활성화하고 미고정 패널을 닫는다.

5.  탭에서 색상을 변경하면 해당 카드를 새 색상에 대응하는 컬럼으로 즉시 옮긴다.

6.  PC 대시보드 헤더는 고정 버튼 왼쪽에 확장 버튼을 표시하고, 브라우저 전체 화면 API를 사용하지 않은 채 페이지 viewport 전체로 확장하거나 기존 패널 크기로 축소한다.

<br>

## 02. 전체 그룹과 카드 표시

> 대시보드는 현재 그룹의 탭만 표시하고 패널 상단에 그룹 이름 필드를 두지 않는다.

1.  All Group 대시보드는 에디터에서 숨긴 탭을 포함해 모든 그룹의 탭을 모으고 카드에 소속 그룹 이름을 표시한다.

2.  All Group에서 카드를 옮기면 해당 탭이 속한 그룹의 상태를 변경한다.

3.  내용이 비어 있거나 공백·탭·개행만 있는 탭은 카드와 컬럼 개수에서 제외한다.

4.  각 상태 컬럼의 카드는 고정, 북마크, 일반 순서로 표시하고 같은 우선순위에서는 기존 순서를 유지한다.

<br>

## 03. 드래그 예외 처리

1.  대시보드 카드가 아닌 외부 데이터는 강조하거나 상태를 변경하지 않는다.

<br>

## 04. 포커스와 스크롤

1.  현재 탭 카드는 상태 색상의 12% 배경과 50% 불투명도 1px 테두리로 강조하고 추가 외곽선 없이 접근성 현재 표시를 제공한다. Memo·Closed 상태의 현재 탭 카드는 탭 자체 색상 대신 해당 상단 상태 색상으로 배경과 테두리를 강조한다.

2.  고정 대시보드에서 다른 카드를 선택하면 편집기 활성 탭과 카드 강조를 함께 옮긴다.

3.  PC 대시보드 헤더는 카드 목록을 스크롤해도 상단에 고정한다.

4.  모바일 대시보드의 첫 상태 제목과 헤더 사이는 상태 영역 사이와 동일한 30px 간격으로 표시한다. 스크롤 중에도 이 간격을 유지하며 Ready를 고정하고, Doing과 Done 영역에 차례로 진입할 때 해당 상태 제목으로 교체해 고정한다.

5.  모바일 대시보드를 위로 스크롤하면 Doing 카드 영역에 진입할 때 Doing을, Ready 영역에 진입할 때 Ready를 다시 상단에 고정한다.

6.  모바일에서 고정된 상태 제목은 자신의 왼쪽 세로선 끝까지 이동하고, 영역 끝에서 제목 아래쪽과 세로선 끝이 일치한 뒤 다음 상태 제목으로 고정을 넘긴다.

<br>

## 05. 모바일 상태 표시

1.  모바일 카드에 Ready·Doing·Done 상태 변경 버튼을 표시하지 않는다.

2.  모바일의 각 상태 제목은 위·아래 7px padding을 적용하고 Memo·Ready·Doing·Done·Closed 모두 같은 글자색을 사용한다. 카드가 있는 상태 영역 왼쪽에는 제목부터 카드 목록 끝까지 이어진 3px 세로선을 표시하고, 상태 색상을 70% 불투명도로 적용한다. Ready·Doing·Done의 빈 상태에서는 제목 왼쪽에만 상태색 선을 표시하고 본문은 옅은 테두리로 감싼다.

3.  모바일에서 Memo와 Closed를 단독 또는 동시에 표시하고 반복 전환해도 모든 상태 영역은 30px 간격의 한 열 세로 배치를 유지한다.

<br>

## 06. PC 상태 이동

1.  PC에서 카드를 다른 컬럼으로 드래그하면 상태와 탭 색상을 대상 컬럼에 맞게 변경한다.

2.  드래그로 변경한 상태는 브라우저에 저장하고 새로고침 후 복원한다.

3.  짧은 일반 탭의 열린 카드를 Done으로 옮겨도 편집기에 열린 상태를 유지한다.

4.  고정 탭을 Done으로 옮기면 확인 팝업 없이 고정과 열린 상태를 유지하고, 새로고침 후에도 Done 상태를 복원한다.

<br>

## 07. 탭 카드 메뉴

1.  PC에서 대시보드 탭 카드의 우클릭 메뉴에는 Pin·Unpin을 표시하지 않는다.

2.  PC에서 열린 탭 카드의 우클릭 메뉴로 북마크 상태를 전환할 수 있다.

3.  PC에서 열린 탭 카드의 우클릭 메뉴로 현재 그룹이 아닌 다른 그룹으로 이동할 수 있다.

4.  PC의 Ready·Doing·Done 카드 우클릭 메뉴에는 Closed 기능을 표시하지 않는다.

5.  PC에서 탭 카드를 우클릭하면 에디터에서 열지 않고 우클릭 메뉴가 열린 동안 해당 카드의 테두리만 클릭한 카드와 같은 방식으로 강조한다.

<br>

## 08. 상태 선택 메뉴

1.  PC와 모바일의 대시보드 우측 상단에 세로 점 세 개 버튼을 표시하고, 선택하면 기존 MENU와 같은 형태의 Memo·Closed 선택 항목과 Edit Status 명령을 표시한다. 기존 푸터 진입점은 제거하고, 각 항목을 선택해 상태 표시를 전환해도 선택 영역을 유지하며 선택 여부를 표시한다.

2.  그룹 선택 영역처럼 메뉴 버튼을 다시 누르거나 선택 영역 바깥을 누르면 상태 선택 영역을 닫는다.

3.  상태 선택 영역에서 Escape를 누르면 대시보드는 유지한 채 선택 영역만 닫고 세로 점 버튼으로 포커스를 돌려준다.

4.  대시보드를 닫았다 다시 열면 상태 선택 영역은 닫힌 상태로 시작하며, 선택한 Memo·Closed 상태 표시는 유지한다.

<br>

## 09. 그룹별 상태 이름

1.  PC와 모바일에서 Edit Status를 선택하면 적용 대상 그룹명과 다섯 상태의 입력란을 표시한다. 저장한 이름은 현재 그룹의 상태 제목과 메뉴에만 적용하고 새로고침과 그룹 전환 후에도 유지하며 다른 그룹과 탭 색상은 변경하지 않는다. 기본 이름은 언어에 따르고 빈 입력은 기본 이름으로 복원하며 최대 30자까지 입력한다. 이전 전역 설정의 상태 이름은 적용하지 않는다.

2.  이름 편집을 Cancel·Escape·팝업 바깥 클릭으로 취소하면 저장하지 않고 대시보드를 유지하며 세로 점 버튼으로 포커스를 돌려준다.

3.  모든 그룹에서는 Edit Status를 비활성화하고 개별 그룹을 선택하라는 안내를 표시하며 그룹별 이름을 변경하지 않는다.

<br>

## 10. 빈 상태에서 할 일 추가

1.  Ready의 Add(추가)를 누르면 현재 그룹에 기본 색상의 빈 노트를 추가하고 대시보드를 닫아 편집할 수 있게 한다. 다른 그룹은 변경하지 않으며 내용을 입력하면 Ready 카드로 표시한다.
