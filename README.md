# Mora Notepad

탭과 그룹으로 메모를 정리하는 브라우저 노트 앱. Next.js 16, React 19, TypeScript, Zustand, SCSS와 Lucide React를 사용합니다.

## 실행

```bash
npm ci
npm run dev
```

http://localhost:3100 에서 실행합니다. 기본 메모 기능은 환경 변수 없이 사용할 수 있습니다.

카카오 로그인을 사용하려면 `.env.example`을 `.env.local`로 복사하고 값을 설정합니다.

| 환경 변수 | 용도 |
| --- | --- |
| `KAKAO_REST_API_KEY` | 카카오 애플리케이션의 REST API 키 |
| `KAKAO_REDIRECT_URI` | 카카오에 등록한 콜백 주소. 로컬 기본값은 `http://localhost:3100/api/auth/oauth/kakao/callback` |
| `AUTH_SECRET` | 세션 서명에 사용할 긴 임의 문자열 |
| `KAKAO_CLIENT_SECRET` | 카카오 Client Secret을 활성화한 경우 설정 |
| `TURSO_DATABASE_URL` | Turso 데이터베이스의 `libsql://` 주소 |
| `TURSO_AUTH_TOKEN` | Turso 데이터베이스 인증 토큰. 서버 환경 변수에만 설정 |

카카오 개발자 콘솔의 **카카오 로그인 → 동의항목**에서 닉네임(`profile_nickname`)과 프로필 사진(`profile_image`)을 사용 설정해야 합니다. 로그인 시 두 항목의 동의를 요청하며, 받은 카카오 프로필을 이름과 사진으로 표시합니다. 기존 `Kakao user` 세션은 로그아웃 후 다시 로그인하면 갱신됩니다.

## 구조

`app/`은 페이지 라우팅과 인증 API, `src/1-page/`는 페이지 구성, `2-widget/`은 헤더·푸터·패널, `3-feature/`는 편집·그룹·검색·대시보드 기능, `4-entity/`는 노트 도메인과 상태 관리, `5-shared/`는 공통 UI·스타일·다국어 문구입니다.

요구사항은 [PRD.md](PRD.md), 상세 요구사항은 [tests-prd/](tests-prd/), 대응 Playwright E2E는 [tests/](tests/)에 관리합니다. 공통 fixture와 테스트 도우미 사용법은 [tests/README.md](tests/README.md)를 참고하세요.

## 기능

탭마다 메모를 작성하고 색상·북마크·줄 선택을 관리합니다. 실행 취소와 다시 실행, 탭 정렬, 드래그 앤 드롭과 다중 화면 분할을 지원합니다. 기본 글자 크기는 90%이며 설정에서 변경할 수 있습니다. 그룹을 생성·수정·삭제·고정·정렬하고, `All Group`에서 여러 그룹의 노트를 함께 확인할 수 있습니다.

대시보드는 `Note`, `To Do`, `Ready`, `Doing`, `Done` 상태로 노트를 정리합니다. 카드를 드래그해 다른 상태로 이동할 수 있으며 그룹별 상태 이름을 변경할 수 있습니다. 새 탭의 기본 상태는 `To Do`이고 `Note` 컬럼은 기본으로 숨깁니다. 우측 옵션에서 Note와 Done 표시를 전환하고, 이전 Closed 메모는 Done으로 복원합니다. 카드 우클릭 메뉴에는 그룹 이동과 북마크만 표시합니다. 상태 변경과 편집 탭 닫기는 별개의 동작입니다.

검색과 북마크는 같은 고정 높이 416px로 우측 하단에 열며, 그룹·북마크 통합 검색은 모든 탭의 제목·본문을 포함하며 검색어·결과·미리보기 여부와 관계없이 콘텐츠 높이를 유지합니다. 검색 결과 미리보기, 닫은 탭 복원을 제공합니다. 그룹·탭·분할 화면과 패널 탐색은 브라우저 뒤로가기·앞으로가기를 지원합니다. 모바일에서는 뒤로가기로 그룹 사이드바를 닫을 수 있습니다.

다크·라이트 테마, 글자 크기, 탭 색상 순서, 영어·한국어, 패널 위치와 슬라이드 효과를 설정할 수 있습니다. 사용 가이드와 PC 단축키 패널을 제공하며 macOS의 `Cmd+B`로 그룹 패널을 열고 닫습니다. 모바일 가이드에서는 단축키 안내와 진입점을 표시하지 않습니다.

메모·그룹·북마크와 설정은 Zustand를 통해 브라우저 localStorage에 즉시 저장하며 새로고침 후 복원합니다. 카카오 로그인과 Turso 환경 변수가 설정되면, 편집·그룹·상태·설정 등 저장 상태의 변경이 멈춘 후 0.5초 뒤 전체 상태를 한 건의 이력으로 Turso에 저장합니다. 에디터 수정 후 0.5초 대기가 끝나 저장을 전송하는 동안 실제 수정한 탭 상단 선에 빛이 왼쪽에서 오른쪽으로 흐르는 효과를 표시합니다. 움직임 줄이기 설정에서는 애니메이션을 정지합니다. 실패한 저장은 로컬 대기열에 남겨 재시도하고, 새로고침해도 대기열을 복구합니다. 같은 카카오 계정으로 접속하면 개인 그룹·탭·메모·설정을 최신 서버 이력에서 복원합니다. 초기 진입과 창 복귀·연결 복구 시 다른 기기의 변경을 가져오며, 대기 중 주기적인 조회는 수행하지 않습니다. 서버 최신 버전을 확인한 뒤 저장하며, 동시에 수정한 본문이 충돌하면 복구 탭으로 양쪽 내용을 보존합니다. 다른 계정의 로컬 작업공간을 섞어 전송하지 않습니다.

그룹 이름 오른쪽 메뉴의 **공유하기**에서 링크를 복사할 수 있습니다. 링크를 받은 사람은 카카오 로그인 후 그룹에 참여하고 글·상태·그룹 이름을 함께 수정할 수 있습니다. 참여자는 그룹 메뉴에서 나갈 수 있고, 주최자는 노트를 보존하며 공유를 취소할 수 있습니다. 공유 취소 후에는 기존 참여자·초대 링크·게시판의 접근을 해제하며 다시 공유하면 새 링크를 발급합니다. 공유 그룹은 Turso에 저장되며 초기 진입·새로고침·화면 복귀·연결 복구 시 변경 사항을 확인합니다. 각자의 편집이 멈추면 0.5초 뒤 저장하고, 저장 버전이 달라졌다면 충돌을 감지해 서로 다른 변경을 합칩니다. 계정 메뉴의 **Alarm / 알람**에는 다른 사용자의 변경자와 변경 내용이 표시됩니다. 읽지 않은 항목을 구분하며 클릭한 항목만 읽음 처리합니다. 알람 우측 상단 휴지통은 내 전체 알람을 비웁니다. 공유 링크를 가진 로그인 사용자는 편집 권한을 얻으므로 링크를 신뢰할 수 있는 사람에게만 전달하세요.

My Page는 프로필, 그룹·공유·참여·노트·북마크 수와 저장 상태를 보여줍니다. 그룹 사이드바는 개인 그룹을 My Group, 내가 공유하거나 참여한 그룹을 Shared Group으로 나누며 생성 영역과 전체 그룹 사이의 공간을 각각 50%씩 차지하고 독립적으로 접고 펼치며 스크롤할 수 있습니다. Ready 상태가 To Do와 Doing 사이에 추가되며 기존 상태 색상은 유지합니다.

로그인한 프로필 이미지·이름을 클릭하면 My Page·Alarm·Settings·Logout 메뉴가 열립니다. 알람은 프로필·이름 버튼 바로 아래 목록 팝업에 표시하고, 게시판은 더보기에서 별도 /board 페이지로 열며 그룹·노트 수·참여자 수·최근 변경 테이블을 표시합니다. My Page 하단에는 별도 설정·보드·로그아웃 버튼을 표시하지 않습니다.

## 검증

```bash
npm run lint
npm run test:e2e:structure
npm run build
npx playwright install chromium
npm run test:e2e
```

현재 E2E는 606개이며 각 번호 파일은 상세 요구사항 하나와 대응합니다. 구조 검사는 요구사항 번호·파일 대응·파일당 단일 테스트와 공통 리소스 배럴을 확인합니다. 테스트 서버는 3100 포트에서 실행하며, 인증과 파일 기반 libSQL 테스트 환경 변수는 Playwright 설정에서 제공합니다.

## 버전 및 배포

운영 반영은 `1.8.14`와 같은 버전 브랜치에서 작업하고 PR을 통해 `main`으로 병합하는 흐름을 사용합니다. 병합 후 최신 `main`을 기준으로 다음 버전 브랜치를 생성하고 `package.json`과 `package-lock.json`의 버전을 함께 갱신합니다. 변경 이력은 [versions/](versions/)에서 확인할 수 있습니다.

Vercel 배포 시 Production Branch는 `main`으로 설정합니다. 카카오 로그인을 사용한다면 배포 환경에도 인증 환경 변수를 설정하고, `KAKAO_REDIRECT_URI`를 실제 배포 도메인의 `/api/auth/oauth/kakao/callback` 주소로 카카오에 등록합니다.
Turso 저장을 사용한다면 배포 환경에 `TURSO_DATABASE_URL`과 `TURSO_AUTH_TOKEN`도 설정합니다. 이력 테이블은 첫 저장 때 자동 생성됩니다.

## 그룹 공유 게시판

더보기의 게시판에서 현재 공유 중인 모든 그룹(내 그룹 포함)을 검색하고 소개·노트 수·참여자 수를 확인합니다. 게시글을 열어 그룹 참여 또는 초대 링크 복사를 사용할 수 있습니다. 참여는 기존 카카오 로그인과 공유 그룹 초대 흐름을 사용합니다.

게시판 목록은 공유 중인 그룹에서 자동으로 구성하며 공유 취소 시 목록에서 제외합니다. 노트 본문은 공개 목록에 표시하지 않습니다.
