# 06. 데이터 복원

> E2E: `tests/06. 데이터 복원/`

## 01. 기존 데이터 - 복원

1.  저장 상태를 복원할 때 누락되거나 잘못된 필드를 기본값으로 정규화하며, 누락되거나 잘못된 탭 색상은 그린으로 복원하고 선택 줄이 없으면 선택 없음으로 복원한다.

2.  이전 긴급 표시 값은 참이면 그린, 거짓이면 그레이로 변환한다.

3.  존재하지 않는 그룹이나 탭을 가리키는 활성 선택을 유효한 기본 선택으로 정리한다.

4.  그룹 구조 도입 전의 최상위 탭·북마크 데이터를 기본 그룹으로 옮겨 복원한다.

5.  기존에 저장된 블루 탭 색상은 레드로 변환한다. 저장된 레드·그린·그레이 색상은 유지한다.

6.  저장된 선택 줄의 중복·범위 초과·잘못된 인덱스는 제거하고 유효한 줄 번호를 정렬해 복원한다.

7.  기존 북마크에 색상·줄 선택 정보가 없으면 그린·선택 없음으로 복원한다.

8.  기존 블루 북마크는 레드로 복원하며, 선택 줄의 중복·범위 초과·잘못된 인덱스는 제거한다.

9.  기존 북마크의 유효한 탭 색상과 첫 줄 선택은 복원 시 유지한다.

10. 저장된 그룹 배열에 null·객체가 아닌 값·ID가 없는 항목이 섞여 있어도 잘못된 항목을 건너뛰고 유효한 그룹의 노트를 복원하며 편집할 수 있다.

11. 빈 그룹이나 누락된 기본 그룹을 복구할 때 생성하는 탭 ID는 모든 그룹의 기존 탭과 북마크 원본 ID를 재사용하지 않는다. 이후 북마크를 열고 All Group으로 전환해도 서로 다른 노트를 독립적으로 유지한다.
