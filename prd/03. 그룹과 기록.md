# 03. 그룹과 기록

> E2E: `tests/03. 그룹과 기록/`

## 01. 그룹 - 생성과 편집

1.  하단 그룹 선택 버튼을 누르면 탭 우클릭 메뉴와 같은 형태의 그룹 드롭다운(버튼 위쪽에 표시)이 열리며, 기본 `Ungrouped` 그룹 외에 이름이 있는 그룹을 만들고 선택해 전환할 수 있다. PC에서는 그룹을 선택해도 드롭다운을 열린 채 유지하며 바깥 영역 클릭·Escape·하단 그룹 선택 버튼 재선택으로만 닫고, 모바일에서는 그룹을 선택하면 바로 닫는다. 그룹 전용 우측 패널과 그룹 검색은 없다.

2.  새 그룹 이름은 앞뒤 공백을 제거해 최대 60자로 저장한다. 이름 입력란의 placeholder는 `Group name`이다.

3.  그룹별 탭, 북마크, 활성 패널 및 분할 비율을 관리한다.

4.  기본 `Ungrouped` 그룹은 삭제할 수 없다.

5.  기본 그룹을 제외한 그룹 행의 오른쪽에는 `…`(가로 점 세 개) 버튼을 표시한다. 누르면 그 자리에 `Pin`·`Edit`·`Delete` 아이콘 버튼(고정·수정·삭제)이 나타나 선택할 수 있고, `Edit`를 누르면 행이 입력란으로 바뀌어 이름을 편집하며 `Delete`를 누르면 삭제 팝업을 연다. 앞뒤 공백을 제거하고 최대 60자로 저장하며 빈 이름은 저장하지 않는다. 고정한 그룹은 `…` 버튼 옆에 핀 아이콘을 표시한다.

6.  그룹 이름 수정은 저장·취소 버튼과 Enter 저장·Escape 취소를 지원하며 그룹 ID, 노트와 북마크는 유지한다.

7.  `All Group`·`Ungrouped` 줄 바로 아래(나머지 그룹 목록 위)에 한 줄 그룹 생성 영역(이름 입력란과 + 버튼)을 두며 Enter 또는 + 버튼으로 생성한다. 입력란은 기존 Groups 톤을 유지하고 추가 버튼의 아이콘과 테두리만 밝게 표시한다.

8.  그룹 추가 버튼과 `…`·고정·수정·삭제 버튼, 이름 수정의 저장·취소 버튼은 정사각형으로 표시한다. 추가 버튼은 PC 34px·모바일 40.8px, 나머지 버튼은 PC 28px·모바일 33.6px다.

## 02. 그룹 - 삭제

1.  그룹 삭제 시 브라우저 내장 확인창 대신 앱 내부 팝업에 `Do you want to delete {group}?`와 실제 그룹 이름을 표시한다.

2. 그룹 삭제 팝업에서 취소 버튼, 닫기, Escape 또는 바깥 영역 클릭으로 취소하면 그룹과 노트·북마크를 유지한다.

3. 그룹 삭제 팝업은 취소 버튼에 기본 포커스를 두고 팝업 안에서 키보드 포커스를 유지한다.

4. 그룹 삭제를 확인한 경우에만 그룹을 삭제하고 해당 그룹의 노트와 북마크를 `Ungrouped`로 옮긴다.

## 03. 그룹 - 정렬과 표시

1. 그룹 목록은 맨 위에 `All Group`과 `Ungrouped`를 한 줄에 나란히 두고 그 아래에 나머지 그룹을 배치한다. 나머지 그룹은 고정한 그룹을 먼저, 같은 고정 상태 안에서는 한글로 시작하는 이름을 먼저 배치해 한국어 기준 문자순으로 정렬한다.

2. 그룹 생성·이름 수정 직후와 새로고침 시에도 같은 정렬을 적용한다.

3. 새 그룹을 생성해도 그룹 드롭다운을 열린 상태로 유지하고 새 그룹을 활성 그룹으로 전환한다.

4. 현재 그룹 이름은 PC와 모바일 모두 우측 그룹 선택 버튼에 아이콘과 함께 표시하며, PC는 최대 너비 351px의 한 줄 말줄임으로 표시한다.

5. 모바일 그룹 이름은 우측 그룹 선택 버튼의 아이콘 오른쪽에 한 줄 말줄임으로 표시한다.

6. 긴 그룹 이름은 전체 이름 툴팁·접근성 라벨로 제공하며 다른 하단 라벨과 겹치지 않는다.

7. 그룹 드롭다운의 그룹 이름은 PC 15px·모바일 18px, 생성 입력은 PC 14px·높이 34px·모바일 16.8px·높이 40.8px, 이름 수정 입력은 PC 15px·높이 30px·모바일 18px·높이 36px로 표시한다.

8. 그룹 드롭다운의 맨 윗줄에는 `All Group`과 `Ungrouped`를 한 줄에 같은 너비(반씩)로 4px 간격을 두고 나란히 표시하고, 그 아래에 그룹 생성 영역, 나머지 그룹 순서로 배치한다. 모든 그룹 행은 간격 없이 PC 높이 39px·모바일 46.8px로 표시한다.

9. `Ungrouped`와 `All Group` 이름은 다른 그룹 이름보다 옅은 회색(같은 색)으로 표시한다.

## 04. 그룹 - 고정과 All Group

1. `…` 메뉴의 `Pin`을 누르면 그룹을 고정해 `All Group`·`Ungrouped` 아래 그룹 목록과 탭 메뉴의 그룹 이동 목록에서 맨 위에 배치하고 핀 아이콘을 표시한다. 고정한 그룹의 `Pin` 버튼은 `Unpin`(`고정 해제`)으로 바뀌며 누르면 고정을 해제한다. 고정 상태는 브라우저에 저장해 새로고침 후에도 유지한다.

2. 그룹 드롭다운은 바깥 영역 클릭·Escape·그룹 버튼 재선택으로 닫으며, Escape로 닫으면 그룹 선택 버튼에 포커스를 복원한다. 기본 `Ungrouped`와 `All Group`에는 `…` 버튼을 표시하지 않는다.

3. `All Group`은 그룹 목록의 맨 위에 표시한다. 가상 그룹으로 고정·수정·삭제를 지원하지 않고, 선택하면 모든 그룹의 탭을 모아 보여주며 하단 그룹 선택 버튼에 `All Group`을 표시한다. 처음에는 하나의 편집기에 표시하고 사용자가 분할한 경우 All Group 전용 분할 배치를 복원한다.

4. `All Group`에서도 탭을 수정할 수 있다. 내용 편집·색상 변경·고정·북마크·닫기·줄 선택은 탭이 속한 그룹에 적용되고, 새 탭은 `Ungrouped`에 추가한다.

5. 그룹 행의 hover 배경은 선택된 그룹 행의 배경보다 옅게(불투명도를 낮춰) 표시하고, 선택된 행은 hover해도 더 짙은 배경을 유지한다.

## 05. 북마크

1.  탭 메뉴에서 북마크를 추가하거나 해제한다. 북마크는 제목, 내용, 생성 시각, 탭 색상과 선택한 줄 번호를 보관한다.

2.  원본 탭의 내용, 색상 또는 줄 선택이 바뀌면 연결된 북마크의 제목·내용·탭 색상·선택한 줄 번호도 갱신한다.

3.  북마크 내용은 제목과 중복되는 첫 줄을 제외하고 접지 않은 전체 내용으로 항상 표시하며 `더보기`·`간소화` 버튼을 표시하지 않는다. 첫 줄 외에 내용이 없으면 편집기에서 Enter를 입력한 것처럼 높이 30px의 빈 내용 영역을 표시한다.

4.  북마크를 패널에서 제거할 수 있다.

5.  원본 탭이 남아 있는 북마크를 열면 해당 탭을 활성화한다.

6.  원본 탭이 없는 북마크를 열면 북마크의 내용, 탭 색상과 선택한 줄 번호로 탭을 복원한다.

7.  북마크 패널의 제목은 22px, 북마크 제목은 15px, 내용과 북마크 없음 문구는 16px, 검색 입력은 14px·높이 42px, 생성 시각은 12px, 동작 버튼은 13px로 표시한다. `No search results` 문구는 15px로 표시한다. 모바일은 각 글자 크기를 1.2배(제목 26.4px, 북마크 제목·`No search results` 18px, 내용·북마크 없음 문구 19.2px, 검색 입력 16.8px, 생성 시각 14.4px, 동작 버튼 15.6px)로 표시하고 검색 입력 높이 42px는 유지한다.

8.  북마크 생성 시각은 제목 길이와 관계없이 항목 우측의 고정 폭 12ch·높이 PC 32px·모바일 38px 영역에 표시하고, 긴 제목은 말줄임 처리해 시각 영역과 겹치지 않는다. PC와 모바일에 동일하게 적용한다.

9.  생성 시각의 첫 줄은 두 자리 연도의 `YY. MM. DD.`(일자 뒤에도 마침표), 둘째 줄은 초 없이 `hh:mm AM/PM` 영어 형식의 현지 시각으로 표시하며 각 줄은 줄바꿈하지 않는다.

## 06. 닫은 탭 - 보관과 복원

1.  내용이 11자 이상인 탭을 닫으면 탭과 닫을 당시의 그룹을 닫은 탭 목록의 맨 위에 보관하고 새로고침 후에도 유지한다. 빈 탭과 내용이 10자 이하인 탭은 보관하지 않고 바로 영구 삭제한다.

2.  PC와 모바일의 우측 상단 MENU에 아이콘과 `CLOSED` 라벨을 표시하고, 전체 닫은 탭 개수를 괄호 없이 표시하며 0이면 개수를 숨긴다.

3.  CLOSED를 선택하면 드롭다운을 닫고 Closed 패널을 연다. 상태 표시줄에는 CLOSED를 표시하지 않는다.

4.  닫은 탭을 복원하면 닫을 당시의 그룹으로 전환해 왼쪽 패널의 활성 탭으로 되돌리고 목록에서 제거한다. 내용, 탭 색상과 줄 선택은 유지한다.

5.  닫을 당시의 그룹이 삭제되었으면 목록에 `Ungrouped`로 표시하고 복원 시 `Ungrouped`로 되돌린다.

6.  MENU의 CLOSED 개수와 Closed 패널 목록은 현재 선택된 그룹과 관계없이 모든 그룹의 닫은 탭을 수집한다. 그룹 전환 후에도 전체 개수·목록을 유지하며 전체 검색에서도 모든 그룹의 닫은 탭을 검색한다.

7.  닫은 탭과 같은 ID의 열린 탭이 이미 있으면 충돌하지 않는 새 ID로 복원한다. 기존 탭과 복원 탭을 모두 유지하고 닫은 탭 기록을 제거하며, 새로고침 후에도 두 탭을 독립적으로 유지한다.

## 07. 닫은 탭 - 패널과 검색

1.  MENU의 CLOSED 명령을 선택하면 우측에서 모든 그룹의 닫은 탭을 모은 Closed 패널을 연다. 각 항목의 제목은 그룹 이름, 내용은 닫은 탭의 내용으로 표시하고 닫은 시각을 함께 표시한다.

2.  닫은 탭 내용은 접지 않은 전체 내용으로 항상 표시하며 `더보기`·`간소화` 버튼을 표시하지 않는다.

3.  닫은 탭 항목의 삭제 버튼을 누르면 확인 팝업 없이 즉시 영구 삭제하며 브라우저 내장 확인창도 표시하지 않는다.

4. 남은 닫은 탭 항목이 없으면 `Empty Closed`를 표시한다.

5. 그룹 이름, 탭 제목과 내용을 대소문자 구분 없이 부분 검색하며 검색창의 placeholder는 `Search closed`다. 검색 결과가 없으면 `No search results`를 표시한다.

6. 닫은 탭을 삭제해도 Closed 패널은 열린 상태로 유지하고 다른 닫은 탭 항목은 그대로 둔다.

## 08. 닫은 탭 - 시각과 재보관

1. 닫은 시각은 그룹명 길이와 관계없이 항목 우측의 고정 폭 12ch·높이 PC 32px·모바일 38px 영역에 표시하고, 긴 그룹명은 말줄임 처리해 시각 영역과 겹치지 않는다. PC와 모바일에 동일하게 적용한다.

2. 닫은 시각의 첫 줄은 두 자리 연도의 `YY. MM. DD.`(일자 뒤에도 마침표), 둘째 줄은 초 없이 `hh:mm AM/PM` 영어 형식의 현지 시각으로 표시하며 각 줄은 줄바꿈하지 않는다.

3. 북마크된 탭은 확인 팝업 없이 바로 닫고 닫은 탭 목록에 보관하지 않는다.

4. 닫은 탭을 복원한 뒤 내용을 수정하지 않았다면 탭을 다시 닫을 때 탭 닫기 확인 팝업 없이 바로 닫아 닫은 탭 목록에 다시 보관한다. 복원 후 내용을 수정했다면 기존처럼 확인 팝업을 표시한다.

5. 복원 후 수정하지 않은 탭은 내용이 10자 이하이거나 북마크된 경우에도 확인 팝업 없이 닫고 닫은 탭 목록에 다시 보관해 대시보드 `Closed` 컬럼에서 사라지지 않게 한다.
