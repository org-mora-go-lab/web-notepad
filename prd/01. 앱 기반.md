# 01. 앱 기반

> E2E: `tests/01. 앱 기반/`

## 01. 구성

1.  Next.js App Router와 React 기반의 브라우저 노트 앱이다.

2.  노트 상태는 Zustand로 관리하며 `web-notepad-storage` 키를 사용해 브라우저 로컬 저장소에 저장한다.

3.  저장 상태를 복원한 뒤 편집 화면을 표시하며, 복원 전에는 로딩 화면을 표시한다.

4.  모바일에서는 하단부·편집기·라인 번호를 제외한 탭·MENU·탭 메뉴·우측 패널·팝업 등의 아이콘과 글자를 PC 크기의 1.2배로 표시하고, 확대로 어색해지는 버튼 영역의 너비·높이도 함께 늘린다. 하단부·편집기·라인 번호의 아이콘과 글자 크기는 기존 크기를 유지한다.

5.  PC와 모바일에서 에디터, 검색창, 그룹 이름 입력란의 텍스트 커서 색상을 그레이(`#b8b8b0`)로 통일한다. 탭 색상을 변경하거나 다른 탭으로 전환해도 커서 색상은 유지한다.

6.  터치 기기에서는 iOS가 입력란 포커스 시 화면을 확대해 UI가 어긋나지 않도록 에디터·검색창·그룹 이름 생성·수정 입력란의 글자 크기를 전체 폰트 크기 설정과 관계없이 최소 16px로 유지한다. 마우스 환경의 글자 크기는 바꾸지 않는다.

## 02. 브라우저 이력

1.  활성 그룹과 좌·우 탭 선택을 URL 이력으로 기록하며, 브라우저 뒤로가기·앞으로가기로 이전·이후의 그룹과 탭 포커스를 복원한다.

2.  그룹 전환은 현재 활성 탭과 패널 상태를 포함해 이력에 기록하고, 뒤로가기·앞으로가기로 전환 전후의 그룹 UI를 복원한다.

3.  분할 화면에서 활성 pane 전환을 이력에 기록하고, 뒤로가기·앞으로가기로 활성 pane과 포커스를 복원한다.

4.  우측 패널을 열거나 닫는 상태를 URL 이력으로 기록하고, 새로고침과 뒤로가기·앞으로가기로 패널 UI를 복원한다.

5.  활성 탭을 닫아 같은 pane의 다른 탭이 활성화되면 URL의 탭 ID를 새 활성 탭으로 교체하며, 새로고침 후에도 같은 탭과 pane을 유지한다.

## 03. 저장소 예외 처리

1.  `web-notepad-storage`의 JSON이 손상되어도 기본 작업공간으로 복구해 앱을 열고, 이후 편집한 정상 상태를 다시 저장한다.

2.  브라우저가 `web-notepad-storage` 읽기·쓰기·삭제를 차단해도 기본 작업공간을 열고 현재 세션의 노트를 계속 편집할 수 있다.
