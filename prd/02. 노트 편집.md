# 02. 노트 편집

> E2E: `tests/02. 노트 편집/`

## 01. 탭

1.  워크스페이스마다 하나 이상의 노트 탭을 관리한다. 마지막 탭을 닫으면 빈 탭을 새로 만든다.

2.  새 탭을 추가하고 원하는 탭을 선택할 수 있다.

3.  탭 제목에서 드래그를 시작해 탭 순서를 바꿀 수 있다.

4.  모바일에서 탭을 선택해도 편집기에 자동 포커스하지 않아 가상 키보드가 다시 열리지 않게 한다.

5.  내용이 저장 기준 내용과 다르면 탭에 변경 표시를 보여준다.

6.  탭 제목은 내용의 첫 번째 비어 있지 않은 줄을 앞뒤 공백 제거 후 최대 28자로 표시한다.

7.  새 탭 또는 내용이 비어 있는 탭의 제목은 `-`로 표시하며, 제목에는 탭 번호를 표시하지 않는다.

8.  탭이 가로로 넘치면 현재 스크롤 위치에 따라 탭 영역의 좌우 가장자리에 페이드 효과를 표시한다.

9.  탭 영역의 가로 스크롤바는 오버플로우 감지 전후 모두 표시하지 않는다. 가로 스크롤 동작과 가장자리 페이드 효과는 유지한다.

10. 탭 제목을 최대 28개의 표시 문자로 제한하며 이모지와 결합 문자를 중간에서 잘라 깨뜨리지 않는다.

## 02. 탭 - 닫기

1.  닫기 버튼과 가운데 클릭으로 탭을 닫을 수 있다.

2.  고정 탭은 일반 닫기 버튼과 가운데 클릭 닫기 동작을 사용할 수 없다.

3.  북마크하지 않은 내용이 11자 이상인 탭을 닫기 버튼·가운데 클릭·단축키로 닫으면 `Do you want to close this tab?` 문구의 앱 내부 확인 팝업을 표시하고, Close를 선택한 경우에만 해당 탭을 닫는다.

4.  빈 탭, 내용이 10자 이하(공백·줄바꿈 포함)인 탭, 북마크된 탭은 확인 팝업 없이 바로 닫으며 닫은 탭 목록에도 보관하지 않는다.

5.  탭 닫기 팝업은 Cancel에 기본 포커스를 두고 팝업 안에서 키보드 포커스를 유지한다.

6.  Escape, Cancel, 닫기 또는 바깥 영역 클릭으로 탭 삭제를 취소하면 탭과 내용을 유지하고 기존 포커스를 복원한다.

7.  Alt/Option+Backspace를 누르면 빈 활성 탭은 바로 닫고, 내용이 있는 활성 탭은 확인 팝업을 표시한다. 팝업에서 같은 단축키를 다시 누르면 삭제를 요청한 탭을 삭제한다.

8.  탭 삭제 팝업이 열린 동안 다른 탭 조작 단축키와 키 자동 반복 입력은 무시한다.

## 03. 탭 메뉴 - 열기와 표시

1.  PC에서는 우클릭 메뉴에서 탭의 고정과 북마크를 전환할 수 있다.

2.  PC에서는 더블클릭으로 탭 메뉴를 열지 않는다.

3.  모바일에서는 탭 제목을 더블클릭(더블탭)했을 때 고정·북마크 메뉴를 열고 각 상태를 전환할 수 있다.

4.  모바일에서는 한 번 탭하거나 우클릭·길게 누르기로 탭 메뉴를 열지 않는다.

5.  모바일에서 핀·북마크 아이콘을 더블클릭(더블탭)하면 해당 탭의 고정·북마크 메뉴를 연다.

6.  PC의 탭 우클릭 메뉴와 모바일의 탭 더블탭 메뉴에서 `Pin`, `Bookmark` 및 해제 문구의 글자 크기는 PC 15px·모바일 18px, 아이콘 크기는 PC 14px·모바일 16.8px로 표시한다.

## 04. 탭 메뉴 - 그룹 이동 동작

1.  `Move Group`에서 대상 그룹을 선택하면 해당 탭을 옮기며 ID, 내용, 저장 기준 내용, 색상, 고정 상태, 줄 선택과 연결 북마크를 유지한다.

2.  그룹 이동 후 현재 그룹 화면은 유지하고 대상 그룹에서는 옮긴 탭을 왼쪽 패널의 활성 탭으로 지정한다.

3.  원래 그룹의 마지막 탭을 이동하면 빈 탭을 새로 만든다.

4. 그룹 이동 결과는 새로고침 후에도 유지한다.

5. 분할 패널의 탭도 `Move Group`으로 옮길 수 있다. 이동 후 원래 그룹의 활성 탭을 유효한 탭으로 조정하고 오른쪽 패널이 비거나 왼쪽 패널의 마지막 탭이 이동하면 남은 탭을 왼쪽 패널로 모아 분할을 해제한다.

6. 분할 패널의 탭을 이동해도 대상 그룹의 기존 오른쪽 패널과 나머지 탭은 유지한다.

## 05. 탭 메뉴 - 그룹 이동 화면

1. PC 탭 우클릭 메뉴와 모바일 탭 더블탭 메뉴에 `Move Group`을 표시한다. 선택하면 현재 그룹을 제외한 대상 그룹 목록을 표시한다.

2. 다른 그룹이 없으면 `Move Group`을 비활성화한다.

3. 뒤로 가기, Escape 또는 바깥 클릭으로 이동 없이 그룹 목록을 닫거나 기존 메뉴로 돌아갈 수 있다.

4. 메뉴와 그룹 목록은 화면 안에 배치하고 긴 그룹 이름은 말줄임·툴팁으로 표시한다. 그룹명 앞에는 아이콘을 표시하지 않고 상단 뒤로가기 화살표는 유지한다.

5. 그룹 선택 화면과 기본 탭 메뉴의 너비는 모두 201px를 유지하고, 메뉴 항목의 최소 높이는 39px로 표시한다.

6. 그룹 목록은 그룹 드롭다운과 같은 기준으로 정렬한다. 고정한 그룹을 먼저 배치하고, 한글로 시작하는 이름을 먼저 배치해 한국어 기준 문자순으로 정렬하고 `Ungrouped`는 맨 아래에 고정한다.

## 06. 탭 - 아이콘

1.  새 탭의 기본 색상은 설정한 1번째 탭 색상이며 기본값은 그레이다.

2.  탭 아이콘을 클릭하면 설정한 탭 색상 순서로 순환하며(기본: 그레이 → 그린 → 퍼플(`#c3a6f5`) → 그레이) 아이콘은 색상에 맞는 글로우를 표시한다.

3.  핀·북마크 아이콘을 클릭하면 해당 탭을 선택하며 고정·북마크 상태는 바꾸지 않는다.

4.  핀·북마크 아이콘에서 드래그하면 아이콘 자체가 아닌 탭 전체를 이동하며 고정·북마크 상태는 유지한다.

5.  고정 탭의 핀 아이콘은 고정 상태를 표시하며, 핀 아이콘과 제목 글자색은 탭 색상을 따른다.

6.  탭 색상 아이콘, 북마크 아이콘, 탭 배경과 활성 탭 상단 강조선은 초록색·빨간색·회색 중 동일한 색조를 따른다. 북마크 아이콘은 PC와 모바일의 활성·비활성 탭 모두에서 해당 탭 색상을 유지한다.

7.  탭 색상 아이콘의 가로·세로 크기는 PC에서 각각 11px, 모바일에서 각각 15.6px이며 버튼 영역은 PC에서 각각 14px, 모바일에서 각각 16.8px다.

## 07. 탭 - 표시

1.  탭 최소 너비는 PC에서 130.485px, 모바일에서 기존 114.406px의 1.2배인 137.287px로 표시한다.

2.  모바일에서 탭과 탭 조작 버튼을 누를 때 브라우저 기본 파란 터치 강조 효과를 표시하지 않는다.

3.  PC와 모바일에서 인접한 일반·고정 탭 사이에 너비 1px의 그레이 구분선을 탭 전체 높이와 동일하게 표시하고 위아래 여백을 두지 않으며 탭 너비는 바꾸지 않는다.

4.  DARK·LIGHT에 맞는 구분선 색상을 불투명도 60%로 옅게 표시한다.

5.  첫 탭의 바깥쪽과 새 탭 추가 버튼에는 좌우 테두리를 표시하지 않고 두께 3px의 활성 탭 상단 강조선은 유지한다.

6.  PC 탭은 최대 너비 300.655px, 높이 39px로 표시하며 헤더, 새 탭 추가 버튼, 탭 선택 버튼, 닫기 버튼과 패널의 탭 행 높이도 39px로 맞춘다.

7.  PC 탭 제목은 15px 글자로 수직 중앙에 배치하고 색상 아이콘은 가로·세로 각각 11px로 표시한다.

8.  모바일 탭은 최소 너비 137.287px, 최대 너비 247.65px, 높이 45px로 표시하며 탭 하단 추가 여백은 1px로 표시한다. 탭 선택·닫기 버튼은 44px를 유지하며 헤더, 새 탭 추가 버튼과 패널의 탭 행은 45px로 맞춘다.

9.  모바일 탭 제목은 18.2px, 색상 아이콘은 가로·세로 각각 15.6px이며 색상·핀·북마크 아이콘과 새 탭 추가 아이콘의 세로 위치를 유지한다.

## 08. 편집기 - 입력

1.  여러 줄 일반 텍스트를 편집하며 줄 번호를 표시한다.

2.  Enter는 커서 위치에 줄바꿈을 삽입한다.

3.  편집기 높이를 넘어가는 위치로 커서가 이동하면 커서가 보이도록 편집기와 줄 번호 영역을 함께 스크롤한다.

4.  Tab은 커서 위치에 탭 문자를 삽입한다.

5.  한글 IME 조합 중에도 입력을 처리한다.

6.  자동 줄바꿈된 긴 원본 줄에서도 커서가 편집기 높이를 벗어나면 커서가 보이도록 편집기와 줄 번호 영역을 함께 스크롤한다.

## 09. 편집기 - 줄바꿈과 표시

1.  편집 영역이 좁아져 자동 줄바꿈으로 표시 줄이 늘어나면 왼쪽 LINE 번호도 표시 줄 수만큼 연속으로 증가한다. 내용 수정, 화면 크기 변경 및 분할 패널 너비 변경 시 갱신하며, 영역이 넓어지면 번호도 줄어든다.

2.  자동 줄바꿈된 번호를 선택하면 같은 원본 줄의 모든 표시 줄을 강조하고, 기존 개행 기준 줄 선택 데이터를 유지한다.

3.  PC 편집기 글자 크기는 19px, 줄 높이(line-height)는 35px로 기존보다 2px 늘리며 줄 번호 영역의 너비는 39px로 표시한다.

4.  모바일 편집기 글자 크기는 19px, 줄 높이는 39px로 유지해 각 줄의 위아래 간격을 PC보다 각각 2px 늘리며 줄 번호 영역의 너비는 41px로 표시한다.

5. 줄 번호와 선택 강조 영역을 같은 줄 높이에 맞춰 정렬하고 선택 색상은 줄 전체를 채운다.

6. 터치 장치에서 편집기를 한 번 터치하면 브라우저가 정한 커서 위치를 유지하고 앱이 전체 선택하거나 문서 끝으로 커서를 다시 설정하지 않는다. 좌우 분할 패널 전환에서도 동일하게 유지한다. 길게 누르기 및 브라우저 기본 선택·복사·붙여넣기 기능은 차단하지 않는다.

## 10. 편집기 - 실행 취소

1. Cmd/Ctrl+Z로 실행 취소하고 Cmd/Ctrl+Shift+Z 또는 Cmd/Ctrl+Y로 다시 실행한다.

2. 실행 취소 기록은 탭별로 독립적으로 관리한다.

3. 탭별 실행 취소 기록은 최대 100개를 보관한다.

4. 탭을 분할 패널 사이로 이동해도 해당 탭의 실행 취소와 다시 실행 기록을 유지한다.

5. 실행 취소 후 새 내용을 편집하면 기존 다시 실행 기록을 제거해 새 편집 분기에서 Redo가 이전 내용을 복원하지 않게 한다.

## 11. 줄 선택

1.  Shift+클릭으로 기준 줄부터 클릭한 줄까지 범위를 선택하고, 선택한 범위를 다시 Shift+클릭하면 해제한다.

2.  Shift+클릭한 줄이 이미 선택된 연속 블록에 속하면 해당 블록 전체를 해제하고 나머지 선택 블록은 유지한다.

3.  줄 번호를 클릭하거나 키보드로 선택하면 줄 번호의 배경색과 글자색을 활성 탭 색상으로 강조한다. 선택하지 않은 줄 번호는 검은 배경을 유지한다.

4.  첫 번째 줄의 선택 배경은 편집기 상단 여백까지 이어지며, 스크롤 시 줄 번호와 함께 이동해 상단에 배경 잔상을 남기지 않는다.

5.  줄 번호를 마우스로 클릭하거나 Shift+클릭해도 줄 주변에 포커스 테두리를 표시하지 않는다.

6.  선택한 줄은 노트별로 로컬 저장소에 저장하고 탭 전환과 새로고침 후 복원한다. 선택 해제도 저장하며 PC와 모바일에서 동일하게 유지한다.

7.  그룹 전환이나 분할 패널 이동 후에도 노트별 줄 선택을 유지하고 새로고침 후 복원한다.

8.  줄 삽입·삭제 시 선택 위치를 맞추고 삭제된 줄의 선택은 제거한다. 변경된 선택 위치도 저장하고 새로고침 후 복원한다.

## 12. 분할 패널 - 기본 동작

1.  탭을 분할된 패널 사이로 드래그해 이동할 수 있다. 탭 제목에서 다른 패널의 편집기 영역으로 직접 드롭해도 이동한다.

2.  왼쪽 패널의 탭을 오른쪽 분할 영역으로 드롭해 분할 화면을 만들 수 있다. 편집기의 오른쪽 위로 직접 드롭해도 분할 표시의 렌더링 타이밍과 관계없이 좌우 분할한다.

3.  각 패널은 자체 탭 목록과 활성 탭을 가진다.

4.  구분선을 드래그해 너비 비율을 조정하며 각 패널은 20%~80% 범위로 제한한다.

5.  오른쪽 패널의 탭을 모두 왼쪽으로 옮기거나 닫으면 분할 화면이 해제된다.

6.  오른쪽 패널의 내용이 11자 이상인 탭은 삭제 확인 후에만 닫고, 확인 전에는 분할 화면을 유지한다.

7.  분할 비율은 앱 재접속 시 중앙으로 초기화한다.

8.  오른쪽 패널에 새 탭을 추가하면 분할선을 중앙으로 조정한다.

## 13. 분할 패널 - 다중 분할

1.  좌우 각 열의 상단 패널은 탭을 `Split down` 영역에 드롭해 상하로 분할할 수 있으며 좌상·좌하·우상·우하 최대 4분할까지 확장한다.

2. `Split right`는 분할 대상인 우측 편집기가 비어 있을 때 왼쪽 열 패널의 오른쪽 절반에 표시한다. 하단 패널에서는 우상단이 열려 있어도 우하단이 비어 있으면 표시한다. 두 분할 영역이 함께 표시되면 `Split right`는 오른쪽 위 1/4 영역을, `Split down`은 아래쪽 절반을 사용하며 `Move here`는 분할 영역과 겹치지 않는 나머지 영역에 표시한다.

3. `Split down` 영역은 드래그 중인 탭이 편집기 높이의 중앙보다 아래로 내려갔을 때만 표시한다.

4. 드래그한 탭의 원래 편집기에 탭이 하나뿐이면 분할 영역을 표시하지 않는다. 같은 편집기에는 드롭 영역을 표시하지 않고 다른 기존 편집기에는 `Move here`만 표시한다. 4분할 상태에서도 분할 영역을 표시하지 않는다.

5. 상하 구분선을 드래그해 상단·하단 패널의 높이 비율을 조정하며 각 패널은 20%~80% 범위로 제한한다. 상하 분할 비율은 열마다 따로 관리하고 앱 재접속 시 중앙으로 초기화한다.

6. 하단 패널의 탭을 모두 다른 패널로 옮기거나 닫으면 해당 열의 상하 분할을 해제하고, 상단 패널이 비면 하단 패널을 상단으로 올린다. 왼쪽 열이 모두 비면 오른쪽 열을 왼쪽으로 옮긴다.

7. 4분할 배치와 각 패널의 활성 탭은 새로고침 후 복원한다. Alt+위/아래 화살표는 좌상→좌하→우상→우하 순서로 패널 경계를 넘어 이동한다.

8. 상하 구분선은 2px 선으로 표시하며 선과 상단 패널, 선과 하단 패널의 탭 줄 사이에 공백을 두지 않는다. 드래그 영역은 10px를 유지하고 남는 8px는 상단 패널 아래쪽에 겹친다.

9. 탭 제목을 편집기 하단으로 직접 드래그해 드롭하면 상하 분할한다. 분할 표시가 화면에 반영되기 전에 편집기 자체가 드롭을 받아도 현재 드롭 좌표에 맞춰 분할·이동 대상을 결정한다.

## 14. 분할 패널 - All Group과 복합 이동

1. All Group에서도 탭 제목을 드래그해 좌우 분할할 수 있다. All Group의 분할 배치는 별도로 저장해 새로고침 후 복원하고, 탭의 소속 그룹과 각 소속 그룹의 분할 배치는 변경하지 않는다.

2. All Group에서도 Split down과 Split right로 최대 4분할하고, 분할된 편집기 사이로 탭을 드래그해 이동할 수 있다. 탭 선택과 활성 편집기를 유지하며 그룹을 전환했다 돌아오거나 새로고침해도 All Group의 배치를 복원한다.

3. All Group의 분할된 편집기에서 새 탭을 추가하면 그 편집기에 표시하고 소속은 Ungrouped로 저장한다. 추가한 탭을 닫으면 원래 탭으로 돌아오고, 편집기의 마지막 탭을 닫으면 빈 편집기를 정리한다.

4. 일반 그룹과 All Group 모두 상하 분할된 하단 편집기의 탭을 오른쪽 영역에 드롭해 우측 분할할 수 있다. 우상단 편집기가 있으면 비어 있는 우하단으로 이동하고 우상단 탭은 유지한다. 오른쪽 열이 없으면 우측 열을 만들며 기존 레이아웃 규칙에 따라 우상단으로 표시한다. 원래 하단 편집기의 나머지 탭과 새로고침 후 배치를 유지한다.

5. 상단에 탭 1, 하단에 탭 2·3이 있는 상태에서 탭 3을 하단 편집기의 우측 `Split right` 영역에 드롭하면 이동한다. 원래 하단에는 탭 2를 유지하고 상단 탭 1은 유지한다. 일반 그룹과 All Group 모두 동일하며 드래그 중 표시가 갱신돼도 편집기 위에 포인터가 있으면 드롭 영역을 유지한다.

6. 좌측 상하 편집기와 우측 편집기로 구성된 3분할에서 우측 탭을 좌하단으로 이동할 때는 우측 탭 개수와 관계없이 전체 영역에 `Move here`만 표시한다. 우측 가장자리에 드롭해도 추가 분할 없이 좌하단의 기존 탭과 합치고 우측 편집기는 비었을 때만 정리한다. 우측 열에서 기존 좌측 편집기로 이동할 때는 분할 영역을 표시하지 않는다.

## 15. 단축키

1.  Alt+Tab: 활성 패널에 새 탭 추가. 일반 Tab 입력은 편집기에 탭 문자를 삽입한다.

2.  Alt+위/아래 화살표: 탭 간 이동. 분할 상태에서는 패널 경계를 넘어 이동할 수 있다.

3.  편집기에 포커스가 있을 때 Cmd+A 또는 Alt+A로 편집기 내용 전체를 선택한다.

4.  검색·그룹 이름 입력 등 편집기 외의 입력 요소에 포커스가 있으면 Cmd+A 입력 즉시 해당 입력 요소의 전체 내용을 선택한다.

5.  macOS에서 Option+F12: 활성 탭을 오른쪽 열의 상단 패널로 이동하고, Option+F11: 왼쪽 열의 상단 패널로 이동한다. 이미 대상 열에 있는 탭은 이동하지 않는다.

6.  왼쪽 패널에 탭이 하나만 남는 경우 Option+F12 이동은 수행하지 않는다.

7.  SHORTCUT 안내 패널에 실제 키보드 단축키와 Shift+클릭 라인 범위 선택·해제 설명을 표시한다.

8.  macOS Shortcut 안내 패널에서 Alt modifier 표기는 `Option`으로 표시한다.

9.  Shortcut 안내 콘텐츠는 단축키 설명을 15px, 키 표시를 12px로 표시한다.
