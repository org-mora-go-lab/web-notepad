# 04. 패널과 검색

> E2E: `tests/04. 패널과 검색/`

## 01. 우측 패널 - 열기와 닫기

1.  상태 표시줄의 BOOKMARK·DASHBOARD와 우측 상단 MENU의 SHORTCUT·CLOSED·SETTINGS·SEARCH 명령을 선택하면 해당 우측 패널(북마크·대시보드·단축키 안내·닫은 탭·설정·전체 검색)을 연다. 그룹 선택 버튼은 그룹 드롭다운을 연다. SHORTCUT은 PC에서만 표시한다.

2.  우측 패널은 한 번에 하나만 열린다.

3.  브라우저에서 뒤로가기를 누르면 열린 우측 패널을 닫는다.

4.  PC와 모바일에서 Escape를 누르면 열린 우측 패널을 닫는다. 검색창에 포커스가 있어도 닫으며 메모·그룹·북마크 데이터는 유지한다.

5.  그룹 삭제 확인 팝업이 열린 상태에서 Escape를 누르면 팝업 취소를 우선하고 그룹 드롭다운은 유지한다.

6.  Escape로 우측 패널을 닫은 뒤에도 다시 열기와 브라우저 뒤로가기가 정상 동작한다.

7.  Escape로 우측 패널을 닫으면 하단·MENU 패널 진입 버튼에 포커스 테두리 잔상이 남지 않도록 현재 포커스를 해제한다. PC와 모바일에서 동일하게 적용하며 키보드 Tab 및 MENU 방향키 탐색 시에는 정상적인 포커스 표시를 유지한다.

8. 닫힌 우측 패널의 모든 컨트롤은 키보드 Tab 순서와 접근성 탐색에서 제외하고, 현재 열린 패널의 컨트롤만 상호작용할 수 있다.

## 02. 우측 패널 - 표시와 크기

1.  북마크·대시보드·단축키 안내·닫은 탭·설정 패널 헤더는 위아래 패딩을 각각 9px로 표시한다.

2.  우측 패널은 PC와 모바일 모두 화면 상단부터 하단까지 동적 뷰포트 전체 높이를 채우며, 긴 목록을 스크롤했을 때 마지막 항목의 콘텐츠까지 볼 수 있다.

3. PC와 모바일에서 닫힌 우측 패널은 그림자를 표시하지 않아 편집기와 하단 메뉴의 우측에 어두운 그라데이션이 남지 않는다. 그림자는 열린 패널에만 불투명도 18%의 옅은 그라데이션으로 표시하고 패널을 닫으면 제거한다.

4. 모바일 우측 패널과 확인 팝업의 아이콘·글자는 PC 크기의 1.2배로 표시한다. 단, 헤더의 초기화·닫기 버튼과 아이콘은 PC와 같은 크기로 표시한다.

5. PC에서 패널의 편집기 쪽 경계선을 드래그해 패널 너비를 조절할 수 있다. 경계선은 편집기 분할 구분선과 같이 너비 2px 선·좌우 조절 커서·hover 강조로 표시하며, 너비는 최소 320px부터 화면 너비의 최대 70%까지로 제한한다. 고정·미고정과 좌우 배치 모두 동일하게 적용하고 저장된 너비를 복원하거나 화면 크기가 바뀌어도 70%를 넘지 않는다. 모바일에서는 경계선을 표시하지 않고 기존 전체 너비 패널을 유지한다.

6. 조절한 패널 너비는 모든 우측 패널에 공통으로 적용하고 새로고침 후에도 유지한다. PC에서 패널을 고정한 상태에서는 헤더·편집기·푸터를 포함한 작업 영역이 조절한 패널 너비를 제외한 공간을 사용한다.

7. 우측 패널을 열거나 슬라이드하는 동안 화면 배경을 검게 어둡게 하지 않고 투명하게 유지한다.

## 03. 우측 패널 - 고정

1. PC 우측 패널 헤더의 닫기 버튼 왼쪽에 고정 버튼을 표시한다. 모바일에서는 고정 버튼을 표시하지 않는다.

2. PC에서 패널을 고정하면 패널은 선택한 화면 좌우 측면의 전체 높이를 채우고 헤더·편집기·푸터를 포함한 작업 영역이 패널 너비만큼 반대쪽으로 밀려 패널과 나란히 표시된다.

3. 고정한 패널을 X 버튼으로 닫으면 body가 화면 전체 너비로 돌아오고, 고정 상태는 유지해 다음에 여는 패널도 고정된 상태로 연다. 고정을 해제하면 기존 오버레이 패널로 표시한다.

4. 패널 고정 상태는 브라우저에 저장해 새로고침 후에도 유지한다. 모바일 화면에서는 고정 상태와 관계없이 기존 오버레이 패널로 표시한다.

5. 고정한 패널은 X 버튼이나 같은 하단 BOOKMARK·DASHBOARD 명령 재선택으로 닫는다. Escape, 그룹 선택·북마크 열기·닫은 탭 복원, 브라우저 뒤로가기로는 닫지 않고 열린 상태를 유지한다. 다른 패널 명령을 선택하면 해당 패널로 전환한다.

6. PC 우측 패널 헤더의 초기화·고정·닫기 버튼은 기존 크기의 1.2배인 33.6px로 표시하며 아이콘은 초기화·닫기 14.4px(단축키 패널 닫기 19.2px), 고정 16.8px로 표시한다. 모바일 버튼 크기는 33.6px를 유지한다.

## 04. 우측 패널 - 경계와 레이아웃

1. 고정되지 않은 열린 패널의 편집기 쪽 경계 바깥 11.52px에 투명에서 테마별 경계색(DARK: 흰색 불투명도 16%, LIGHT: 검정 불투명도 22%)으로 이어지는 부드러운 그라데이션 음영을 표시한다. 바깥쪽에서 패널 경계로 갈수록 경계색의 혼합 비율을 0%·25%(거리 30%)·65%(거리 65%)·100%로 높이며 좌우 패널 배치에 맞춰 방향을 반전한다. 음영은 클릭·크기 조절을 막지 않으며 닫히거나 고정되면 제거하고, 고정을 해제하면 다시 표시한다.

2. PC에서 고정하지 않은 패널은 패널 바깥을 클릭하면 닫는다.

3. 고정 중에는 배경 덮개와 그림자·왼쪽 그라데이션 음영을 표시하지 않아 편집기를 계속 사용할 수 있다.

4. 고정 패널을 열고 닫을 때와 다시 열 때는 슬라이드 효과 없이 바로 표시·제거한다.

5. PC와 모바일의 모든 사이드 패널은 좌우 배치와 관계없이 화면 전체 높이를 채운다. 미고정 패널은 헤더·푸터 배치를 바꾸지 않고 두 영역 위를 덮으며 바깥 클릭 영역도 화면 전체를 채운다. PC 고정 패널은 헤더·푸터를 포함한 작업 영역을 패널 너비만큼 밀고, 크기 조절 시에도 나란히 배치한다. 닫으면 작업 영역을 원래 배치로 복원한다. 모바일은 기존대로 고정 버튼 없이 오버레이로 표시한다.

## 05. 검색 - 북마크

1.  북마크 패널은 북마크 제목과 내용을 대소문자 구분 없이 부분 검색하며 검색창의 placeholder는 `Search bookmarks`다.

2.  북마크 검색창은 헤더 아래에 표시하며 위쪽 여백은 14px, 아래쪽 여백은 6px로 적용한다.

3.  검색어가 입력된 검색창의 지우기 아이콘은 패널 닫기 버튼과 같은 옅은 회색으로 표시한다.

4.  검색 결과에서 일치하는 키워드 부분을 음영으로 강조한다. 북마크 제목·내용, 닫은 탭의 그룹명·내용에 적용하며 대소문자를 구분하지 않는다.

## 06. 검색 - 전체 검색

1.  우측 상단 MENU의 CLOSED 바로 아래에 전체 검색 명령을 표시하고 선택 시 우측 검색 패널을 연다.

2.  MENU의 SEARCH 항목은 PC와 모바일 모두 다른 MENU 항목과 같이 아이콘 오른쪽에 `SEARCH` 라벨을 표시한다.

3.  검색어가 없으면 `Enter a search term`, 결과가 없으면 `No search results`를 표시한다.

4.  그룹·북마크·모든 그룹의 닫은 탭을 대소문자 구분 없이 부분 검색한다.

5.  그룹 검색 결과를 선택하면 해당 그룹으로 이동한다.

6. 북마크 검색 결과를 선택하면 해당 북마크를 연다.

7. 닫은 탭 검색 결과를 선택하면 Closed 패널을 기존 검색어가 입력·적용된 상태로 연다. 이 동작만으로 탭을 복원하지 않는다.

8. 전체 검색 패널을 Escape로 닫으면 검색어를 초기화하며 다시 열 때 빈 검색 상태를 표시한다.

## 07. 대시보드 - 기본 표시와 상태

1.  하단 BOOKMARK 오른쪽(가장 오른쪽)에 `DASHBOARD` 명령(대시보드 아이콘)을 표시하며 PC는 아이콘 오른쪽에, 모바일은 아이콘 아래에 라벨을 함께 표시한다. 누르면 우측에 `Dashboard` 패널을 연다.

2.  대시보드는 현재 그룹의 모든 탭을 `Todo`·`WIP`·`Closed` 세 컬럼에 카드로 표시하고 컬럼 제목 옆에 탭 개수를 표시한다. 컬럼은 탭 색상 순서의 1·2·3번째 색상(기본 Gray·Green·Purple)에 대응하며, 탭의 현재 색상이 속한 컬럼에 탭을 표시한다(순서에 없는 색상은 `Todo`). 카드는 탭 제목과 본문 미리보기(최대 3줄)를 표시하고 컬럼 제목(상태 이름과 개수 줄, 위·아래 padding 5px)은 해당 탭 색상을 16% 투명도로 배경에 채우고 카드에도 해당 탭 색상을 표시하며, 카드는 왼쪽 강조선 없이 모서리를 6px로 둥글게 표시한다.

3.  카드를 drag & drop으로 다른 컬럼에 놓아 상태를 바꾼다(이동 화살표 버튼은 없다). 상태가 바뀌면 탭 색상도 대상 컬럼에 대응하는 색상으로 바뀌며, 결과는 브라우저에 저장해 새로고침 후에도 유지한다. `Closed` 컬럼으로 옮기면 탭 닫기 팝업 없이 바로 탭을 닫아 왼쪽 에디터에서 제거하고 닫은 탭(MENU의 CLOSED 개수·Closed 패널)에 보관한다(내용 길이·북마크 여부와 관계없이 보관하며 고정된 탭은 `고정을 해제하고 Closed 상태로 변경하시겠습니까?` 확인 팝업을 먼저 표시하고, 확인하면 고정을 해제한 뒤 닫으며 취소하면 그대로 둔다).

4.  상태는 탭 색상으로 결정되어 그룹별로 독립이며, 현재 그룹의 탭만 보여주며 패널 상단에 그룹 이름 필드는 표시하지 않는다.

5.  카드를 누르면 해당 탭을 활성화하고 (고정하지 않은 경우) 패널을 닫는다.

6.  PC는 세 컬럼을 가로로 나란히, 모바일은 세로로 쌓아 표시한다.

7. 탭이 없는 컬럼도 카드 하나가 들어갈 만큼의 최소 높이를 유지하고, 카드 영역에는 평상시 별도의 테두리를 표시하지 않는다.

8.  탭에서 색상을 변경하면 대시보드의 해당 탭도 새 색상에 대응하는 컬럼으로 즉시 옮겨 표시한다.

9.  대시보드 내부 글자는 기존 대비 1.2배로 표시한다(컬럼 제목 16.8px, 카드 제목 16.8px, 카드 미리보기 15.6px, 개수 14.4px). 컬럼 제목의 개수는 오른쪽 padding을 10px로 둔다.

10. 대시보드 컬럼(상태) 사이 간격은 15px로 표시한다.

## 08. 대시보드 - 전체 그룹과 닫은 탭

1. `All Group`의 대시보드는 모든 그룹의 탭을 상태 컬럼에 모아 표시하고 카드에 소속 그룹 이름을 함께 표시한다. 카드를 다른 컬럼으로 옮기면 해당 탭이 속한 그룹의 탭 색상(상태)이 바뀐다.

2. 대시보드 `Closed` 컬럼에는 현재 그룹(`All Group`은 모든 그룹)의 닫은 탭도 카드로 표시하고 개수에 포함한다. 닫은 카드를 누르면 탭을 복원하고, `Todo`·`WIP` 컬럼으로 옮기면 해당 색상으로 복원한다.

3. 고정된 탭을 `Closed` 컬럼으로 옮기면 고정 해제 여부를 묻는 확인 팝업(`고정 해제 후 닫기`·`Cancel`)을 표시한다. 확인하면 고정을 해제하고 탭을 닫으며, 취소하면 탭은 고정된 채 기존 컬럼에 남는다.

4. 고정·북마크된 탭의 대시보드 카드는 우측 상단에 해당 탭 색상의 핀·북마크 아이콘을 표시한다. 둘 다 해당하면 핀 아이콘 오른쪽에 북마크 아이콘을 가로로 나란히 표시하고, 해당하지 않는 상태의 아이콘은 표시하지 않는다.

5. 내용이 비어 있는 탭(`Empty Note`)은 대시보드에 표시하지 않으며 컬럼 개수에도 포함하지 않는다.

6. `Closed` 컬럼에서 복원한 탭을 수정 없이 X로 닫으면 짧은 내용이어도 확인 팝업 없이 닫고 `Closed` 컬럼에 다시 보관한다.

7. 닫을 당시의 그룹이 삭제된 탭은 `Ungrouped` 대시보드의 `Closed` 컬럼에 표시하고, 카드를 선택하면 `Ungrouped`로 복원한다.

## 09. 대시보드 - 드래그 표시

1. 드래그 중인 카드가 컬럼 위에 있으면 제목 아래 카드 영역을 탭 분할 드롭 영역과 동일한 연녹색 배경(`rgba(143, 227, 176, 0.08)`)과 signal 색상의 1px 점선으로 강조한다. 모서리 둥글림·그림자·전환 효과 없이 표시하며 컬럼을 벗어나거나 드롭하면 강조를 제거한다.

2. 카드 영역에 상시 6px 내부 여백을 두어 드롭 강조선이 첫 카드 상단과 카드 좌우 테두리에 겹치지 않으며, 좌우 음수 여백으로 기존 카드 너비를 유지한다. 드래그 시작·종료 시 카드 위치와 크기는 바뀌지 않는다.

3. 컬럼은 패널 하단까지 이어져 상태 제목 아래 영역 어디에 놓아도 해당 컬럼으로 이동한다.

4. 새 탭은 첫 번째 색상이므로 내용을 입력하면 `Todo`에 표시한다. 비어 있는 동안에는 카드와 컬럼 개수에서 제외한다.

5. 드롭 없이 드래그를 취소하면 강조·카드 흐림을 해제하고 저장 데이터를 유지한다.

6. 다른 컬럼으로 이동한 뒤 이전 컬럼의 이탈 이벤트가 와도 새 대상만 강조한다.

7. 같은 컬럼 내부의 카드·자식 요소 사이를 이동해도 드롭 강조를 유지한다.

## 10. 대시보드 - 드래그 예외 처리

1. 대시보드 카드 드래그가 아닌 외부 데이터는 강조하거나 상태를 변경하지 않는다.

2. 닫은 카드를 Closed에 다시 드롭하면 복원하거나 중복 보관하지 않는다.

3. 공백·탭·개행만 있는 열린 탭과 닫은 탭은 카드와 컬럼 개수에서 제외한다.

4. 열린 카드를 원래 컬럼에 다시 드롭해도 카드·탭을 중복 생성하지 않는다.

5. 닫은 탭 항목 ID의 형식과 관계없이 `Closed` 카드를 `Todo`·`WIP`으로 옮기면 대상 상태의 색상으로 정확히 한 번 복원한다.

## 11. 대시보드 - 포커스와 스크롤

1. 현재 포커스된 편집기 탭의 카드를 불투명도 50%의 1px 색상 테두리와 기본 카드 배경에 상태 색상을 12% 혼합한 옅은 배경으로 강조하며 추가 외곽선은 표시하지 않고 접근성 현재 표시를 제공한다. 고정 대시보드에서 다른 카드를 클릭하면 강조도 해당 카드로 옮긴다.

2. 대시보드 헤더와 Todo·WIP·Closed 상태 제목·개수는 PC와 모바일 모두 상단에 항상 고정하고, 그 아래 전체 카드 영역에 하나의 공통 세로 스크롤만 표시한다. 컬럼별 스크롤은 표시하지 않는다. 상태 제목은 가로로 나란히 고정하고 카드 컬럼은 PC 가로·모바일 세로 배치를 유지한다. 상태 제목 영역의 오른쪽 여백은 기본 14px에 카드 영역의 실제 세로 스크롤바 너비를 더하며, 콘텐츠나 패널 크기가 바뀌어 스크롤바가 사라지면 기본 여백으로 돌아간다.

3. PC와 모바일에서 카드 목록을 아래로 스크롤하면 고정 상태 제목 영역 바로 아래에 높이 48px의 fog 효과를 표시한다. 진한 색을 유지하는 구간 없이 패널 배경색의 불투명도를 상단 100%에서 높이 35% 지점의 65%, 70% 지점의 25%, 하단 0%로 부드럽게 줄인다. DARK·LIGHT 테마의 패널 배경색을 따르며 카드 클릭·드래그와 스크롤바 조작을 막지 않는다. 표시·제거는 180ms 동안 자연스럽게 전환하고 목록 맨 위로 돌아오면 효과를 제거한다.
