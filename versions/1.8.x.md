# 1.8.x 버전 이력

대시보드의 상태 이동 메뉴와 표시 위치를 개선하고, 모바일 파동 효과와 그룹 표시·이동 구성을 정비했습니다. 1.8.1에서는 PC·모바일 상태 표시 블러와 기본 상태 색상을 다듬고 PRD 구조를 E2E 계층과 통일했습니다.

<br>

## 1.8.1

1. 모바일 대시보드 상태 표시의 블러를 경계에서 바깥쪽으로 점진적으로 사라지게 변경하고 위·아래 범위를 20px로 통일

2. 모바일 상태 표시가 스크롤 중 Dashboard 헤더에 맞닿도록 고정 위치를 조정하고, 초기 상단 간격은 5px 축소

3. PC 대시보드 상태 표시 아래 블러를 48px에서 24px, 강도를 5px에서 2px로 줄이고 아래로 자연스럽게 사라지는 효과 적용

4. 기본 상태 색상을 To Do는 Gray, Doing은 Indigo, Done은 Teal, Closed는 Green으로 변경하고 설정 기본 순환색과 복구·초기화 동작 동기화

5. 대시보드 옵션 아이콘의 크기·위치, 헤더 메뉴 오른쪽 여백, 그룹 이름 생성 영역의 상단 간격을 조정

6. `tests-prd`를 `tests`와 같은 카테고리·세부 문서 계층으로 재구성하고 78개 세부 PRD·300개 요구사항을 300개 E2E와 일대일로 동기화

7. 패키지 버전을 `1.8.1`로 갱신하고 전체 300개 E2E 테스트 통과

<br>

## 1.8.0

1. 대시보드 To Do 카드의 우클릭 메뉴 맨 아래에 `Note`, Done 카드의 메뉴 맨 아래에 `Closed`를 추가해 해당 상태로 이동 지원

2. 대시보드 점 세 개 메뉴 버튼을 제목 오른쪽 5px 위치로 이동하고, 상태 명칭을 `To Do`, 메뉴의 닫은 탭 명칭을 `Closed`로 통일

3. 대시보드 상태 표시의 바깥쪽 효과를 상태색이 투명하게 사라지는 방식으로 수정하고, PC의 `None` 영역 상단을 일반 탭 카드와 같은 높이로 정렬

4. 모바일 아이콘 클릭 파동의 확산 범위를 20% 축소하고 애니메이션 속도를 1.2배 높여 재생 시간을 350ms로 조정

5. 모바일 현재 그룹명 왼쪽에 그룹 아이콘을 3px 간격으로 추가하고, 에디터·대시보드의 `Move Group` 대상에서 `Ungrouped` 제외

6. 패키지 버전을 `1.8.0`으로 갱신하고 변경 사항에 맞춰 PRD·E2E를 동기화했으며 전체 300개 테스트 통과
