# 1.6.x 버전 이력

{1.6.9 이력 작성 시점에 요약본 작성}

<br>

## 1.6.0

1. 상태 표시줄 CLOSED 개수는 현재 선택된 그룹 기준으로 표시하고, 전체 검색은 모든 그룹의 닫은 탭을 검색하도록 유지하며 관련 표기를 `Closed`로 통일

2. 우측 패널 높이를 동적 뷰포트에 맞추고, 긴 목록을 스크롤해 마지막 항목의 콘텐츠까지 볼 수 있도록 개선

3. 모바일 탭의 글자·크기·왼쪽 색상 아이콘을 확대하고 에디터 줄 간격을 조정해 선택 강조가 줄 전체에 맞도록 개선

<br>

## 1.6.1

1. 모바일 탭의 최소 너비·높이를 각각 6px, 색상 아이콘을 가로·세로 각각 2px 확대하고 에디터 줄 높이를 39px로 늘려 줄 번호·선택 강조 영역과 정렬

2. 모바일 하단을 SEARCH·CLOSED·BOOKMARK·GROUP의 동일 너비 4개 메뉴로 구성하고 아이콘 아래 라벨·개수 배지를 표시하며 가로 스크롤·구분자 제거 및 하단 안전 영역 대응

3. 모바일 최상부에 높이 44px의 현재 그룹 표시줄을 추가하고 18px 아이콘·15px 그룹명, 긴 이름 말줄임·툴팁 및 그룹 전환·새로고침 동기화 지원

4. PC 하단에서 SHORTCUT·SEARCH는 왼쪽, CLOSED·BOOKMARK·그룹 선택은 오른쪽으로 모으고 아이콘 오른쪽에 텍스트를 배치하며 하단 높이를 48px로 축소

5. PC 하단 라벨·그룹명은 14px, 개수는 12px로 확대하고 그룹 선택 버튼에 현재 그룹명·그룹 수를 표시하며 그룹명 최대 너비를 351px로 확대

<br>

## 1.6.2

1. PC 에디터 줄 높이를 35px, 탭 제목 글자 크기를 15px, 색상 아이콘을 가로·세로 각각 11px로 확대하고 탭 높이를 39px로 조정해 제목을 수직 중앙에 배치

2. 모바일 탭 하단에만 2px를 추가해 높이를 46px로 늘리고 아이콘·제목의 세로 위치를 유지하며 줄 번호 영역을 41px로 확대하고 터치 시 편집기·분할 패널의 포커스·커서 재설정을 제거

3. 모바일 그룹 표시줄을 하단 메뉴 위로 이동하고 그룹 동기화·말줄임·툴팁을 유지하며 하단 개수의 괄호를 제거하고 PC에도 아이콘 우측 상단 배지를 적용해 왼쪽 기준 23px로 배치하고 PC 오른쪽 패딩을 26px로 확대

4. 닫힌 우측 패널의 그림자가 편집기·하단 메뉴 우측에 어두운 그라데이션으로 남는 문제를 수정하고 열린 패널에만 그림자 표시

5. PRD의 탭 표시와 전체 검색 요구사항을 별도 제목으로 세분화하고 관련 제목·E2E 폴더 순서를 재정렬하며 모바일 터치·배지 표시·패널 그림자 회귀 테스트 보강

<br>

## 1.6.3

1. 모바일 탭 제목을 16px로 확대하고 하단 여백을 1px·탭 높이를 45px로 조정하며 탭 사이에 전체 높이의 1px 그레이 구분선을 불투명도 60%로 추가

2. 우측 상단에 메뉴 아이콘의 MENU 드롭다운을 추가하고 PC 버튼·드롭다운을 간결하게 정리하며 DARK 기본값·LIGHT 테마 전환, 설정 저장·복원·탭 간 동기화 및 LIGHT 그레이·그린 탭 배경 대비 강화

3. CLOSED를 전체 그룹 기준으로 MENU에 옮기고 하단 SHORTCUT을 제거하며 그룹 개수 배지와 모바일 그룹 표시줄을 삭제하고 현재 그룹명을 하단 버튼에 통합해 편집 공간 확보 및 모바일 그룹명 최대 너비 1.2배 확대

4. 북마크·Closed 패널의 시각을 고정된 우측 영역에 두 줄로 배치하고 날짜는 `YY. MM. DD`, 상세 시간은 영어 `hh:mm:ss AM/PM`으로 표시하며 긴 제목·그룹명은 말줄임 처리

5. 테마 기능을 feature/theme로 통합해 헤더에서 연결하고 AGENTS에 내부 폴더 index.ts 배럴 규칙을 추가해 구조를 정리하며 PRD·E2E의 메뉴·테마 요구사항을 분리하고 관련 회귀 테스트 보강

<br>

## 1.6.4

1. 탭을 드래그 앤 드롭해 좌우 각 열을 상하로 분할하는 최대 4분할을 추가하고, 하단 분할 영역은 편집기 중앙 아래로 내려갔을 때만 활성화하며 4분할 배치·활성 탭 복원과 패널 간 Alt+위/아래 이동 지원

2. PC 우측 패널에 고정 버튼을 추가해 고정 시 body·MENU·그룹 선택이 패널 왼쪽으로 이동하고 슬라이드 없이 X 버튼으로만 닫히게 하며, 왼쪽 경계선 드래그로 패널 너비를 320px~화면 너비-400px 범위에서 조절·저장

3. 모바일에서 하단부·편집기·라인 번호를 제외한 아이콘·글자를 1.2배 확대하고 탭 최소 너비를 1.2배로 늘리며 탭 제목은 18.2px로 조정, 활성 탭 상단 강조선을 3px로 늘리고 그룹 추가 버튼을 정사각형으로 변경

4. 하단 메뉴를 그룹·검색·북마크 순서로 바꾸고 북마크 개수 배지 대신 오늘 변경된 북마크가 있을 때만 붉은 점을 표시하며, 북마크·Closed 패널은 더보기·간소화 없이 전체 내용을 항상 표시하고 Ungrouped를 그룹 목록 맨 아래로 정렬

5. LIGHT 모드의 줄 선택 색상을 라인 번호·편집기 공통 강조색으로 맞추고 활성 탭 배경을 조금 더 짙게 조정하며, src 레이어 폴더를 `{n}-layer` 형식으로 정리하고 PRD 요구사항 번호별 분리와 E2E 테스트 동기화

<br>
