# 1.7.x 버전 이력

{1.7.9 시점에 요약본 작성}

<br>

## 1.7.0

1. 대시보드 드래그 앤 드롭 강조를 탭 분할과 동일한 연녹색 배경·점선 스타일로 통일

2. 대시보드 카드 주변 여백을 확보해 드롭 강조선과 카드 테두리 겹침을 개선하고 드래그 중 카드 위치·크기 유지

3. 미고정 우측 패널 왼쪽 경계에 테마별 그라데이션 음영 추가(DARK는 밝은 음영, LIGHT는 어두운 음영), 고정·닫기 시 제거

4. 우측 패널·대시보드 PRD와 E2E 시나리오 세분화 및 드래그 취소·컬럼 이동·외부 드래그·중복 드롭·공백 메모 코너케이스 추가(전체 276개 테스트 통과)

<br>

## 1.7.1

1. 대시보드 상태 영역의 스크롤 정렬·fog 효과와 선택 카드 배경 개선

2. All Group 및 다중 분할 화면의 탭 드래그 앤 드롭 오류 수정

3. 패널 고정·미고정 레이아웃 정리, PC 최대 너비 70% 지원 및 경계 그라데이션 조정

4. 관심사별 모듈 그룹화, props 타입·공통 코드 정리 및 테마 entity 분리

5. 저장 복원 코너케이스 수정과 E2E 공통화·병렬 실행 개선(전체 290개 테스트 통과)

<br>

## 1.7.2

1. PRD를 기능별 문서로 세분화하고 상세 요구사항과 E2E 테스트 구조를 일치하도록 재구성

2. 소스와 테스트 코드를 관심사별로 그룹화하고 모듈 props 타입·barrel·공통 코드를 정리

3. 저장소·편집기·패널·설정의 예외 처리와 데이터 복원 안정성 개선

4. 모바일 대시보드 상태 표시와 Todo·Doing·Closed 이동 버튼의 배치 및 간격 개선

5. 접근성·키보드 조작·코너케이스 검증을 보강하고 전체 639개 E2E 테스트 통과

<br>

## 1.7.3

1. 대시보드 탭 카드에 컨텍스트 메뉴와 우선순위 정렬을 추가하고 Closed 탭을 대시보드 상태 기반으로 통합

2. 대시보드의 닫힌 탭 메뉴와 모바일 상태 표시를 개선하고 완료 상태 명칭을 `Done`으로 변경

3. 테마 선택을 슬라이딩 토글로 개편하고 전역 검색 진입점을 푸터로 이동하며 상단 탭 Pin 메뉴 제거

4. 패널 최대 너비를 80%로 확장하고 새 탭 생성 시 분할선과 대시보드 카드 복원 위치가 유지되도록 수정

5. 중복·저효율 시나리오를 정리해 핵심 E2E 테스트 체계로 재구성하고 전체 300개 테스트 통과

<br>

## 1.7.4

1. 모바일 터치 하이라이트를 제거하고 아이콘 버튼 중앙 정렬, 푸터 그룹명 표시와 메뉴 아이콘 균등 배치를 개선

2. 설정 패널에 전체 데이터 삭제와 재확인 팝업을 추가하고 모바일 팝업 액션 버튼의 깨짐을 수정

3. 대시보드 진행 상태를 `WIP`에서 `Doing`으로, 전체 그룹 명칭을 `All Group`에서 `All`로 변경

4. 패널 최소 너비를 5% 확대하고 `All`의 `Move Group`에서 `Ungrouped`를 선택할 수 있도록 수정

5. 대시보드에서 닫힌 탭을 복원할 때 기본 빈 탭을 교체하고 다시 닫으면 빈 탭이 생성되도록 개선하며 전체 300개 E2E 테스트 통과

<br>

## 1.7.5

1. 탭 클릭 후 Shift 클릭으로 연속 범위를 선택하고 선택한 탭을 순서대로 함께 드래그하는 기능 추가

2. 대시보드를 브라우저 내부 페이지 전체 영역으로 확장·축소하는 버튼 추가

3. 그룹 패널 너비를 15% 확대하고 넓은 고정 패널로 작업 영역이 좁아지면 푸터를 모바일 아이콘 구성으로 전환

4. 그룹 메뉴에 `Closed`를 추가하고 닫힌 탭의 복원·Todo 변경·영구 삭제와 삭제 재확인 팝업을 제공

5. 대시보드의 열린 Done 탭 컨텍스트 메뉴에서 탭을 `Closed`로 이동할 수 있도록 개선하고 전체 312개 E2E 테스트 통과
