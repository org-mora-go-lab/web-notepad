# 1.9.x 버전 이력

## 1.9.2

1. `1.9.1`의 main PR 병합 후 최신 main에서 개발 브랜치를 생성하고 패키지 버전을 `1.9.2`로 갱신

2. 로그인 후 별도 우측 아이콘을 제거하고 인증 확인 중 계정 영역에 스켈레톤을 표시

3. 알림을 그룹알림으로 바꿔 더보기로 옮기고 하단 메뉴를 그룹·대시보드·더보기로 정리

4. 개인 작업공간과 공유 그룹의 주기적 조회를 제거하고 화면 복귀·연결 복구 시 동기화

## 1.9.1

1. 더보기에서 공유 그룹 게시판과 초대·참여 기능을 제공하고 임시 관리자 모드에서 게시글 등록·수정·내리기를 지원

2. 카카오 프로필 동의 요청과 이름·사진 표시를 보완하고 로그인 영역 좌우 여백을 축소

3. 같은 계정의 PC·모바일 작업공간을 복원·동기화하고 미전송 변경, 동시 수정 본문과 탭 ID 충돌을 복구

4. 하단 저장 상태 영역을 활성 탭 제목의 반짝임 효과로 변경하고 전체 E2E 557개 통과

## 1.9.0

1. 카카오 로그인 후 프로필 이미지와 이름을 표시하고 PC·모바일의 로그인 전후 헤더 배치를 개선

2. 그룹 공유 링크와 공동 편집, 다른 사용자의 변경 알림을 추가

3. 편집이 멈춘 뒤 3초 후 변경 상태를 Turso에 한 건의 이력으로 저장하고 저장 상태를 표시

4. 패키지 버전을 `1.9.0`으로 갱신
